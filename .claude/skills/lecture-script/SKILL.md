# lecture-script｜読み上げ原稿の作成・収録動画の反映

千葉大のオンデマンド講義の **読み上げ原稿**（`slides/<deck>/原稿_第N回.md`）を作る・直す、そして
**収録した動画を原稿に「反映」する**（＝実際に話した内容に原稿を合わせる）ためのスキル。

スライド本体（Marp）は **marp-academic-slides**、データ図は **marp-echarts**。本スキルは **原稿テキスト側** を扱う。

## When to use
- 「第N回の原稿を書いて／直して」「読み上げ原稿を作って」
- 「この動画（.mov / .mp4）を文字起こしして」
- 「文字起こしを原稿の動画Nに反映して」「実際に話した内容に原稿を合わせて」
- 新規ドラフトを書くときも、本スキルの **文体・語尾ガイド** と **差分パターン** に従う

## 原稿ファイルの構造（崩さない）
- 場所: `slides/<deck>/原稿_第N回.md`（例: `20260614_GenAI-Research_01_ethics-literacy/原稿_第1回.md`）
- 構造: `# 読み上げ原稿 …`（タイトル）→ `# 動画N｜…`（動画見出し）→ `### スライド N-x｜…`（スライド見出し）→ **本文1段落** → `---`（区切り）
- **1スライド = 1段落**。編集は **本文段落だけ** を差し替え、見出し・`---`・他の動画は触らない。

## ワークフロー：収録動画 → 原稿へ反映
1. **編集前に必ずバックアップ**（別名 `.bak`）
   `cp 原稿_第N回.md 原稿_第N回.md.YYYYMMDD-動画N反映前.bak`
2. **文字起こし** → 詳細は [references/transcription.md](references/transcription.md)（ffmpeg で16kHz mono WAV → whisper.cpp、`-l ja`）
3. **反映**（文字起こし＝実発話を正、ドラフト＝専門用語の正本）
   - 文字起こしを動画 → スライドに対応づける（`.srt` のタイムスタンプとスライド見出しで突き合わせ）
   - whisper の **誤変換を修正**（[references/transcription.md](references/transcription.md) の誤変換表）
   - **語尾・文体を整える**＝ [references/style-guide.md](references/style-guide.md)
   - 動画は **1本ずつ**。動画Nの収録なら **動画Nセクションのみ** 更新し、他は変えない
   - 次動画へのブリッジは付けず、**各動画は自己完結の導入・締め**にする（収録は1本ずつのため）
4. **差分を報告**：ドラフトから内容が変わった点・省略された点・要確認点（例：ペナルティ文の有無）を箇条書きで伝える
5. 生成物（音声 `transcript/vN_audio.wav`、`vN_transcript.txt/.srt`）と `.bak` の場所を伝える

## 文体・語尾の要点（詳細・before/after は [references/style-guide.md](references/style-guide.md)）
読み上げ原稿は declarative / instructional 寄り。話し言葉の弱い語尾を整理する：
- 多用しない: 「〜と思います」「〜できればと思います」「〜ありがたいです」「〜結構です」「〜と思ってください」
- 置換: 依頼→「〜してください」／勧誘・提案→「〜しましょう」／事実・説明→「〜します・〜です」
- **残す**: 一人称の所感（「〜と感じています」「悩んでいるところですが」）・温かい結語・問いかけの「〜でしょうか」。硬くしすぎない
- 同じ語尾を連続させない（体言止め・問いかけを混ぜて単調さを避ける）

## 関連スキル / メモリ
- 文字起こしのローカル環境はメモリ `local-transcription-whispercpp` にも要約
- スライド本体は marp-academic-slides、図は marp-echarts、既存図の再利用は marp-reuse-figures
