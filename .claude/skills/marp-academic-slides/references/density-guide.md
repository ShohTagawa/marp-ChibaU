# 密度ガイド（スカスカ回避）

学術発表スライドが「スカスカ」に見える主因は **情報密度の不足** と **余白の使い方の下手さ**。フォントを小さくして無理に詰め込むのではなく、**コンテンツの粒度を上げ、適切なパターンを選ぶ** ことで密度を確保する。

## 1スライドの基本三点セット

すべての本文スライド（cover/message/divider/qa 以外）は次の3要素を満たすべき：

1. **メッセージ**：このスライドで主張したい1行
2. **根拠**：図/表/データ/箇条書きなど
3. **補足**：キャプション or テイクアウェイ or 補注

3点のうち2点しか書けないなら、たいてい別パターンに変えるか、内容を分割せず統合した方がよい。

## 箇条書きルール

- **3項目以上を原則**。2項目以下は次のどれかで対処：
  - 統合：上位概念の1メッセージに集約してパターン④（message）にする
  - 増強：補足の根拠を1-2項目足す
  - 変形：左右分割（③）にして右に図を入れる
- 各項目は **20〜43字** が読みやすい。短すぎ（10字未満）も「スカスカ」要因。
- 箇条書きが5項目を超えるなら、2つのセクション（summary 型）に分けるか、表に変える。

## 図表プレースホルダー

実画像がまだ無い時、空白で残さない。次のいずれかで埋める：

- 角丸プレースホルダー：`<div class="placeholder">[ここに○○のグラフ]</div>`
- ダミー表：列名と数行のサンプル値を入れた表
- ASCII 図 / 簡易 SVG：構造図なら手書き SVG を埋め込む

プレースホルダーには **どんな図を入れるか** を明示する。「[画像]」ではなく「[2020-2024 年の論文数推移グラフ]」。

## フォントサイズの不変則

**最小 18px を厳守**。

- 本文 24px（標準）
- 表本文 20px
- 参考文献・キャプション・ページ番号・ふりがな ≥ 18px（最小）

空間が余るからといってフォントを下げない。下げるのは **内容を増やせない時の最後の手段** ですらない（18px未満は不可）。代わりに：

- パターンを変える（fig → split、summary → fig）
- 補足の側注（caption）を追加
- 関連スライドと統合（章の構造を見直す）

## 文字数ターゲット（patterns.md と整合）

| 要素 | 上限 |
|---|---|
| スライドタイトル | 20字 |
| セクション見出し | 14字 |
| 箇条書き1行 | 43字 |
| テイクアウェイ | 43字 |
| 表セル | 15字 |
| キャプション | 30字 |
| サブメッセージ | 43字 |
| カバータイトル | 30字（理想20字） |

## 余白とリズム

- ヘッダー帯下と本文の間、本文と次要素の間：**8〜16px** 程度を維持
- 大きな余白を作りたい時は **paragraph break** を使う。`<br>` で無理矢理空けない
- 1スライドに見出しレベルは2つまで（h2 + h3）

## インラインSVG図解の作法（見切れ防止）

手描きの構造図（`<svg>` 直書き）は、テキストが枠やキャンバスをはみ出して **見切れ** やすい。次を守る。

1. **文字幅を見積もってから枠幅を決める。** ブラウザ描画の概算：全角（CJK・全角記号）≒ `font-size × 1.0` px、半角（英数・記号・矢印）≒ `× 0.55` px、空白 ≒ `× 0.3` px。`<rect class="card" width="W">` に中央寄せで入れる文字列は **推定幅 ≤ W − 16px**（角丸＋余白分）に収める。溢れたら ①枠を広げる ②文言を短く ③2行に分ける ④font-size を下げる（SVG内キャプションは最小13pxまで可。本文HTMLの18px則とは別枠）。
2. **viewBox の内側に収める。** SVG は既定で viewBox 外を **クリップ（＝無言で切り落とし）** する。各テキストの左右端（中央寄せなら `x ± 幅/2`）が viewBox の左右より最低 8px 内側に入るように。端ギリギリは避ける。
3. **並列ボックスは「いちばん狭い枠」に文字数を合わせる。** Part1/2/3 のように役割が並ぶ枠群は、各キャプション長を揃える。1つだけ長いとその枠だけ見切れる。
4. **主役ボックス列は矢印で繋ぐ。** フロー図の主役ボックスに背景の通し線（progress line）を重ねない。線が枠を貫いてノイズ・見切れに見える。通し線を使うなら、上部の小型インジケータ等、主役と分離した場所に限る。
5. **作ったら必ず原寸で見る。** 図を追加・変更したら `--html`（必須・無いと生SVGが文字列化）付きで PNG 出力し、各図を拡大確認する。数が多い時は 1. の文字幅見積もりで候補を機械抽出 → 該当だけ目視、が速い（見積もりは過検出側に倒すと見逃さない）。
