# Slide Patterns

10種類のスライド型。各パターンに **用途・最小コンテンツ・文字数上限・Markdownスニペット・拡張のヒント** を載せる。
パターンは `<!-- _class: <name> -->` で適用する。

## ヘッダーの構造（重要）

ヘッダー帯には3要素が並ぶ：
1. **デックタイトル** — 発表全体のタイトル。frontmatter `header:` で **1回だけ** 設定。
2. **ページタイトル** — そのスライド固有のタイトル。スライド本文の冒頭で `<div class="page-title">○○</div>` と書く。
3. **ロゴ** — frontmatter `header:` の `<img class="hdr-logo">` で設定。

つまり、各スライドでヘッダーをまるごと書き直す必要はない。frontmatterで1回設定、各スライドはページタイトルだけ `<div class="page-title">` で書く。

cover / divider / message / qa はヘッダー帯を表示しないので page-title も書かない（書いても表示されない）。

## パターン一覧

| # | クラス | 用途 |
|---|---|---|
| P1 | `cover` | 表紙 |
| – | `intro` | 自己紹介 |
| ① | `fig` | 図表中心型 |
| ② | `summary` | テキスト要約型（角丸セクション） |
| ③ | `split` | 左右分割型 |
| ④ | `message` | メッセージ型 |
| – | `divider` | 章扉 |
| – | `wrap` | まとめ（✓付き） |
| – | `refs` | 参考文献 |
| – | `qa` | Q&A / おわり |

## P1: 表紙（cover）

**用途**：デックの最初。タイトル・サブタイトル・発表者・日付・所属。
**ヘッダー帯**：なし。
**最小コンテンツ**：タイトル＋発表者＋所属。
**文字数**：タイトル ≤ 30字（理想 ≤ 20字）、サブタイトル ≤ 50字。

```markdown
<!-- _class: cover -->

# {{発表タイトル}}

## {{サブタイトル}}

### {{発表者氏名}}
### {{所属}}

<div class="meta">
{{YYYY年MM月DD日 / イベント名}}
</div>

<!-- スピーカーノート：自己紹介と謝辞 -->
```

## 自己紹介（intro）

**用途**：演者紹介。名前（ふりがな付き）、所属、役割の説明、研究/興味分野を2カラムで。
**ヘッダー帯**：あり。page-title は「自己紹介」。
**最小コンテンツ**：氏名、所属、左右カラム両方に内容。

```markdown
<!-- _class: intro -->

<div class="page-title">自己紹介</div>

<div class="intro-head">
<div class="intro-name">
<span class="ruby">たがわ　しょう</span>
田川　翔
</div>
<div class="intro-affil">
<strong>所属：</strong>{{大学名}}<br>
{{部局/センター名}}
<div class="role">{{役割や仕事の一言説明}}</div>
</div>
</div>

<div class="two-col">
<div class="col">

### ①{{経歴トピック1}}

![{{図のalt}}]({{図パス or プレースホルダー}})

</div>
<div class="col">

### ②{{経歴トピック2}}

{{2-4行の説明文}}

</div>
</div>

<!-- 経歴の流れと今回の発表との繋がりを話す -->
```

## ①図表中心型（fig）

**用途**：1枚の図・表・グラフを主役にして語る。最下部にテイクアウェイ（固定位置）。
**ヘッダー帯**：あり。
**最小コンテンツ**：見出し＋図表＋テイクアウェイ（3点必須）。
**文字数**：タイトル ≤ 20字、テイクアウェイ ≤ 43字、表セル ≤ 15字。

```markdown
<!-- _class: fig -->

<div class="page-title">{{ページタイトル ≤14字}}</div>

## {{スライドの見出し ≤20字}}

<div class="fig-area">

![{{グラフ説明}}]({{画像パス}})

</div>

<div class="caption">図1. {{図のキャプション}}</div>

<div class="takeaway">{{要点メッセージ ≤43字}}</div>

<!-- どの数値に注目させるかを口頭で補足 -->
```

**表バージョン**（画像の代わりに表）：`.fig-area` の中に Markdown 表を置く。

**手描き SVG 図を直書きする時**：density-guide.md「インラインSVG図解の作法（見切れ防止）」の5原則（文字幅見積もり・viewBox内に収める・並列枠の文字数を揃える・主役は矢印接続・原寸で目視確認）に従う。

**画像が無い時**：

```markdown
<div class="fig-area"><div class="placeholder">[ここに○○のグラフ]</div></div>
```

## ②テキスト要約型（summary）

**用途**：複数観点を整理して示す。各観点を角丸ボックスで区切る。
**ヘッダー帯**：あり。
**最小コンテンツ**：セクション 2-3 個。各セクション 2-4 箇条書き。
**文字数**：セクション見出し ≤ 14字、各箇条 ≤ 43字。
**注意**：セクション 1 個なら別パターン（fig や split）に変える。

```markdown
<!-- _class: summary -->

<div class="page-title">{{ページタイトル}}</div>

## {{タイトル ≤20字}}

<div class="sections">

<div class="sec-box">

### {{セクション見出し1}}

- {{要点1 ≤43字}}
- {{要点2 ≤43字}}
- {{要点3 ≤43字}}

</div>

<div class="sec-box">

### {{セクション見出し2}}

- {{要点1 ≤43字}}
- {{要点2 ≤43字}}

</div>

</div>

<!-- 各セクションの相互関係を言葉で繋ぐ -->
```

---

## ③左右分割型（split）

**用途**：図と説明を並べて見せる。図 50% + 箇条書き 50%。下部にテイクアウェイ（固定位置）。
**ヘッダー帯**：あり。
**最小コンテンツ**：左に図/表、右に箇条書き3項目以上、下部テイクアウェイ。
**文字数**：右側見出し ≤ 20字、各箇条 ≤ 43字、テイクアウェイ ≤ 43字。

```markdown
<!-- _class: split -->

<div class="page-title">{{ページタイトル}}</div>

## {{タイトル ≤20字}}

<div class="split-body">
<div class="left">

![{{図alt}}]({{画像パス}})

<div class="caption">図1. {{キャプション}}</div>

</div>
<div class="right">

### {{右側見出し}}

- {{要点1 ≤43字}}
- {{要点2 ≤43字}}
- {{要点3 ≤43字}}
- {{要点4 ≤43字（任意）}}

</div>
</div>

<div class="takeaway">{{全体メッセージ ≤43字}}</div>
```

---

## ④メッセージ型（message）

**用途**：1メッセージで聴衆の注意を引きたい時。問いかけ・宣言・キーフレーズ。
**ヘッダー帯**：なし。
**最小コンテンツ**：メッセージ 1 行。サブメッセージ任意。
**文字数**：メッセージ ≤ 30字、サブメッセージ ≤ 43字。

```markdown
<!-- _class: message -->

# {{中心メッセージ ≤30字}}

## {{サブメッセージ ≤43字（任意）}}

<!-- このスライドで一拍置く -->
```

---

## 章扉（divider）

**用途**：章の区切り。背景を赤にして章番号と章タイトルを大きく。
**ヘッダー帯**：なし（背景全面が赤）。

```markdown
<!-- _class: divider -->

<div class="chapter-num">CHAPTER {{章番号}}</div>

# {{章タイトル}}

## {{章の一言サマリ ≤30字}}

<!-- この章で扱うトピックを口頭で予告 -->
```

---

## まとめ（wrap）

**用途**：発表全体の要点を ✓ チェック付きで箇条書きにする。
**最小コンテンツ**：要点 3-5 項目。各項目はその章の核を1行で。
**文字数**：各要点 ≤ 43字。

```markdown
<!-- _class: wrap -->

<div class="page-title">まとめ</div>

## まとめ

- {{P○の要点 ≤43字}}
- {{P○の要点 ≤43字}}
- {{P○の要点 ≤43字}}
- {{P○の要点 ≤43字}}

<!-- 発表全体のメッセージを再強調 -->
```

---

## 参考文献（refs）

**用途**：参照した論文・書籍リスト。APAスタイル。

```markdown
<!-- _class: refs -->

<div class="page-title">参考文献</div>

## 参考文献

- 著者A, 著者B (2024). タイトル. *ジャーナル名*, 12(3), 45-67. https://doi.org/...
- 著者C (2023). *書名*. 出版社.
- Author D, Author E (2025). Article title. *Journal Name*, 5(2), 123-145.
```

**項目が10件超**：ページ分割（refs を複数枚に）。フォントは小さくしない。

---

## Q&A / おわり（qa）

```markdown
<!-- _class: qa -->

<div class="page-title">Q&amp;A</div>

# Q&A

## {{メール / SNS / プロジェクトURL}}
```

---

## パターン選択フローチャート

| 伝えたいこと | 推奨パターン |
|---|---|
| 数値・データの示唆 | ① fig |
| 図と説明を対比 | ③ split |
| 複数観点の整理 | ② summary |
| 1つの強いメッセージ | ④ message |
| 章の切り替え | divider または message |
| 結論の集約 | wrap |
| 演者紹介 | intro |
| 開始・終了 | cover / qa |

迷ったらまず **fig** または **split**。情報密度を上げやすい。
