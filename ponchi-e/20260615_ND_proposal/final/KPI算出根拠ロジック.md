# KPI算出根拠ロジック — Nexus Uni+

> 姉妹文書 [`KPI実装可能性ロジック.md`](./KPI実装可能性ロジック.md)（＝機序・測定設計）に対し、本書は**「その数字がどう計算されるか（算出式）」と「なぜ届くか（達成可能性）」を、複数の算出案つきで示す“計算を見せる”版**。
> **太字＝仮定値（要較正）**。実数（GS2025等）はその旨明記。各KPIに **複数案（A/B/C…）** を置き、相互チェックで頑健性を担保する。

## 0. 算出の2タイプと共通ルール

| 型 | 対象 | 計算の本質 | 検証法 |
|---|---|---|---|
| **タイプI：積み上げ算定** | KPI①②（時間・業務削減） | 投入リソースから**理論値を積算**→実測で確認 | RAGログ・タイムスタディ |
| **タイプII：調査スコアの前後差** | KPI③④（研究力・評判） | 既存調査指標を**介入前後で差分** | 利用群 vs 非利用群 |

**共通：純効果はDID（差分の差分）で抽出**（全学トレンド・他施策の交絡を除去）

```
純効果 = (利用群_after − 利用群_before) − (非利用群_after − 非利用群_before)
```

→ 「目標+Npt」は、この**純効果がNに達するか**で判定する（見かけの変化ではなく因果の純増）。

## 1. KPI① 教員の研究時間 +3h/週（＝+30%相当）

### 算出式（基本）
```
削減時間/週 = Σ_i ( 発生頻度_i × 1件あたり時間_i × AI代替率_i )
```

### 算出案（3通りで相互チェック）

**案A：業務源の積み上げ（ボトムアップ）** ← 主案
| 削減源 | 算定の要素（前提） | 週削減(分) |
|---|---|---|
| 定型問合せ（手続・履修・様式・進捗） | 指導院生**6人**×月次問合せ×RAG自己解決**55%** | **60** |
| 多言語対応（翻訳・多言語資料） | AI翻訳・生成 | **30** |
| 申請書・評価資料・様式の下書き | AIドラフト（教員は確認のみ） | **45** |
| 支援部署への取次・情報探索 | ニーズ⇄支援マッチング | **30** |
| 重複説明・オンボーディングFAQ化 | ナレッジ再利用 | **15** |
| **合計** | | **180 ＝ 3.0h** |

**案B：業務ポートフォリオ（トップダウン）**
```
削減時間 = 週労働時間 × 定型業務比率 × 平均削減率
         = 55h(仮) × 20%(仮) × 27%(仮) ≈ 2.97h ≈ 3.0h
```

**案C：実測（事後・RAGログ）** ← 検証用
```
削減時間/週 = Σ(自己解決した問合せ件数 × 従来の平均対応分) ÷ 稼働週
```
RAGが代替した件数×従来対応時間を**実ログから事後算定**。案A・Bの理論値と突合し、3hに収束するかを月次でダッシュボード検証。

> 3案が独立に約3hへ収束 → 推計の頑健性（triangulation）。

### 保守/標準/楽観（RAG自己解決率で振る）
| シナリオ | 自己解決率 | 削減時間 |
|---|---|---|
| 保守 | 40% | ≈ 2.4h |
| **標準** | **55%** | **3.0h** |
| 楽観 | 65% | ≈ 3.5h |

### 財務換算（みなし人件費削減額・参考）
```
年間削減額 = 削減時間/週 × 稼働週 × 対象教員数 × 教員時給
例: 3h × 40週 × 教員1人 × ¥5,000(仮) = ¥600,000/人・年
```

### 達成可能性：**高**
3hは「1日あたり約36分」に過ぎず、既存の非研究業務の置換。標準前提で到達、保守でも8割（2.4h）で符号は不変。

## 2. KPI② 高度化に使える時間 +30%（定型削減 ＋ 非定型へのAI活用）

「高度化に使える時間 +30%」は**2つの経路の合算**で達成する。
- **(A) 削減パス**：定型・窓口業務をAIが肩代わり → 時間が浮く
- **(B) 活用パス**：既存の**高度／非定型業務にAIを活用** → 同じ時間でより多く・時短（＝高度業務でもAIが使えるなら、その効率化分も30%に含める）

### 算出式（基本：2経路の合算）
```
高度化に使える時間 増加率 = (A)削減パス ＋ (B)活用パス   （重複は排除）

(A) 定型業務 削減率     = Σ_i ( 定型業務構成比_i × 機構別削減率_i )
(B) 非定型業務 利用率   = Σ_j ( AIが活用できる非定型業務カテゴリ構成比_j )
```
> **(B) の扱い**：利用率＝**高度／非定型業務のうち AI を活用できる業務の割合**（構成比の単純合計＝最も簡単）。これは「時間削減」ではなく **AIの関与・浸透の広がり（coverage）** を表す指標。(A)削減率（時間）とは**単位が異なる**ため、両者は**並べて報告**（または「AIが関与した業務の割合」として束ねる）し、機械的な足し算で“時間が30%増えた”とは言わない。実効担保のため (A)の時短・満足度をガードレールに併せ見る（deflection と同じ考え方）。

### (A) 削減パスの算出案（3通り）

**案A：業務構成比 × 削減率** ← 主案
| 業務カテゴリ | 構成比 | 削減率 | 寄与 |
|---|---|---|---|
| FAQ・問合せ対応 | **35%** | **55%** | 19.3pt |
| 手続き・様式処理 | **20%** | **30%** | 6.0pt |
| 情報探索・部署間取次 | **15%** | **50%** | 7.5pt |
| **削減合計** | | | **≈ 32.8% ⇒ 約30%** |

**案B：RAG deflection rate（直接）**
```
正味削減率 ≒ ( AIだけで完結した件数 − 一定期間内の再問合せ件数 ) ÷ 総問合せ件数
```
AIサポートの自己解決（deflection）は分析会社・ベンダー報告で概ね **20〜50%（成功例で40〜80%）**、Gartner は FAQ級が全体の約4割と報告。本目標30%はこの範囲の**下方＝控えめ**。
> **出典と扱い方**：(1) 上記は主に**民間カスタマーサポート**の値で、出典の多くは**ベンダー/業界ブログ＝二次情報**。正式提案では **Gartner／Zendesk CX Trends／Salesforce State of Service** 等の**一次資料を直接引用**すること。(2) **労力削減は deflection 基準でよい**：本KPIは職員・教員の**工数削減**を測り、問合せが**人手に来なければ工数は実際に浮く**ため分子は deflection が適切。ただし「諦め離脱→後日また人手」を除くため **正味deflection＝deflection −（一定期間内の再問合せ）** とする。(3) **ガードレールに resolution率／満足度を併測**し低下させない（＝離脱で稼ぐ見かけのdeflectionを排除）。Gartner の「45%deflectでも完全解決は約14%」は、この**ガードレールの必要性**を示すもの（分子を否定するものではない）。なお品質ガードレールは KPI④（推奨意向）と並走する。

**案C：FTE換算**
```
削減率 = 削減した人時(窓口・事務) ÷ 総人時
```
人員配置の再配分で経営的に表現。

### (B) 活用パスの算定（非定型業務への AI 利用率）
高度／非定型業務のうち**AIを活用できる業務カテゴリの構成比を合計**する（最も簡単）。例：

| 非定型・高度業務 | AI活用 | 構成比 |
|---|---|---|
| 申請書・評価資料の起草／要約 | ◎ | **15%** |
| 文献・情報の収集・整理 | ◎ | **10%** |
| データ集計・分析の下処理 | ○ | **8%** |
| **AI利用率 小計** | | **≈ 33%（仮定値）** |

> **位置づけと二重計上の回避**：(B)利用率は「非定型業務にAIがどれだけ関与するか」の**広がり**を示し、(A)削減率（時間）とは別の指標。KPI②は **(A)削減率と(B)利用率の2サブ指標で報告**（または「AIが関与した業務の割合」で束ねる）。申請書起草等は KPI①(+3h/週)とも重なるため、**①②間・(A)(B)間で二重計上しない**。

### 保守/標準/楽観（FAQ deflectionで振る）
| シナリオ | FAQ deflection | 全体削減率 |
|---|---|---|
| 保守 | 40% | ≈ 24% |
| **標準** | **55%** | **約30%** |
| 楽観 | 65% | ≈ 36% |

### 達成可能性：**高**
業界標準（30–50%）に照らし30%は控えめ。「削減」と「高度化への再配分」を分離測定でき、効果の所在が明確。**削減(A)・活用(B)の2経路**があるため、片方が伸び悩んでももう一方で補完でき、目標の頑健性が高い。

## 3. KPI③ 院生の研究力 +5pt（自己効力感・成長実感）

> タイプII（調査スコアの前後差）。既存「意識・満足度調査」等の**回答をポイント換算**して測る（新規尺度なし）。**+5pt を最も安全＝高確度に達成できる**測り方を主案にする。

### 算出式（基本）
```
ΔKPI③ = スコア_after − スコア_before   （DIDで純効果を抽出）
```

### 安全な算出法（主案A）：既存回答の「100点換算スコア」
5段階回答を等間隔で点数化し、加重平均を 0–100 に正規化する。
```
スコア = ((平均点 − 1) ÷ (段階数 − 1)) × 100      ［5→100, 4→75, 3→50, 2→25, 1→0］
```

**現状値（実数から換算）**
| 合成指標 | 設問（出典・平均点） | 100点換算（現状） | +5pt目標 |
|---|---|---|---|
| 研究力コア（自己効力感） | GS2025 Q5：主体性4.26・問題解決4.25・ねばり強さ4.35・自立的決断4.30 等の合成（平均≈4.27） | **≈ 82点** | **87点** |
| 成長実感 | 学習状況調査：「成長を実感している」（4段階・平均3.31） | **≈ 77点** | **82点** |

### なぜ“安全（高確度）”に届くか
1. **部分的な上昇も全部加点**：top-box方式は最上位に届いた人しか数えないが、点数換算は **④→③・③→②・②→① のどの1段階アップも加点**。改善を取りこぼさず＝感度が高く天井に張り付かない。
2. **小さな分布シフトで+5pt**：+5点 ＝ 平均 **+0.2**（5段階）。**回答者の約20%が1段階上がる**だけで到達（または10%が2段階）。本当に効けば自然に届く水準。
3. **多項目の合成で安定**：複数設問の平均ゆえ年次のブレ（分散）が小さく、+5ptが偶然でなく**構造的**に出る。
4. **天井に余裕**：現状 82／77点 ⇔ 満点100。伸びしろ十分。
5. **効果量で控えめ**：+0.2平均 ≈ **0.2 SD**＝学習支援・メンタリング介入の通常域の下限。過大でない。

### 最小到達シナリオ（5段階・研究力コア）
| 必要な変化（介入2年で） | スコア変化 |
|---|---|
| 回答者の 12% が1段階アップ | +3点 |
| **回答者の 20% が1段階アップ** | **+5点（目標）** |
| 回答者の 8% が2段階アップ | +4点 |

### 算出案（点数化の代替）
| 案 | 取り方 | +5pt の意味 |
|---|---|---|
| **A（主案・安全）** | 100点換算スコア（部分上昇も加点） | 平均+0.2／20%が1段階↑ |
| B | top-box（最上位）%ポイント | 成長実感 45.5→50.5% 等（最上位到達者のみ計上＝厳しめ） |
| C | 標準化効果量 | ≈ 0.2 SD |
| **D（補完・保険）** | 直接寄与設問 × 群間比較（後述） | 「寄与した」肯定率／利用群−非利用群差 |

### 補完・フォールバック案D：アプリの“寄与”を直接聞く × 群間比較
主案Aのスコアが+5pt伸び悩む場合の保険。利用群に「**Nexus（アプリ・AI伴走）はあなたの成長実感／研究力にどの程度寄与したか**」を直接聞き、**肯定率**で示す＋**利用群 vs 非利用群**の成長実感スコアを比較（DID）。
- **長所**：アプリの**因果（寄与）を直接示せる**・1問追加で**最も簡単**・既存スコアが天井でも測れる。
- **留意**：直接「効いたか？」は**自己帰属バイアス／回答迎合**が乗りやすく、**単独では“軟らかい”証拠**。利用群は元々意欲が高い**選択バイアス**もある。
- **使い方**：主案A（スコアのDID）と**必ず併用**し、(1) 寄与の肯定率（直接）＋ (2) 利用群−非利用群のスコア差（客観）＋ (3) 利用強度×成長実感の相関、で**三角測量**。「効いたと感じる」だけでなく「実際にスコアも上がった」を両輪で示す。

### 達成可能性：**高（安全側）**
点数換算は改善を取りこぼさず、現状 82／77点で天井に余裕、+5ptは平均+0.2＝0.2SDで通常域。**DIDで純効果**を抽出し、利用群が非利用群を +5pt 上回るかを検証。自己申告偏りは Journeyログ・指導教員評価で三角測量。弱点＝英語(3.62)はマッチングで底上げ。

## 4. KPI④ レピュテーション +3pt（内部評判＝推奨意向）

> タイプII。**正本＝GS2025 Q4「知人や後輩に千葉大学への進学をすすめる」（推奨意向＝NPSの内部版）**。外部評判（THE/QS）は遅行・床・バンドのため2年KPIに不可（→実装可能性ロジック §5.2）。

### 算出式（基本）
```
ΔKPI④ = 推奨意向_after − 推奨意向_before   （DIDで純効果）
```

### 算出案（4通り）
| 案 | 計算法 | 現状（GS2025修了生）→ 目標 | 備考 |
|---|---|---|---|
| **A（主案）** | 推奨意向 **top-box（あてはまる）** の%ポイント | **32.6% → 35.6%** | 天井遠く伸びしろ大。Q4内で最も低い項目＝効きどころ |
| B | **NPS式**＝推奨者%−批判者%（top-box=推奨者／下位2=批判者） | ≈ +26.6 → **+29.6** | 推奨者32.6 − 批判者(3.8+2.2=6.0) |
| C | 肯定計（top-2）の%ポイント | 75.5% → 78.5% | 慣用的 |
| D | 副次「学生の声→改善」両面 | 肯定 15.8→18.8% ／ 不満 49.9→46.9% | 高レバレッジの過程指標 |

### 達成可能性：**中〜高**
推奨意向 top-box は **32.6%＝天井から遠い**。かつ Q4 の体験項目（優れた友人4.39・希望進路4.35・優れた教員4.29）に対し**推奨だけ4.00と一段低い**＝「体験は高いのに薦めが伸びていない」未充足＝基盤の伸びしろ。外部評判（THE/QS）は2年では先行指標（研究生産性等）の正方向推移で示す。

## 5. 感度分析まとめ（保守でも符号は不変か）

| KPI | 保守 | 標準（目標） | 楽観 | 判定 |
|---|---|---|---|---|
| ① 研究時間 | 2.4h | **3.0h** | 3.5h | 保守でも8割・方向維持 |
| ② 定型削減 | 24% | **30%** | 36% | 保守でも有意 |
| ③ 研究力 | +2.5pt(0.15SD) | **+5pt(0.25SD)** | +7pt | 縮小も正方向 |
| ④ 推奨意向 | +1.5pt | **+3pt** | +4pt | 正方向 |

→ いずれも**改善方向（符号）は保持**。目標値は標準前提での到達点で、保守前提でも投資判断を覆す逆転は起きない。
