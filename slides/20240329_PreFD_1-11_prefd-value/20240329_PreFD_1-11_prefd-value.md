# <span style="color:var(--accent-dark)">PreFD</span>(プレFD)とは

<div class="lead-note" style="font-size:28px;">学識を教授するために必要な能力を培うための機会</div>

<div class="box-info" style="font-size:21px; padding:8px 20px;"><b>大学院設置基準 第四十二条</b>　大学院は、博士課程の学生が修了後自らが有する学識を教授するために必要な能力を培うための機会を設けること又は当該機会に関する情報の提供を行うことに努めるものとする</div>

<div style="font-size:18px; color:#666; margin:4px 0;">※Pre FDは和製英語。英語では、Preparing Future Faculty （PFF）。</div>

<div class="subhead" style="margin-top:8px;"><span style="color:var(--accent-dark); font-weight:800;">２つの機会</span><span class="tag-soft" style="border-radius:8px; padding:3px 14px; font-weight:800;">大学教員準備プログラム</span><span class="tag-soft" style="border-radius:8px; padding:3px 14px; font-weight:800;">TF(ティーチングフェロー)制度</span></div>

<div class="stepbox" style="padding:10px 24px; margin:8px 0;">
<div class="st" style="font-size:23px; margin:3px 0;"><b>達成価値</b>：授業を準備し実施するための一通りを体験</div>
<div class="st" style="font-size:23px; margin:3px 0;"><b>内発的価値</b>：タスクや仕事が楽しい / 色々な人と学べて満足</div>
<div class="st" style="font-size:23px; margin:3px 0;"><b>道具的価値</b>：実際の授業で役立つ / <span style="color:var(--accent); font-weight:800;">採用に役立つ</span></div>
</div>

<div style="text-align:center; font-size:32px; font-weight:800; color:var(--accent-dark); margin-top:8px;">どうして<span style="color:var(--accent);">採用</span>にも関わるのか？</div>

<!--
