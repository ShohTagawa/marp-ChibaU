# <span style="color:var(--accent-dark)">1．</span>シラバスの位置づけ

<div class="subhead" style="margin:2px 0 8px;"><span class="tag tag-soft">問い</span><span>シラバスとは何か？</span></div>

<div class="stepbox" style="margin:4px 0; padding:8px 24px;">
<div class="st" style="font-size:22px; line-height:1.45;">各授業科目の詳細な授業計画<br>履修条件、授業科目名、学習成果、担当教員名、講義、<b>毎回の授業内容</b>、<b>成績評価基準・方法</b>、<b>準備学習のための具体的な指示</b>、教科書・参考文献等が記載</div>
</div>
<div class="cite" style="margin-top:2px;">（大学改革支援・学位授与機構「高等教育に関する質保証関係用語集」）</div>

<div class="box-info" style="margin-top:6px; padding:9px 22px; font-size:21px; margin-right:calc(var(--pip-w) + 40px);">2008年時点で、9割以上の大学が全授業科目のシラバスを作成<br>しかし当時、「準備学習等についての具体的な指示」を盛り込んでいたのは約半数</div>
<div class="cite" style="margin-top:2px;">（中央教育審議会，2008，「学士課程教育の構築に向けて（答申）」）</div>

<div class="box-warn" style="margin-top:6px; padding:9px 22px; font-size:21px; margin-right:calc(var(--pip-w) + 40px);">現在、<b>シラバスは、学生との契約</b>と考えられている<br>大学（に限らず社会で）は、契約を適切に守る必要がある<br><span style="font-weight:600; color:#8a4b00;">（予告なく契約内容を変更されると、まず学生が困り、結果的に契約不履行を指摘されて大学も困ることに…）</span></div>

<!--
- シラバスとは詳細な授業計画。9割以上が作成するも、準備学習の具体的指示は当時約半数。現在は「学生との契約」とされる。
-->

# <span style="color:var(--accent-dark)">1．</span>シラバスの位置づけ

<div class="subhead" style="margin:2px 0 6px;"><span class="tag tag-soft">方策</span><span>シラバス作成に当たっての改善方策</span></div>

<div class="box-accent" style="margin-top:2px; padding:8px 22px; margin-right:calc(var(--pip-w) + 40px);">シラバスに関しては、国際的に通用するものとなるよう、以下の点に留意する</div>

<div class="exrow" style="margin:6px 0; padding:6px 18px;"><div class="exn">①</div><div>各科目の<b>到達目標</b>や学生の<b>学修内容</b>を明確に記述すること</div></div>
<div class="exrow" style="margin:6px 0; padding:6px 18px;"><div class="exn">②</div><div><b>準備学習</b>の内容を具体的に指示すること</div></div>
<div class="exrow" style="margin:6px 0; padding:6px 18px;"><div class="exn">③</div><div><b>成績評価の方法・基準</b>を明示すること</div></div>
<div class="exrow" style="margin:6px 0; padding:6px 18px;"><div class="exn">④</div><div>シラバスの実態が、<b>授業内容の概要を総覧する資料（コース・カタログ）と同等のものにとどまらないようにする</b>こと</div></div>

<div class="cite" style="margin-top:3px;">（中央教育審議会，2008，「学士課程教育の構築に向けて（答申）」）</div>

<div class="box-warn" style="margin-top:5px; padding:8px 22px; font-size:21px; margin-right:calc(var(--pip-w) + 40px);">「こんなことやります」、「あんなことやります」だけでは条件を満たさない<br><b>目的・目標、その達成のためにどのような学習が必要か、どのように学習が評価されるかを明示する</b>必要</div>

<!--
- 改善方策：到達目標・学修内容、準備学習、評価方法・基準を明示し、コース・カタログ同等にとどめない。「やります」列挙だけでは不十分。
-->

# <span style="color:var(--accent-dark)">1．</span>シラバスの位置づけ

<div class="subhead"><span class="tag tag-soft">コツ</span><span>シラバス作成のコツ</span></div>

<div class="stepbox" style="margin-top:10px;">
<div class="st">多くの大学で、シラバスの<b>「様式」</b>が定められている</div>
<div class="st">「様式」に、<b>遺漏なく詳細に計画を記載</b>すれば、条件を満たせる可能性は高まる</div>
<div class="st">さらに、<b>シラバスチェック</b>（大学内での相互点検等）で指摘があれば、その点を直すことで、さらに条件を満たせる可能性が高まる</div>
</div>

<div class="box-accent" style="margin-top:16px; margin-right:calc(var(--pip-w) + 40px);">すべてイチから覚悟して準備しなくても、<b>「様式」を活用すること</b>が大事<br>若手も、中堅も、ベテランも、奇をてらったり歌舞いたりしようとせず、<b>様式をふまえて淡々とこなすこと</b>がむしろ大事</div>

<div class="attrib">大学院共通教育「大学などで教える」（担当：松本暢平）</div>

<!--
- 作成のコツ：多くの大学に「様式」がある。遺漏なく記載し、シラバスチェックの指摘を直す。イチからでなく様式を活用し淡々とこなすことが大事。
-->
