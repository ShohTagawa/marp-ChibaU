<div class="page-title">変更案</div>

# 設置上の<span style="color:var(--accent-dark)">最小カリキュラム</span>を定める

<div class="box-accent" style="font-size:21px; padding:8px 22px;"><b>今後開設される副専攻について、設置上の最小要件を設定したい</b>。また、その最小要件でも、<b>千葉大の副専攻の趣旨を満たすか確認する</b></div>

<div class="goal-box" style="font-size:23px; margin:10px 0; padding:8px 24px;"><b>変更案 ：</b> <b>1</b>、<b>2</b>の両方を設置上の最小カリキュラムとする</div>

<div class="stepbox" style="margin:8px 0; padding:8px 24px;">
<div class="st" style="font-size:22px; line-height:1.4; margin:2px 0;"><b>1.</b>「専攻分野以外の幅広い知見」を得る機会の実質化のため、副専攻設置要件に、「修了に要する最小単位数」を盛り込む。</div>
<div class="st" style="font-size:20px; line-height:1.4; margin:2px 0; margin-left:1.6em;"><b>現行</b>：指定科目から30単位 (専攻を問わない)</div>
<div class="st" style="font-size:20px; line-height:1.4; margin:2px 0; margin-left:1.6em;"><b>案</b>：<b>「他学部開講科目」と「普遍教育科目(必修を除く)」から16単位以上を要件</b>とする(但し、副専攻カリキュラムを16単位以上とすることや、主専攻での必修科目を設けることを<b>妨げない</b>。)</div>
</div>

<div class="stepbox" style="margin:8px 0; padding:8px 24px;">
<div class="st" style="font-size:22px; line-height:1.4; margin:2px 0;"><b>2.</b>「副専攻分野の体系的な能力や素養の獲得」の実現のため、必修科目(導入科目と総括科目)の指定を設ける。</div>
<div class="st" style="font-size:20px; line-height:1.4; margin:2px 0; margin-left:1.6em;">必修科目１：副専攻の主題の体系的な俯瞰のための導入科目 (1～2単位程度)</div>
<div class="st" style="font-size:20px; line-height:1.4; margin:2px 0; margin-left:1.6em;">必修科目２：副専攻の主題への学びを応用・転移する総括科目 (2単位程度)</div>
</div>

<!--
- 変更案は2点。1=最小単位数（他学部+普遍から16単位以上）の導入。2=必修の導入科目・総括科目の指定。
-->

# 「千葉大の副専攻」の<span style="color:var(--accent-dark)">最小単位数</span>

<div class="subhead" style="margin-top:14px;"><span class="tag tag-soft">上限</span><span>CAP制の考え方に基づく、主専攻カリキュラムの確認</span></div>

# 16単位で「副専攻」と呼べるか

<div class="subhead"><span class="tag tag-accent">確認</span><span>16単位で「副専攻」と呼んでも問題ないか</span></div>

<div class="box-info" style="font-size:21px;"><b>国内</b>：10単位程度の副専攻プログラムが存在(例：福井大)、<br>　　　国内副専攻制度の論文でも16単位が妥当との結論 (田中 2011)</div>

<div class="box-info" style="font-size:21px; margin-top:8px;"><b>海外</b>：UCB等のマイナーでも、18単位程度のものが存在</div>
