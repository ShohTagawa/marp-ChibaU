<div class="bgroup">

<div class="bg-items">

<div class="page-title">学習意欲の第一原理</div>

# 学習意欲の第一原理 <span class="tag tag-ref">参考</span>

<div class="goal-box" style="font-size:24px; line-height:1.6; padding:16px 28px; margin:14px 0;">
学習への意欲は、次のときに増進される。<br>
1. 学修者の好奇心が現在の知識のなかのギャップを知覚して刺激されたとき<br>
2. 学ぶべき知識が学修者のゴールへ有意義に関連があると気づいたとき<br>
3. 学修者が学習課題をマスターすることに成功できると思うとき<br>
4. 学修者が学習課題に満足な結果を予想し経験するとき<br>
更に、<br>
5. 学修者が彼らの意図を保護するために意志（自己調整）の方略を使うとき、　増進され、かつ、維持される。
</div>

# より良い勉強法 <span class="tag tag-ref">参考</span>

<div style="font-size:20px; color:#555; margin:2px 0 8px;">ダンロスキーらのレビューを基にした、科学的根拠に基づく最高の勉強法より</div>

<div class="box-warn" style="margin:6px 0; font-size:22px;"><b>記憶に意味がない</b>学習法 (スキル向上は別)：<br>再読、ハイライト、単に書き写す・まとめる</div>

<div class="box-accent" style="margin:8px 0; font-size:22px; line-height:1.55;"><b>記憶に意味がある学習法</b>：<br>
<b>アクティブリコール (レトリーブ)</b> (思い出す・白紙に書き出す)<br>
<b>分散学習</b> (一気に全部ではなく、何回も復習)<br>
<b>精緻的質問・自己説明</b> (Why?How?と自分にといかけ自分の言葉で説明)<br>
<b>インターリービング</b> (近いが異なる学び・スキルを挟んで学習)</div>

<div style="font-size:21px; color:#444; margin-top:8px;">「学びて時にこれを習ふ、亦た説ばしからずや」<br>学んだことを、時に応じて反復し、理解を深める、これもまた楽しいことではないか。<span style="color:#888;">出典：デジタル大辞泉（小学館）</span></div>

<div class="cite pip-safe">安川 科学的根拠に基づく最高の勉強法 (2024)</div>

<!--
- より良い勉強法。再読やハイライトは記憶には効果が薄い。アクティブリコール、分散学習、精緻的質問・自己説明、インターリービングが科学的根拠に基づく勉強法。
