# (補足) 評価に関わる対策集 / 阪大FD (2024)

<div class="cite" style="margin-top:0;">浦田・長岡・村上 (2024) <i>情報処理</i></div>

<div style="display:grid; grid-template-columns:1fr 1fr; gap:10px 14px; margin-top:6px;">

<div class="box-warn" style="font-size:17px; line-height:1.4; font-weight:400; color:#3a2300;">
<b style="color:#C0182B;">問題作成と試験の形式：</b><br>
<b>最新の出来事</b>や資料を扱うテーマを設定する／事前に生成AIで試験問題を解いてみて、解けた場合は別の問題を検討する／<b>授業内で</b>ディスカッションした内容を書かせる／短いライティング課題を頻繁に課す／口頭試験にする／長い文章を要約させる／インタビュー、コンセプトマップ、動画、ディベートなど、レポート形式以外の課題にする／オンライン試験では、問題文は（コピペしにくいように）画像にする／音声と映像を組み合わせた動画で出題する／モラルに反する質問やプログラミングに反する質問への回答を求める
</div>

<div class="box-info" style="font-size:17px; line-height:1.4;">
<b>評価とフィードバック：</b><br>
ピアや教員との対面ミーティングを組み合わせて段階的に評価する／生成AIで作成した成果物ではないという内容に署名させる／生成AIを利用していない時に学生が書いた文章と提出されたものを比較する／引用を多用する課題を課す／学生が引用した文献を抜き打ちで実在するかチェックする（ことを伝える）／対面または同期型で指導する成果についてのプレゼン課題でQ&amp;Aも行う／手書きか口頭で、学んだことのリフレクションを提出させる／ピア評価を取り入れて建設的なフィードバックができる能力を評価する／生成AIに書かせた文章を批評させる引用文献には文献データベースへのリンクを付けさせる
</div>

<div class="box-accent" style="font-size:17px; line-height:1.4;">
<b>課題の提出：</b><br>
注釈を付けることを課す／課題を作成する過程についての考察を課す／手書きのレポート課題にする／レポートのテーマと自分の個人的な経験を統合する課題にする／レポートの執筆プロセス（下書きや参考文献、編集履歴等）も提出させて評価対象にする／引用文献のスクリーンショットの提出を課す
</div>

<div class="box-info pip-safe" style="font-size:17px; line-height:1.4;">
<b>方針の明示と周知：</b><br>
試験で使用を許可する・許可しないツールを明記する／出力の不正確さ、偏り、論理や文体の問題の例を学生に示して注意を促す／剽窃チェックツールが存在し、進化していることを学生に伝える／AIの利用に関する方針をシラバスに明記する／学問的誠実性を強調し、不正行為の結果を理解させる／書くプロセスが学びになぜ大切かを伝える／内発的動機づけを促す<br>
<span style="font-size:16px; color:#777;">(科目によっては、あまり意味がない場合があると考えられる点)</span>
</div>

# 参考：課題中心型の授業設計

<div class="box-warn" style="font-weight:400; color:#3a2300;"><b style="color:#C0182B;">✗問題解決型</b>：現実の解決する形で設定するが、どのような学びや学問を使用するかは、明確にデザインされていない (スキル獲得を目指すもの)。</div>

<div class="box-accent" style="margin-top:8px;"><b>◯課題中心型</b>：現実に起きそうな問題を、教員が小問 (道しるべ) や試行錯誤、ワークなど、使用する概念や獲得される学びを把握して、学習課程を設計する。</div>

<div class="stepbox pip-safe" style="margin-top:12px;">
<div style="font-weight:800; color:var(--accent-dark); font-size:24px; margin-bottom:4px;">方法</div>
<div style="font-size:21px; line-height:1.5;">
①新しい全体的なタスクを見せる<br>
②タスクに必要な構成要素を提示する<br>
③タスクに関する構成要素を演示する<br>
④もう一つ新しい全体タスクを見せる<br>
⑤学修者に、既習の構成要素を新タスクに応用させる<br>
⑥この新タスクに必要となる追加的な構成要素を提示する　<span style="color:#777;">補足：追加部分は、AIに支援させるなども可能</span><br>
⑦これらの追加的な構成要素を演示する<br>
⑧ステップ4~7を続くステップにも繰り返す
</div>
</div>

<div class="cite">ブランチ・メリル (2013)</div>

# 参考：最近接発達領域

<div style="display:flex; gap:22px; align-items:flex-start;">
<div style="flex:0 0 470px;">
<img src="./src/fig24-zpd-venn.png" alt="最近接発達領域のベン図：自力で出来る／援助があれば出来る／援助があっても出来ない" style="width:100%;">
<div class="cite">Vygotsky (1978)</div>
</div>
<div style="flex:1;">

<div class="box-accent" style="font-size:22px;"><b>足場かけ (Scaffolding)：</b>他者の援助や協同で出来る状態にする</div>
<div style="font-size:21px; margin:6px 0 0 8px;">最近接発達領域を広げたり、身につけたりする内容</div>

<div class="box-info" style="font-size:22px; margin-top:10px;"><b>足場外し (Fading)：</b>他者の援助や協同を徐々に減らし独り立ち</div>
<div style="font-size:21px; margin:6px 0 0 8px;">自力出来るようになる内容</div>

<div class="box-warn" style="margin-top:10px; text-align:center;"><b>受講前は自力でできないが、課題を解いたら自力で出来るようになる</b></div>

</div>
</div>

<div class="box-accent pip-safe" style="text-align:center; font-weight:800; margin-top:12px;">生成AIの活用を前提とすれば、よい本質的な課題に取り組む設計が出来る？</div>
