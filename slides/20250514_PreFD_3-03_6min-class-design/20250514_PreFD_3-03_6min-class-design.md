# <span style="color:var(--accent-dark)">クラスの外</span>も充実させる　<span class="tag tag-ref">参照</span>

<div class="box-accent" style="margin-top:6px;">

　<b>課題や課外活動などについても同時に</b>デザインする
<div class="box-warn" style="font-size:20px; margin-top:8px; padding:6px 14px;">※学部：<b>１単位＝４５時間の学修</b> (大学設置基準第二十一条)　→<b>30時間のクラス外活動が標準</b></div>
</div>

<div style="font-size:25px; margin-top:12px; line-height:1.5;">
✔シラバス時に設計した大規模課題などは、<b>授業との関連性</b>を考える
<div style="font-size:22px; margin-left:1.3em; color:#333;">- 事前知識や課題の狙いを説明したか？　- 例の提示や補足説明は不要か？</div>
</div>

</div>

<div class="box-warn" style="margin-top:12px; margin-right:calc(var(--pip-w) + 16px);"><b>確実なフィードバック</b>と<b>課題にかかる時間</b>に留意</div>

# <span style="color:var(--accent-dark)">6分間クラスデザイン</span>　<span class="tag tag-design">設計</span><span class="tag tag-ref">参照</span>

<div class="subhead"><span style="font-size:28px;"><b>1つのトピックを説明する6分間をデザインする</b></span></div>

<div class="box-info" style="font-size:22px; margin-top:2px;">
※普段は<b>パワーポイントのアウトライン作成</b>が同じ作業／通常はクラスレベルでデザインすればOK
</div>

<div class="stepbox" style="margin-top:12px; margin-right:calc(var(--pip-w) - 90px);">
<div style="font-size:24px; font-weight:800; color:var(--accent-dark); margin-bottom:4px;">確認</div>
<div style="font-size:22px; line-height:1.55;">
①レベルは、学部初級(普遍教育か2年次のイントロ科目)<br>
②導入 – 展開 – まとめの構成で作る<br>
③簡易<b>ワーク</b>をいれ、主体的に学べる仕掛け作りを。<span style="color:#555;"> (Think pair shareや問いかけは2分程度)</span><br>
④スライドまたは板書で実施<br>
⑤必要に応じて、<b>Google Formsなど使用可</b><br>
⑥<b>詰め込み過ぎない </b>(内容の飛躍も注意)<br>
⑦興味・関心をひくか　⑧内容は目標と合っているか
</div>
</div>

<div class="box-warn" style="margin-top:10px; margin-right:calc(var(--pip-w) + 16px);"><b>無駄を削いだら、6分 - 1コンセプト</b>を実感しよう</div>
