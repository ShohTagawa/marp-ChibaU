## slide 47
  • 　参考：もっと高度な出力
  • ‹#›
  • **Structured Output（構造化出力）**
  • **定義:** LLMの出力を、事前に定義されたJSONスキーマなどの構造に沿って生成する技術。
  • **利点:**
  • 予測可能な出力形式で後続処理を容易に
  • スキーマに合致しない誤ったデータを自動で拒否
  • プロンプトを簡潔にし、LLMへの指示を削減
  • **簡単な例:** ユーザー情報抽出のためのJSONスキーマ
  • {  "type": "object",  "properties": {    "name": { "type": "string" },    "email": { "type": "string", "format": "email" },    "age": { "type": "integer" }  },  "required": ["name", "email"]}
  • **Function Calling（関数呼び出し）**
  • **定義:** LLMがユーザーの意図を解釈し、外部ツール（API）を呼び出し特定のアクションを実行する機能。
  • **用途:**
  • レストラン予約やオンラインショッピングの注文処理
  • カレンダー管理など外部アプリとの連携
  • データ検索やアクション実行の自動化
  • **簡単な例:** レストラン予約のための関数呼び出し
  • tool_code: bookRestaurant(restaurant_name: string, date: string, time: string, party_size: integer, special_requests: string)tool_name: レストラン予約tool_description: 指定されたレストランの予約を行います。arguments:  restaurant_name: 必須の文字列引数。予約したいレストランの名前。  date: 必須の文字列引数。予約希望日 (YYYY-MM-DD)。  time: 必須の文字列引数。予約希望時刻 (HH:MM)。  party_size: 必須の整数引数。予約人数。  special_requests: オプションの文字列引数。特別な要望やアレルギー情報。
