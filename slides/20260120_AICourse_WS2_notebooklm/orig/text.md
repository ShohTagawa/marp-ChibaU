  [TABLE]
    | テクニック | 内容・方法 | 効果 | 主な理由 |
    | 実力テスト | フラッシュカードや練習問題などを使い、自分の記憶から情報を引き出すテストを行う。 | 高 | 学習効果が高く、幅広い教材・年齢層に有効。フィードバックがあると効果的。 |
    | 分散学習 | 一気に学習せず、学習スケジュールを分散させる。 | 高 | 長期的な記憶保持に有効。一夜漬けよりも遥かに効率が良い。 |
    | 精緻化的質問 | 「なぜその事実が成り立つのか？」という質問を自分に投げかけ、説明を考える。 | 中 | 事実の学習に有効だが、ある程度の予備知識が必要。 |
    | 自己説明 | 学習のプロセスや、新しい情報が既知の情報とどう関連するかを自分自身に説明する。 | 中 | 数学や論理的思考を要する問題解決に有効だが、時間がかかる。 |
    | 交互練習 | 1つの種類の問題をまとめて解くのではなく、異なる種類の問題を混ぜて練習する。 | 中 | 数学などで劇的な効果がある（区別がつかなくなるのを防ぐ）。 ※ 全ての教科での効果は未検証。 |
    | 要約 | 学習したテキストの要点をまとめ短い文章にする。 | 低 | 時間がかかるわりに、要約スキルの形成を除き効果が薄い。 |
    | ハイライト | 重要な部分に線を引いたり、色を塗ったりする。 | 低 | 読むだけより効果が薄くなりがちで、推論能力を阻害しうる。 |
    | キーワード法 | 発音が似たキーワードにイメージを結びつける。 | 低 | 適用できる教材が限られ（語呂合わせなど）、長期記憶しにくい。 |
    | テキストのイメージ化 | 読んでいる内容を頭の中で映像化する。 | 低 | 視覚化しやすい教材に限られ、効果が一貫しない。 |
    | 再読 | テキストやノートを繰り返し読む。 | 低 | 最も一般的だが、時間対効果が低く、深い理解につながらない。 |
  • ※個人差はあります。
  ┌ text box:
