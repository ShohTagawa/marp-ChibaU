# <span style="color:var(--accent-dark)">情報</span>と<span style="color:var(--accent-dark)">技術</span>を使いこなす能力を身につけよう

<div class="lead-note"><b>情報</b>は、 <b>技術だけではない</b>です。<b>新聞</b>も、<b>スパイ映画</b>も、<b>本</b>も、<b>データ</b>も情報。</div>

<div class="box-accent" style="margin-top:10px;">
<b>情報</b>は、 <b>つねに人と物事を結びつける。</b><br>
より効果的な情報テクノロジーを作り出せば、必ず世の中をより忠実に理解できるようになると考える、素朴な見方は間違っている。 ーーユバル・ノア・ハラリ『Nexus』
</div>

<div class="goal-box" style="margin-top:18px; text-align:center; margin-right:calc(var(--pip-w) + 40px);"><b>情報と技術を使いこなす能力を身につけよう</b></div>

<div style="font-size:22px; text-align:center; color:#555; margin-top:10px; margin-right:calc(var(--pip-w) + 40px);">講義と実践の両方を通して、 大学生に求められる情報リテラシーと データサイエンス・AIの基礎を俯瞰的に学びます。</div>

<div class="careercol" style="margin-top:6px;">

# <span style="color:var(--accent-dark)">授業に参加するにあたって</span>

<div class="stepbox" style="margin:8px 0;">
<div class="ch" style="font-size:22px; color:var(--accent-dark); font-weight:800;">授業の基本ルール</div>
<div style="font-size:20px; line-height:1.5;">• オンデマンド授業（メディア授業）の際は教室に来る必要はありません。<br>• 成績の付け方は、クラスによって異なる場合があるので注意してください。</div>
</div>

<div class="stepbox" style="margin:8px 0;">
<div class="ch" style="font-size:22px; color:var(--accent-dark); font-weight:800;">学習時間の目安</div>
<div style="font-size:20px; line-height:1.5;">• 1単位 = 45時間の学習が必要です。(授業： 1.5時間×8分しかカバーしないことに注意！)<br>• (本来は)授業時間の倍程度の時間を使い、授業外で学ぶこと（本を読む、試す等）が求められます。<br>• 提示されるワークや教材は、採点対象外であってもぜひ試してみてください。</div>
</div>

<div class="stepbox" style="margin:8px 0; margin-right:calc(var(--pip-w) + 20px);">
<div class="ch" style="font-size:22px; color:var(--accent-dark); font-weight:800;">ワークへの取り組みと姿勢</div>
<div style="font-size:20px; line-height:1.5;">• <b>協力的な学びの場</b>をみんなで作りましょう。敬意を持って、忌憚なく建設的に取り組みましょう。<br>• 「やってはいけないこと」と「やるべきこと」にはギャップがあります。自由に試行錯誤してみましょう！</div>
</div>

# <span style="color:var(--accent-dark)">実践・協働・思考を大切に</span>

<div class="stepbox" style="margin:8px 0;">
<div class="ch" style="font-size:22px; color:var(--accent-dark); font-weight:800;">自分の手で試す</div>
<div style="font-size:20px; line-height:1.5;">• 習ったことを試し、具体例を使ってみる。自分の手で試すことが非常に大切です。模写でもOK!<br>• 結果がでたら、一歩立ち止まって、考えてみましょう。</div>
</div>

<div class="stepbox" style="margin:8px 0;">
<div class="ch" style="font-size:22px; color:var(--accent-dark); font-weight:800;">協働して解決する</div>
<div style="font-size:20px; line-height:1.5;">• 困ったことは友人と相談して解決しましょう。公式AI（Gemini等）や教員にも積極的に質問を。<br>• Moodleに質問を書き込み、分かる友達が解決する「教え合いの環境」を作りましょう。</div>
</div>

<div class="stepbox" style="margin:8px 0; margin-right:calc(var(--pip-w) + 20px);">
<div class="ch" style="font-size:22px; color:var(--accent-dark); font-weight:800;">「なぜ」を考える</div>
<div style="font-size:20px; line-height:1.5;">• 「なぜそのような考え方をする必要があるのか」「なぜその機能があるのか」を説明できるように。<br>• 他の人の視点に立って、考えられる力を持ちましょう。</div>
</div>
