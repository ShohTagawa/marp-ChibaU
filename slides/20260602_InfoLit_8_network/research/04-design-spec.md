## 0. いま起きている問題（現状診断）

- **SVG内テキストが小さすぎる**: 14px未満が **138箇所**（11px×35、12px×44、13px×13px×59）。スクリーン投影でなく動画の小さいプレイヤーで見るため、致命的。**全件14px以上へ**。
- **viewBoxとSVGテキストの単位ズレ**: 多くのSVGが `viewBox="0 0 900 230"` を `width:100%`（実描画 約840px幅）で表示。viewBox単位の `font-size="13"` は実画面で約12.1pxに縮む。**実効サイズ = 指定値 × (実描画幅 / viewBox幅)** を意識し、viewBox幅900級では最低 `font-size="16"`、360級（split左）では最低 `font-size="14"` を基準にする（後述「実効px換算表」）。
- **図ごとに色の意味がバラバラ**: 同じ青(#3E78B2)が「LAN」「クライアント」「アプリ層」「正の相関」に流用され、色＝意味の対応が崩れている。色トークンを役割で固定する。
- **線幅・角丸・影が無秩序**: stroke-width が 2 / 2.5 / 3 / 4 / 6 と混在、角丸 rx も 4〜10 がバラバラ、影は皆無で図が平板。
- **スカスカ感**: テキストが少ない `fig` スライドで図が中央に小さく浮く。テキスト追加ではなく「図の拡大・余白設計・キャプション帯」で埋める。

## 1. SVGデザイントークン標準（再利用の核）

### 1.1 カラートークン（役割固定 — 色の意味を1講義で統一）

| トークン | 値 | 役割（この用途以外に使わない） |
|---|---|---|
| `accent` 赤 | `#A6192E` | 主役・あなたの端末・宛先・結論・最短経路・暗号文 |
| `accent-dark` | `#7d1322` | 赤の濃い版（ビット背景文字など） |
| `accent-soft` | `#F8E5EA` | 赤系の淡い面・Internet雲・暗号文ボックス |
| blue | `#3E78B2` | LAN／ネットワーク部／クライアント／受信側ACK |
| blue-soft | `#eef4fa` | 上記の淡面 |
| green | `#3C8A57` | 正常系・無線/Wi-Fi・送信成功・平文・公開鍵 |
| green-soft | `#eef7ef` / `#DDEBC8` | 上記の淡面 |
| orange | `#D98A2B` | WAN・モバイル・ホスト部・レスポンス・注意/外れ値 |
| orange-soft | `#fdf3e8` / `#FCE3C7` | 上記の淡面 |
| gray | `#6B6F76` | 装置/物理層・サーバ筐体・中立 |
| line-weak | `#cccccc` | 接続線（意味を持たない配線） |
| ink | `#1a1a1a` / `#555` | 本文／補足 |

→ 各章扉に「この章で青は○○、緑は○○」の意味は持ち込まず、**講義全体で固定**。学生が色だけで層・部位を追えるようにする。

### 1.2 フォント階層（SVG内・実効pxで設計）

viewBox幅で2系統に分け、**指定値**を以下で統一（実効pxは§1.3）。

| 役割 | viewBox≈900（fig全幅） | viewBox≈360（split左半） | 用途 |
|---|---|---|---|
| 図中見出し | `20` | `17` | 図のサブタイトル |
| 主要ラベル | `17`〜`18` | `15`〜`16` | ボックス名・主役の語 |
| 副ラベル/補足 | `15`〜`16` | `14` | カッコ書き・単位・注記 |
| **下限** | **`15`（≈14px実効）** | **`14`（≈13.7px実効）** | これ未満禁止 |
| 数字の主役（IP/ビット） | `30`〜`36` | — | 手計算の見せ場 |
| 矢印見出し（→の語） | `15` | `14` | リクエスト/暗号化など |

絵文字（🔒🔑🛰）は装飾。意味を担う箇所はテキスト併記必須。

### 1.3 実効px換算表（チェック用の早見）

実効px = `font-size × (約840 / viewBox幅)`。13px厳守の境界値:

| viewBox幅 | ×係数 | 14px実効に必要な指定値 |
|---|---|---|
| 360（split左SVG, 実描画≈400px） | ≈1.11 | **13以上**でOK（13→14.4px） |
| 420（grid2内SVG） | ≈1.0 | **14以上** |
| 760〜900（fig全幅, 実描画≈840px） | ≈0.93 | **15以上**（14だと13.0pxで境界→15推奨） |
| 920〜980 | ≈0.88 | **16以上** |

**運用ルール**: 全SVGの `font-size` を「viewBox900級→16、420級→14、360級→14」へ一括底上げ。13px指定が残ってよいのは viewBox≤420 のみ。

### 1.4 線・角丸・影・矢印（形のトークン）

| 項目 | 標準値 | 例外 |
|---|---|---|
| 主要ボックス枠線 | `stroke-width="2"` | 主役強調は `2.5` |
| 接続線（中立） | `1.5`〜`2`、色 `#ccc` | — |
| データフロー矢印 | `2.5` | — |
| 強調経路（最短路など） | `3.5`（現状4→統一） | — |
| 角丸 rx | ボックス`8` / 小タグ`6` / 帯`6` | 大カード`10` |
| 影（新規導入） | `filter: drop-shadow(0 2px 3px rgba(0,0,0,.12))` を主要カードに | 雲・帯は無し |
| 矢印マーカー | 共通 `markerWidth/Height=8 refX=6 refY=3`、`path M0,0 L6,3 L0,6 Z` | 色はフロー色に一致 |

→ 影は `<style>` に `svg .card { filter: drop-shadow(0 2px 3px rgba(0,0,0,.12)); }` を1本追加し、カードrectに `class="card"` を付けるだけで全図に効かせる（個別指定を避ける）。

## 2. 再利用SVGパーツ指針（“部品で組む”）

`<style>` 内にSVG用ユーティリティを定義し、各図で使い回す。新規パーツは作らず以下に寄せる。

- **ノードカード** `rect rx=8 stroke-width=2 + class="card"（影）`: 端末・ルータ・サーバ・DNS等。主役は赤枠、装置は gray枠。
- **Internet雲**: `ellipse rx≈60 fill=accent-soft stroke=accent`。常に同じ見た目で「外の世界」を表す（旅の終点/始点の目印）。
- **電波**: green の `path q`カーブ3本（AP/Wi-Fi）、orange3本（モバイル基地局）。色で有線/無線/モバイルを区別。
- **ビットセル**: `rect 8bit + 等幅monoテキスト`。IP・パリティで再利用。背景 accent-soft、文字 accent-dark。
- **矢印（フロー）**: §1.4のマーカー定義を `<defs>` に1セットだけ置き全図で `url(#arrow-grn)` 等を共有（現状 a1/pa/d1… と毎回再定義 → IDを `arrow-{red|grn|blue|org}` に統一）。
- **層スタック**: 4段 `rect` 縦積み（TCP/IP・カプセル化・IaaS/PaaS/SaaS で共通の見た目）。各層の色は§1.1固定（アプリ=blue, トランスポート=green, IP=orange, 物理=gray）。
- **旅プログレスバー**: 各 `fig` スライド上部に「端末→Wi-Fi→DNS→Internet→サーバ→表示」の6点バーを小さく置き、**今どこの話か**を点灯（現在地を赤）。表紙P2の地図図を縮小再利用 → ストーリーの背骨になる。

## 4. スライドあたり情報量ガイド（オンデマンド＝1スライド1メッセージ）

| パターン | 主役 | テキスト上限の目安 | スカスカ対策 |
|---|---|---|---|
| `fig` | 図1点 | h2(1文)＋caption(1〜2文)＋takeaway/ask 1個 | 図を `max-height:340px`まで拡大、左右に余白20px、captionは赤帯`band`で1本通す |
| `split` | 左図＋右box | 右は cbox 最大2個（各箇条3行以内） | 左図を縦いっぱい、boxは2個で打ち止め。3個になりそうなら2枚に割る |
| `divider` | 章タイトル | num＋h1＋h2(繋ぎ文1行) | そのまま |
| ワーク | 手順4つ＋スクショ枠 | 箇条4行 | 現状維持（プレースホルダで右半分が埋まる） |

- **1スライド＝1つの問い/1つの図**。「Wi-Fi規格表」と「モバイル世代表」のように表が2つ並ぶ箇所は、片方を主役にしてもう片方を補足サイズに。
- 文字を増やさず、**captionを赤帯(`.band`)化**・**figの下に1行takeaway**で“締まり”を出す。
- `ask`（黄）と `important`（赤タグ）は1スライド各1個まで（多用で価値が薄れる）。

## 6. 一括適用の実務手順（推奨）

1. `<style>` に SVGユーティリティ追加: `.card{filter:drop-shadow(...)}`、共通矢印マーカー、`svg text`の既定`font-size`を底上げ。
2. viewBox幅で grep し `font-size="11|12|13"` を機械的に置換（≤420は14、≥760は16）。138箇所。
3. 色を§1.1の役割表で監査（青の誤用を是正）。
4. 各 fig に旅プログレスバー(§2)を載せ、現在地を点灯。
5. 出力確認: `npx @marp-team/marp-cli@latest "$DECK/<deck>.md" --theme-set theme/academic.css --pdf --allow-local-files -o "$DECK/out/<deck>.pdf"` で実寸チェック。
