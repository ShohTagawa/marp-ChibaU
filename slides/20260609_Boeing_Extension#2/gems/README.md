## 0. この設計書の使い方（教員向け）

各設計書は次の構成です。**「② 設定プロンプト」をそのままGeminiにコピペ**すればGemが完成します。

1. 基本情報（名前・アイコン・使う場面）
2. **設定プロンプト（Instructions）** ← コピペ用・ここが本体
3. 会話の始め方（Conversation starters）
4. 使用例（学生に見せる見本対話）
5. 運用メモ・注意点

---

## 1. Gem の作り方（学生にそのまま渡せる手順）

> Gemini の「Gem」＝あらかじめ役割を仕込んだ自分専用チャット。一度作れば使い回せます。

1. [gemini.google.com](https://gemini.google.com) を開く（**大学Googleアカウント**でログイン）
2. 左メニュー → **「Gem マネージャー」→「新しい Gem」**
3. **名前**を入力（例：`壁打ちGem`）
4. **手順（Instructions）** の欄に、設計書の「② 設定プロンプト」を**まるごと貼り付け**
5. （任意）**会話の始め方**を設計書からコピーして登録
6. **「保存」** → 一覧に出たGemを選べばすぐ使える

スマホは Gemini アプリでも同じ手順。**PCの方が貼り付けが速い**ので推奨。

## 2. 配布方法（2通り・どちらか選ぶ）

### A. 学生が各自で作る（推奨・全員がプロンプトを理解できる）
- Classroom に2本のプロンプトを掲示 → 学生が上記手順で自作
- 利点：プロンプトの中身（＝AIへの指示の書き方）自体が学びになる
- 当日は**WORK直前の1分アイスブレイク中**に作らせると流れがスムーズ

### B. 教員が作って共有リンクで配る（速い・全員同一設定）
- 教員が2つのGemを作成 → **各Gemの「共有」からリンクを発行** → Classroom に掲示
- 利点：設定ミスがない・即使える／注意：Workspace設定で共有可否を要確認
- ※共有Gemは**閲覧者が自分のコピーとして使う**形になる（会話は各自に閉じる）

> **おすすめ運用**：教員が共有リンク（B）を主、プロンプト全文（A）も併載。
> 「リンクですぐ使ってOK／中身を知りたい人はプロンプトも読んでみて」と案内。

## 4. 学生に必ず伝える「3つの約束」（両Gem共通）

1. **AIは答えではなく“壁打ち相手”** ── 出てきた案は素材。採否は必ず自分たちで決める
2. **個人情報・未公開情報を入れない** ── 実在の特定個人や機微情報は書かない（ペルソナは“架空の人物像”で）
3. **鵜呑みにしない** ── AIの発言は事実確認していない。気になったら自分で調べ直す
