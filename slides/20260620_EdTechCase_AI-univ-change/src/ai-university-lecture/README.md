# AI時代に大学はどう変わる？ — 講義制作プロジェクト

教育テック大学院大学「教育テック事例研究（Ⅰ）」内、講義①「AI時代に大学はどう変わる？」の
**前半パート（登壇者：田川翔／千葉大学 国際未来教育基幹）** を制作するプロジェクト。

このREADMEは、Claude Code が文脈を引き継いで作業を続けるための入口。

## このプロジェクトは何か

- **アウトプット**：前半30分の講義スライド＋話し言葉の原稿＋ワーク①の設計。
- **聴衆**：教育テック大学院大学の院生・社会人（教育×テクノロジーに関心、リテラシー高め）。
- **持ち時間**：前半講義30分＋ワーク①（別枠）。後半は別の登壇者（橋口剛先生＝民間AI最前線）が担当し、最後にワーク②（小規模大学の3年再建ケース）がある。ワーク②は田川は担当しないが、ワーク①がワーク②へ接続するよう設計済み。

## 講義の主張（背骨）

> **そもそも学ぶとは「情報の移動」ではなく「人の変容」である。**
> 自分一人でできること（知識の獲得）はAIに外部化できる。
> 大学に残る本質は「AIと自分だけでは絶対にできないこと」＝ともに考える共同体。
> ゆえに「知識授受からコミュニティへ」。AIは従属変数である。
> 効率化・最適化を自明の善とせず、本質に集中するために本質でないものを手放す。

この主張は、対話を重ねて到達したもの。理論的支柱はティム・インゴルド『教育とは何か』
（「強い教育／弱い教育」、四つの柱＝自由・信頼・教育・共同体）とレイヴ＆ウェンガーの
実践共同体論。ミネルバ大学を「同期/非同期 × 大学でできること/自分でできること」で
大学を再配置した極論モデルとして扱う。

## 引用・事実確認の注意（厳守）

- 数値・固有事実には出典を付す。検証済みのもののみ断定。未確認は「とされる」と留保。
- **要一次確認**：①ミネルバの「全授業が例外なく完全反転/同期双方向か」とForumの個別UI仕様、
  ②各種AI認知研究は査読前プレプリント（Kosmyna 2025 等）。報道の派生数値（「結合性55%減」等）は
  一次論文の表現に置き換える。
- 「学ぶとは人の変容」「4つの像（変容・関係・問い・不確かさ）」は、この対話で構築した
  **田川独自のフレーム**であり特定文献の直接引用ではない。スライドでも独自整理として提示する。
- 主要数値の出典：生成AI実態調査＝大学教育学会 課題研究（2025年9-10月実施、有効回答113機関、
  2026年5月公開）。実質化の困難85.8%／業務効率化への期待94.6%／思考力低下リスク 肯定47.3%・中立46.4%。
