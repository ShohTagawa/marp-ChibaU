<div class="page-title">ギャップについて</div>

# <span style="color:var(--accent-dark)">ギャップ</span>について

<div style="margin-top:4px;">

<div class="stepbox"><div class="st"><b>学生 - 教員間のギャップとして目立つ点は、比較的少ない</b></div>
<div style="font-size:21px; margin:2px 0 0 1.2em; line-height:1.5;">○ 学生は、AIの影響にポジティブだが同時に不安や意見を抱えている<br>○ 教員は、学生の使用事例・頻度について、驚いている発言も一定数ある</div>
</div>

<div class="stepbox"><div class="st"><b>「現状」と「理想」の間の課題感としてのギャップが目立つ</b></div>
<div style="font-size:21px; margin:2px 0 0 1.2em; line-height:1.5;">○ 共通の領域で、学生と教員がそれぞれの課題感を持っている印象<br>○ 課題感を対話する価値については、納得感があった<br>○ ギャップは個人間の方が大きい可能性がある</div>
</div>

<div class="stepbox"><div class="st"><b>理工系・医薬系では、ギャップが少ない傾向</b></div>
<div style="font-size:21px; margin:2px 0 0 1.2em; line-height:1.5;">→ (質的な差はあるものの)教員・学生とも重要性の認識、方向性は一致</div>
</div>

</div>

<div class="big-msg pip-safe" style="margin-top:14px;">懇談会では共通の課題感が、共有された</div>
