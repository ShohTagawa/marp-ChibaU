<div>
<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin-bottom:4px;">あて先の明記</div>
<div style="font-size:21px; line-height:1.45;">本文の冒頭に、受信者の所属と名前を書く（あて先の確認の意味）。</div>
</div>

<div>
<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin-bottom:4px;">名乗り（送信者の所属と名前）</div>
<div style="font-size:21px; line-height:1.45;">システムの「From」情報だけに頼らず、本文でもしっかり名乗る。</div>
</div>

<div style="grid-column:1 / span 2;">
<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin-bottom:4px;">受け手を想像した配慮</div>
<div class="box-accent" style="font-size:20px;">依頼は注意。「〜までに〜して下さい」と一方的に指示するのではなく、締切を明記した上で、<b>「恐縮ですがよろしくお願いいたします」「ご放念下さい」</b>などの表現を。相手は、こちらの心情や表情が見えない。。<br>環境依存文字（①や㈱など）の利用には注意する。自動改行機能を使わず、読みやすい位置で自分で改行を入れる。</div>
</div>

<div style="grid-column:1 / span 2;">
<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin-bottom:4px;">署名</div>
<div style="font-size:21px; line-height:1.45;">本文の最後に、所属、名前、住所、連絡先等を記載する。</div>
</div>

</div>

# メール送付時のマナーとネチケット

<div class="pip-safe" style="margin-top:10px;">

<div style="font-weight:800; color:var(--accent-dark); font-size:25px; border-bottom:2px solid var(--accent); display:inline-block; margin-bottom:6px;">ファイルサイズに注意</div>

<ul style="font-size:22px; line-height:1.5; margin-top:4px;">
<li>何MBもの巨大な添付ファイルは、受信者のネットワーク帯域やメールボックスの容量を圧迫し、<b style="color:var(--accent)">大きな迷惑になる</b>ことがあります。</li>
<li>巨大な写真をそのまま貼り付けただけの重い文書ファイルにも注意が必要です。</li>
</ul>

<div style="font-weight:800; color:var(--accent-dark); font-size:25px; border-bottom:2px solid var(--accent); display:inline-block; margin:10px 0 6px;">受け手を想像した配慮</div>

<ul style="font-size:22px; line-height:1.5; margin-top:4px;">
<li>サイズは問題ないか、本当に必要なファイルかを確認してから添付する。</li>
<li>大容量になる場合は、クラウドストレージやファイル転送サービスの利用を検討する。</li>
</ul>

<div style="font-weight:800; color:var(--accent-dark); font-size:25px; border-bottom:2px solid var(--accent); display:inline-block; margin:10px 0 6px;">機密保持</div>

<ul style="font-size:22px; line-height:1.5; margin-top:4px;">
<li>機密のファイルは、クラウドストレージの共有機能やパスワードをかけて別送する。</li>
<li>組織外のアドレスと出る場合には、要注意！</li>
</ul>

</div>

<!--
- 送付時はファイルサイズと機密保持に注意。巨大な添付は相手の迷惑になり得るし、機密ファイルはパスワードや共有機能で別送を。組織外アドレス宛は特に要注意。

<div class="page-title">SNSの注意点①</div>

# SNSの注意点①

<div class="box-info pip-safe" style="font-size:21px; margin:6px 0 12px;">例： パスワードが予想されてしまった…</div>

<div class="pip-safe">

<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin-bottom:4px;">プロフィールの設定</div>
<ul style="font-size:21px; line-height:1.45; margin-top:2px;">
<li>自分の顔がはっきり分かるような個人情報は慎重に扱う。</li>
<li>プロフィール写真から個人が特定され、<b style="color:var(--accent)">悪用される危険性</b>がある。</li>
<li>他人の写真やイラストなどを許可なくアイコンとして使用しない。</li>
</ul>

<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin:10px 0 4px;">公開範囲の設定</div>
<ul style="font-size:21px; line-height:1.45; margin-top:2px;">
<li>「友人限定」の設定であっても、スクリーンショット等で拡散される可能性があることを忘れない。</li>
<li>サービスごとの公開範囲設定を適切に行う。</li>
<li>自分の投稿が<b style="color:var(--accent)">「誰に」見られているか</b>を常に意識する。</li>
</ul>

</div>

<!--
- SNSの注意点その1。プロフィールの設定と公開範囲の設定。顔写真などから個人が特定され悪用される危険があるし、友人限定でもスクショで拡散されうる。誰に見られているかを常に意識。
-->

# SNSの注意点②

<div class="box-info pip-safe" style="font-size:21px; margin:6px 0 12px;">例： Be Realで個人情報・取引先情報が流出...</div>

<div class="pip-safe">

<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin-bottom:4px;">写真や場所に関する注意</div>
<ul style="font-size:21px; line-height:1.45; margin-top:2px;">
<li>自宅や学校、アルバイト先が特定できる写真や書き込みは避ける(一部のAIで場所は特定しうる)。</li>
<li>位置情報（ジオタグ）が付与された写真の投稿は、現在地を不特定多数に知らせるリスクがある。</li>
<li>映り込んだものには注意する。人の顔、機密情報、個人情報が問題になることがある。</li>
</ul>

<div style="font-weight:800; color:var(--accent-dark); font-size:24px; border-bottom:2px solid var(--accent); display:inline-block; margin:10px 0 4px;">投稿内容の注意</div>
<ul style="font-size:21px; line-height:1.45; margin-top:2px;">
<li>誹謗中傷や差別的な発言、不適切な悪ふざけの投稿は絶対にしない。</li>
<li>記録は後々まで残り（デジタルタトゥー）、深刻な問題に発展することがある。</li>
<li>投稿する前に、一歩止まって確認を。</li>
</ul>

</div>

# ハルシネーションとカットオフ

<div class="box-warn pip-safe" style="font-size:20px; margin-top:8px;">
<div style="font-weight:800; font-size:22px;">生成AIが誤った情報を生成する現象</div>
<div style="margin-top:4px;"><b>学習データの誤り</b> → ブログやSNS投稿からも学習しているため</div>
<div><b>学習データの偏り</b> → バイアスや偏見を学習してしまう</div>
<div><b>学習データの鮮度</b> → 過去のデータに基づく、最新情報には未対応の場合がある(カットオフ)</div>
</div>
