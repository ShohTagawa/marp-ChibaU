## オープニング（13:00–13:10）

### 0-1 ［自由 / word cloud］アイスブレイク
**「生成AI」と聞いて、いま頭に浮かぶ言葉を1つだけ教えてください。**
- 形式：word cloud（1〜2語）
- ねらい：会場の温度感を可視化。期待・不安・無関心が一目で分かる
- 進行：回答を眺めながら「便利そう／不安そう、両方ありますね」と受ける

### 0-2 ［選択 / 3択］現在地の確認
**生成AIは、大学教育に「どちらの」影響を及ぼすと感じますか。**
1. どちらかといえば **良い** 影響
2. どちらかといえば **悪い** 影響
3. **良くも悪くも、使い方次第**
- ねらい：「使い方次第」が多数になる想定 → 「では"良い使い方"を今日一緒に作りましょう」と接続

### Pre ［自由］期待の言語化
**今日の研修が終わったとき、「これが分かった／決まった」と言えたら嬉しいことは何ですか。**
- 形式：open text
- ねらい：参加者の期待を先に出させ、まとめ②で回収する布石

## Session 1（13:10–13:35）関わり方

### 1-1 ［選択 / 3択］学生の現状認識
**いまの学生は、生成AIを「学びに」活かせていると感じますか。**
1. わりと**活かせている**と思う
2. **使ってはいるが、学びにはなっていない**と思う
3. **よく分からない／見えていない**
- ねらい：2が多い想定 → 「だからこそ"文脈づくり"が要る」へ接続

### 1-2 ［自由］理想の関わり方
**先生方は、学生に生成AIと「どんな関わり方」をしてほしいですか。（一言で）**
- 形式：open text（word cloud でも可）
- ねらい：ワーク①の前ふり。タイパ型／創造性型のどちらに寄るかを可視化

### 1-3 ［自由］方法のアイデア
**どうすれば、学生に「良い関わり方の文脈」を作れると思いますか。**
- 形式：open text
- ねらい：ポリシー・透明性・価値を語る、の3点に教員の知恵を足す。会場で2〜3件読み上げる

## Session 2（13:35–14:00）業務活用

### 2-1 ［選択 / 5択］活用頻度
**生成AIを、日頃どのくらい活用されていますか。**
1. ほぼ毎日
2. 週に数回
3. 月に数回
4. ほとんど使わない
5. 使ったことがない
- ねらい：会場のレベル分布を把握し、この後の説明の深さを調整

### 2-2 ［選択 / 6択・複数選択可］利用ツール
**どの生成AIを使っていますか。（複数選択可・有料版を含む）**
1. ChatGPT（無料／有料）
2. Google Gemini
3. Microsoft Copilot（ブラウザ等）
4. Claude
5. NotebookLM
6. 使っていない／分からない
- ねらい：Copilot・無料版が多い想定 → 「安全な学校版」の話に自然に接続

### 2-3 ［自由 / word cloud］ニーズの収集
**どんな仕事・作業が「AIで簡単になってほしい」ですか。**
- 形式：open text / word cloud
- ねらい：体験ワークの題材に直結（メール返信・要約・採点・資料作成など）

## Session 3（14:00–14:25）授業設計

### 3-1 ［選択 / 3択］評価設計の方向性
**レポート課題などの「学生・教員双方の苦労」を減らすには、どの方向が良いと思いますか。**
1. **課題を作り変える**（AIで解けない／使ってこそ深まる課題へ）
2. **評価対象を広げる**（成果物＋対話記録＋振り返り）
3. **ルールで線を引く**（使用可否を明示・徹底）
- ねらい：1と2が今日の主張。3も否定せず「3だけでは限界」と補足

### 3-2 ［自由］ワーク③の共有
**ワーク③で気づいたこと・課題を作り変えるアイデアを、会場全体に共有してください。**
- 形式：open text
- ねらい：参加者の実例を全体知に。2〜3件を読み上げてコメント

### 3-3 ［評価 / 5段階 or 3択］可能性の手応え
**今日をとおして、AIの「教育への可能性」を感じましたか。**
- 形式：rating（★1〜5）または 3択（感じた／どちらとも／感じなかった）
- ねらい：研修効果の自己評価。0-2 とのビフォーアフター比較に使える

## 運用メモ
- 0-2 と 3-3 は対になる設計（前後比較）。スクショを撮ると効果測定に使える。
- 1-2 / 2-3 / 3-2 は word cloud にすると盛り上がる。
- 個人情報・機微情報は入力しないよう毎回ひとこと添える（データ利用の同意）。
