## Copilot（m365.cloud.microsoft）で実際に使えるもの

講師が実機で確認済み。以下は**そのまま手順に書いてよい**。

- チャット画面に「このチャットには **エンタープライズ データ保護** が適用されます」と出る
- **エージェント**：サイドバーに「Idea Coach」（Microsoft製）「新しいエージェント」「その他のエージェント」。
  **Agent Builder**（"Build your own specialist agent"）で自作できる。
  テンプレートに AI Learning Advisor / Text Translator / Corporate Comms Crafter。「テンプレート」「自分のエージェント」タブ
- 入力欄の「＋」メニュー：コンテンツの追加／**画像とファイルのアップロード**／**クラウド ファイルを添付**／
  機能を追加／**エージェントとチャット**（@で呼べる）
- **画像・ビデオの作成**：「何を作りますか?」→「画像の作成」「ビデオの作成」。スタイル／色／サイズ指定。「マイ画像」に履歴
- **作成ハブ（ストーリー）**：「作成するストーリーを説明してください」＋ファイルを追加する。
  テンプレート例＝ファイルを攻略ガイドに変換する／プロジェクトの更新に変換する／レポートの概要に変換する など

### ★ Copilot の「教育ツール」（m365.cloud.microsoft/teach）

教職員向け。**有償のCopilotライセンスは不要**。実機の画面は次のとおり。

**よく使われるもの**

| 名前 | 説明（画面の表記） |
|---|---|
| 授業計画 | レッスンの詳細ガイド |
| フラッシュカード | 習得するまでの学習概念です |
| ルーブリック | 一貫した条件で学生の作業を評価します |
| クイズ | Microsoft Forms を使用して標準に合わせたクイズを作成します |
| 空欄補充問題 | 正しい単語で文章を完成させる |

**左の分類**：カリキュラム計画／既存のコンテンツを変更する（多様なニーズを満たすために）／宿題と評価／学習アクティビティ

**「既存のコンテンツを変更する」の中身**

| 名前 | 説明（画面の表記） |
|---|---|
| 読み取りレベルを変更する | 学生の読み上げ能力に合わせてテキストを簡略化またはチャレンジします |
| 指示を区別する | さまざまな学習レベルのタスクをカスタマイズします |
| サポートの例を追加 | 関連する例を使用してテキストを強化します |
| 標準に合わせる | テキストまたはドキュメントを関連する教育基準に合わせます |

画面の上に「すべて／最近使用／お気に入り／人気」のタブと検索がある。下に「履歴」がある。

## ★ Copilot で使えないもの

学園には **Microsoft 365 Copilot の有償ライセンス契約が無い**。
**Word / Excel / PowerPoint / Outlook / Teams のアプリの「中」で動く Copilot は使えない。**
「Wordを開いてCopilotボタンを押す」と書いたらその班は詰む。
ファイルは **Copilot のチャット画面に添付する／中身を貼り付ける**という導線で書く。

## Google 側（教員）

Google Workspace for Education **Fundamentals**（Geminiの有償アドオン無し）。

**使えるもの**

- **Gemini アプリ**（gemini.google.com）。学園アカウントで使う限り、入力は学習に使われず、人によるレビューも入らない
- **Gem**（自分専用のGemini）の作成と共有。
  導線：［Gem を表示］→［Gem を作成］→「名前」「指示」→（知識に［ファイルをアップロード］／ドライブ）→［保存］→
  ［共有］→「組織内」＋「閲覧者／編集者」→［リンクをコピー］。URL は `https://gemini.google.com/gems/create`
  ★知識に添付できるのは**PCのファイルかドライブのファイル**に限る
- **NotebookLM**：コアサービス。管理者操作不要・全年齢。**ドライブのドキュメント／スライドを直接ソースにできる**。
  組織内の共有は人数無制限。1ノートブックにつきソースは50まで。**音声解説は日本語に対応**
- **画像生成**、**Canvas**、**Deep Research**、ファイルのアップロード（PDF・画像・音声）

**使えないもの（★書かない）**

- Google ドキュメント／スライド／スプレッドシートの**サイドパネル内蔵 Gemini**
- スプレッドシートの `=AI()` 関数
- **予約アクション（定期実行）**
- **NotebookLM の動画解説は英語のみ**（日本語で作らせるなら音声解説）
- @Gmail / @Drive のアプリ連携は当てにしない。ファイルは**手でアップロード**するか、NotebookLMのソースに追加する

## Canva（広報系8名）

機能名は日本語UIの表記に合わせる：**マジック作文**（文章の変換・書き換え）／**マジック生成**（画像・イラスト・動画）／
**AI背景生成**／**マジック消しゴム**／**マジック切り抜き**／**マジック拡張**／**高画質化**／**一括作成**。
有料プラン限定の機能が多く、月間の使用回数に上限がある。使えない機能があっても進められるように書く。
