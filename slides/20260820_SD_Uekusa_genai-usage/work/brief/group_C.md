# グループC「AI時代の新しい学びを創る」（教員6名）

**使う道具**：Gemini アプリ、NotebookLM、Copilot のエージェント・教育ツール

**このグループですること**：授業を一段高度にする材料を、AIで作る。

## ★講師の指定：シナリオは次の3本

### ① 少し遠くまで行ける課題を設定し、授業を高度化する

学生に体験してほしいことを1つ決める。そのうえで、いまより少し遠くまで行ける課題を設定する。
道具は **Gem** または **Copilot のエージェント**。作った課題を、そのAIに検討させて練り上げる。

### ② 自分の資料から小教材を作り、検証する

自分の授業のレジュメ（または学生が高校時代に学んだ事項）を **NotebookLM** に入れる。
そこから小教材を作らせる。作った教材を、**自分の専門の目で検証する**。
検証は、次の4段階で判定する表を手順書に印刷して、書き込んでもらう。

| 判定 | 意味 |
|---|---|
| ◎ | そのまま学生に見せてよい |
| ○ | おおむね正しいが、言葉足らず |
| △ | 間違ってはいないが、この分野の作法から外れている |
| × | 誤り。学生が読んだら困る |

### ③ ルーブリックを作る

**Copilot の教育ツール**（`m365.cloud.microsoft/teach` の［ルーブリック］）または **Gem** で、
課題の評価基準を作る。

## 補足

- 植草学園は保育士・幼稚園教諭・特別支援教育・作業療法士・理学療法士などを養成している。題材はこの領域から採る
- 実在の学生・保護者・患者・利用者の情報は入れさせない。架空の設定で行う
- ①と③で使う指示文は、**完成した文案を全文**載せる
