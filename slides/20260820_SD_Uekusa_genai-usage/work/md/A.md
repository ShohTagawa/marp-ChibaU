# グループA　手順書

「AIと教育のルールを考える」（教員6名／3名×2班）

使う道具：Gemini アプリと Gemini Notebook が中心です。

---

## 1. このグループでやること

このワークが終わるとき、みなさんの手元に「私たちが考えたベストな、授業における生成AIの利用ポリシー」という1枚の文章ができあがり、それを1枚の図にまとめたものを添えて、配れる状態になります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）。** たとえば、次のような文章です。

- タイトル：「〇〇学部 授業における生成AIの利用について（第1版・2026年8月20日 班で作成）」
- 参考にした資料：△△大学の公開ポリシー（URL）、大阪大学TLSC 資料
- 学生に伝える7項目を、自分たちの言葉で書き直したもの（5行程度）
- 教員が課題を出すときの工夫を3つ（この紙の巻末にある対策から選んだもの）
- やらないと決めたことを1つ（巻末の「推奨されない対応」から。なぜやらないのかも一言添えます）
- 次に決めなければいけないことを1つ（今日は結論が出なかったこと）

**② インフォグラフィック（やったことを1枚の図にしたもの）。** これもAIに作ってもらいます。班の名前、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つが、見て分かるように並んだ1枚です。作り方は、共通ページの Step 3 をご覧ください。

## 3. あなたの道具はどれですか

グループAは全員が教員の方なので、全員が同じ道具を使います。どちらも学園のGoogleアカウントで使います。

| 道具 | どこで開くか | 得意なこと |
|---|---|---|
| Gemini アプリ | `https://gemini.google.com` | 調べる、書く、点検させる |
| Gemini Notebook | `https://notebook.google.com/?icid=home_maincta` | 読み込ませた資料の中だけで答える |
| 〈Gemini に相談〉 | Chrome の画面の右上にあるアイコン | いま開いているページについて、その場で聞く |

Gemini アプリと Gemini Notebook の違いを、先に一言で覚えてください。Gemini は「都度、webから検索」、Gemini Notebook は「渡した資料だけの読み込み」です。ポリシーの文面のように、根拠がはっきりしていないと困るものは、Gemini Notebook が向いています。

3つめの 〈Gemini に相談〉 は、Chrome に組み込まれているものです。いま画面に開いているページを、ページを離れずにそのまま読ませて聞けます。使い方はシナリオ5にあります。学園のアカウントの設定や、お使いのパソコン・Chromeの状態によっては、このアイコンが出ないことがあります。画面に出ない方は、シナリオ5は飛ばしてください。

なお、Google ドキュメントやスライドを開いたときに画面の横に出てくるGemini（サイドパネル）は、学園の契約では使えません。資料をAIに読ませたいときは、Gemini の画面にファイルを添付するか、Gemini Notebook にソースとして追加してください。

**開き方（どのシナリオも、ここから始まります）**

① ブラウザ（Chrome など）の新しいタブを開きます。
→ 空のタブが開けば、ここまでは正しく進んでいます。

② アドレス欄に、上の表のアドレスを入力して、Enter を押します。
→ Gemini アプリは、画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。
→ Gemini Notebook は、ノートブックの一覧と、右上に［新規作成］にあたるボタンが見えていれば、正しい画面です。

③ 画面の右上にある丸いアイコン（自分のアカウントのアイコン）を押して、学園のGoogleアカウントでサインインしているかを確かめます。
→ 学園のメールアドレスが表示されていれば、正しい状態です。
→ 個人のGmailのアドレスが出ていたら、そこから学園のアカウントに切り替えてください。ここは必ず確かめてください。
→ サインインできない方は、班の他の方の画面を一緒に見る形で進めてください。

## 5. 各シナリオ

### シナリオ1　他大学の方針を調べます

つくるもの：他大学の生成AI利用方針を2〜3件、5つの観点で整理した文章

Deep Research（ディープリサーチ＝AIが自分で何十ページも調べて長いレポートを書く機能）は、学園のアカウントでは1人あたり1か月に5回までです。実行するのは、班につき1回にしてください。1台で走らせて、3人でその画面を一緒に見ます。

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。
→ 画面の下のほうに、横長の入力欄が見えていれば、正しい画面です。

② 画面下の入力欄のすぐ下（または入力欄の中）にある ＋（プラス）のアイコンを押します。
→ ボタンの名前は「ファイルを追加」と表示されることがあります。
→ メニューが開けば、正しい状態です。

③ 出てきたメニューの中から 〈Deep Research〉にあたる項目を選びます。
→ 入力欄のあたりに「Deep Research」という表示が付いた状態になっていれば、正しい状態です。
→ 見つからないときは、何も選ばずにそのまま次へ進んでください。下の文は、ふつうのチャットに貼っても動きます。

④ 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔　〕の1か所だけです。埋めなくても動きます。

```
大学の教務に詳しい調査担当者として、以下を作成して下さい。
日本の大学・短期大学が公開している「授業における生成AIの利用に関する方針（ポリシー）」を調べてください。

【調べる範囲】
・大学・短期大学の公式サイトに掲載されているページ、または公式に公開されているPDFに限ってください。
・個人のブログ、まとめ記事、ニュース記事は使わないでください。
・〔 例：教育系や保健医療系の学部を持つ大学 〕を優先して探してください。
・3つ以上の大学を見つけて、その中から特に参考になるものを2つ選んでください。
・アカデミック・インテグリティについても調査して下さい。

【見る観点】次の5つについて、それぞれ何と書かれているかを拾ってください。
1. 学生が生成AIを使ってよい場面と、使ってはいけない場面
2. 使った場合に、申告や明記を求めているかどうか
3. 教員が課題を出すときに気をつけるように書かれていること
4. 個人情報や未公開資料の扱いについて書かれていること
5. ルールを守らなかった場合にどう扱うと書かれていること

【出力の形式】
・大学ごとに見出しを分けて、上の5つの観点を箇条書きで書いてください。
・それぞれの記述について、出典のページ名とURLを必ず付けてください。
・最後に「共通していること」「大学によって違うこと」を、それぞれ5行以内でまとめてください。
・日本語で、敬体（です・ます）で書いてください。
```

⑤ 送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ すぐにレポートが出てくるのではなく、「これから何を調べるか」という計画（プラン）が先に表示されます。ここまで来ていれば、正しく進んでいます。

⑥ ［リサーチを開始］にあたるボタンを押します。
→ 「調べています」という趣旨の表示が出て、参照したページの数が増えていけば、正しく動いています。ここから、しばらく待ちます。

⑦ レポートが表示されたら、その上部にある ［Google ドキュメントにエクスポート］にあたるボタンを押します。
→ Google ドキュメントが新しいタブで開き、レポートの本文が入っていれば、保存できています。
→ ボタンが見つからないときは、レポートを範囲選択してコピーし、アドレス欄に `docs.new` と入力して開いた新しい Google ドキュメントに貼り付けてください。

⑧ 開いたドキュメントのタイトルに、班の名前（A-1班 / A-2班）を入れます。

⑨ レポートに出てきた大学のURLを1つ開いて、その大学の公式サイトに同じ文書があることを確かめます。
→ ページが開かない、大学名が違う、という場合は、その大学を外してください。

### シナリオ2　方針を読み比べます

つくるもの：他大学の方針と大阪大学の資料を並べた比較表

読み込ませるのは、公開されている資料に限ります。学生の個人情報が入ったものや、未公開の学内資料は入れません。

① Gemini Notebook を開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。

② ［新規作成］または［新しいノートブック］にあたるボタンを押します。
→ 画面の左側に「ソース」という欄があり、そこに資料を追加するように促す表示が出ていれば、正しい画面です。まだ何も入っていない、空っぽの状態で構いません。

③ 左の「ソース」欄にある ［＋ 追加］にあたるボタンを押します。
→ 資料の種類（ウェブサイト、コピーしたテキスト、Google ドライブ、ファイル）を選ぶ画面が出れば、正しい画面です。

④ 「ウェブサイト」にあたる欄に、他大学の方針が載っている公式サイトのページのアドレスを貼り付けて追加します。これを2〜3件くり返します。
→ 左の「ソース」欄に、資料の名前が1行ずつ増えていれば成功です。
→ シナリオ1で Google ドキュメントを作った方は、「Google ドライブ（Google ドキュメント／スライド）」にあたる欄から、そのドキュメントも追加できます。いったんダウンロードする必要はありません。

⑤ この紙の巻末にある「資料」を、「コピーしたテキスト」にあたる欄に貼り付けて追加します。
→ 「ソース」欄に3件ほど並んでいれば、準備ができています。1つのノートブックには50個まで入れられます。

⑥ 画面の下にある、質問を打ち込む欄をクリックして、次の文をコピーして貼り付け、送信します。

```
読み込んだ資料だけを使って、比較表を作ってください。

【行（たてに並べる項目）】
1. 学生が生成AIを使ってよい場面
2. 学生が生成AIを使ってはいけない場面
3. 使ったときに申告や明記を求めているか
4. 教員が課題を出すときの工夫
5. 個人情報・未公開資料の扱い
6. ルールを守らなかった場合の扱い

【列（よこに並べる項目）】
・他大学のポリシー（大学ごとに1列）
・大阪大学の資料（浦田 2023）

【書き方の約束】
・資料に書かれていない項目は、想像で埋めずに「記載なし」と書いてください。
・それぞれのマス目の最後に、どの資料から取ったかが分かるようにしてください。
・日本語で、敬体（です・ます）で書いてください。
```

→ 表が表示され、文章のところどころに小さな数字やマークが付いていれば、正しく動いています。

⑦ その数字を1つ押して、元の資料のどこにそう書いてあったかを確かめます。
→ 画面の左側に、元の資料の該当箇所が表示されます。

⑧ 気に入った表が出たら、［メモに保存］にあたるボタンで残します。
→ ボタンが見つからないときは、表をコピーして、提出用の文書に貼ってください。

### シナリオ3　自分の科目の方針文を書きます

つくるもの：学生に見せる「この授業での生成AIの使い方」の文面

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。
→ シナリオ2を進めた方は、そのノートブックの質問欄に貼っても構いません。

② 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔担当科目名〕と〔到達目標〕の2か所です。到達目標は、シラバスの文をそのままコピーして貼ってください。

```
あなたは、大学の教務に詳しいアドバイザーです。
私の授業で学生に見せる「授業における生成AIの利用について」という文章の下書きを作ってください。

【立場】
・書き手は、〔 例：発達教育学部の「保育原理」 〕を担当する教員です。
・読み手は、その科目を受けている学生です。
・この科目の到達目標は、次のとおりです。
　〔 シラバスの到達目標をそのまま貼り付けてください 〕

【必ず入れること】
1. 学生に伝えること（次の7項目を、私たちの学生に伝わる言い方に直したもの）
　1 生成AIを適切に使用しない場合は、学業上の不正行為とみなされること
　2 生成AIの使用は、あくまでも学習サポートに限ること
　3 情報の分析などで生成AIを使用した場合は、その旨を明記すること
　4 意図しない盗用、著作権侵害、個人情報・機密情報の漏洩の可能性といった法的リスクがあること
　5 「ハルシネーション」や、参考文献は実在しないものが多いといった出力の信頼性の問題があること
　6 詐欺への注意として、安易にインストールしたり課金したりしないこと
　7 生成AIの不正な使用は、アカデミック・インテグリティの原則に違反しうること
2. 教員が課題を出すときの工夫を3つ（次の中から選び、なぜそれを選んだかも1行ずつ）
　・最新の出来事や資料を扱うテーマを設定する
　・事前に生成AIで試験問題を試してみて、対応できた場合は別の問題を検討する
　・授業内でディスカッションした内容を書かせる
　・口頭試験にする
　・インタビュー、コンセプトマップ、動画、ディベートなど、レポート形式以外の課題にする
　・ピアや教員との対面ミーティングを組み合わせて段階的に評価する
　・学生が引用した文献を抜き打ちで実在するかチェックする（ことを伝える）
　・レポートの執筆プロセス（下書きや参考文献、編集履歴等）も提出させて評価対象にする
　・試験で許可する・しないツールを明記する
　・AIの利用に関する方針をシラバスに明記する
　・学問的誠実性を強調し、不正行為の結果を理解させる
3. この学園ではやらないと決めたことを1つ（次の「推奨されない対応」から選び、なぜやらないかを1行）
　1 生成AIに剽窃チェックをさせる（出力自体が正確でない場合がある）
　2 剽窃チェックツールで判定する（検出率は4分の1程度といわれ、プライバシーポリシー上の問題もある）
　3 手書きでの課題提出を強制する（合理的配慮が必要な学生がいる場合がある）
　4 学生に生成AIの利用を強制する（プライバシーへの配慮が必要）
4. 個人情報と未公開資料を入力しないという約束

【書き方の約束】
・全体で1枚（A4で1ページ、900字以内）に収めてください。
・日本語で、敬体（です・ます）で書いてください。
・体言止めを使わないでください。
・「革命」「激変」のような、あおる言葉を使わないでください。
・断定できないことは「現時点では」と前置きしてください。
・ここに書かれていないことは、書かないでください。
```

③ 送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ 見出しの付いた1枚分の文章が出てくれば、正しく動いています。

④ 出てきた下書きを、3人で声に出して読みます。

⑤ 読みにくいところ、自分たちの現場に合わないところを1か所だけ挙げて、続けて直すように頼みます。
→ 例：「『学習サポートに限る』という言い方が学生に伝わりにくいので、具体的な場面を1つ足してください。」

⑥ できあがった文章をコピーして、提出用の文書に貼ります。

### シナリオ4　書いた方針をAIに点検させます

つくるもの：点検の結果と、書き直した方針文の全文

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。

② 画面の左上にある ［新しいチャット］ を押して、まっさらな状態にします。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

③ 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは、いちばん下の〔　〕の1か所だけです。ここに、点検したい方針文をそのまま貼ってください。

```
あなたは、大学・短期大学の教務に詳しいアドバイザーです。
教員が書いた「授業における生成AIの利用に関する方針（ポリシー）」の下書きを受け取り、
公表する前に点検して、直したほうがよい箇所を具体的に指摘してください。

【第1段階】
まず、次の4つが方針文に含まれていないかを確認してください。
これらは「推奨されない対応」として整理されているものです（大阪大学 全学教育推進機構 TLSC／浦田 2023）。
1つでも含まれていたら、最初に、目立つように指摘してください。
(1) 生成AIに剽窃チェックをさせること
　　… 出力は出ますが、その出力自体が正確でない場合があります。
(2) 剽窃チェックツールで判定すること
　　… 現時点での検出率は4分の1程度といわれ、プライバシーポリシー上の問題もあります。
(3) 手書きでの課題提出を強制すること
　　… 合理的配慮が必要な学生がいる場合があります。
(4) 学生に生成AIの利用を強制すること
　　… 学生のプライバシーへの配慮が必要です。

【第2段階】
次に、学生に伝えるべき次の7項目のうち、方針文に書かれていないものを挙げてください（浦田 2023）。
1 生成AIを適切に使用しない場合は、学業上の不正行為とみなされること
2 生成AIの使用は、あくまでも学習サポートに限ること
3 情報の分析などで生成AIを使用した場合は、その旨を明記すること
4 意図しない盗用、著作権侵害、個人情報・機密情報の漏洩の可能性といった法的リスクがあること
5 「ハルシネーション」や、参考文献は実在しないものが多いといった出力の信頼性の問題があること
6 詐欺への注意として、安易にインストールしたり課金したりしないこと
7 生成AIの不正な使用は、アカデミック・インテグリティの原則に違反しうること

【第3段階】
次の観点で、読みにくさを指摘してください。
・学生が読んで、何をすればよいか分かるか
・「原則として」「適切に」のような、判断を学生に丸投げしている表現がないか
・禁止だけが並んでいて、使ってよい場面が書かれていないということがないか

【回答の形式】必ずこの形で出してください。
1.【そのまま使えるところ】良いところを2つ、具体的に引用してください。
2.【必ず直してほしいところ】第1段階に当たるものがあれば書いてください。無ければ「ありません」と書いてください。
3.【足りない項目】第2段階で見つかった不足を、番号つきで挙げてください。

5.【書き直し案】上の指摘を反映した文章を、A4で1枚（900字以内）にまとめて示してください。

【書き方の約束】
・日本語で、敬体（です・ます）で書いてください。

・出典が確認できない統計や、実在しない文献名を書かないでください。

【点検する方針文】
〔 ここに、点検したい方針文をそのまま貼り付けてください 〕
```

### シナリオ5　開いているページについて、その場で聞きます

つくるもの：他大学の方針ページの中身を5つの観点で書き出したメモ

シナリオ1の Deep Research は、たくさんのページをまとめて調べさせて、長いレポートを1本もらう道具です。ここで使う 〈Gemini に相談〉 は、いま画面に開いている、その1ページについて聞く道具です。他大学の方針を読んでいる途中で「この大学は申告を求めているのだろうか」と気になったときに、ページを離れずにその場で確かめられます。

**★ 先に、Chrome にログインしているアカウントを確かめます。** 〈Gemini に相談〉 は、Chrome にログインしているアカウントで動きます。個人のGoogleアカウントで Chrome にログインしていると、学園のアカウントのデータ保護が効きません。業務の情報を扱いますので、ここを確かめてから使います。共通ページの Step 1 で確かめたのと同じことを、Chrome でも確かめる、ということです。

① Chrome の画面の右上にある丸いアイコン（自分のアカウントのアイコン）を押して、学園のGoogleアカウントでログインしていることを確かめます。
→ 学園のメールアドレスが表示されていれば、正しい状態です。
→ 個人のアカウント（ふだんの私用のGmail）になっていたら、学園のアカウントに切り替えてから進めてください。

② 他大学の方針が載っている公式サイトのページを、ふつうにタブで開きます。
→ ページの本文が画面に表示されていれば、正しい状態です。PDFのページでも構いません。

→ アイコンが画面に出ない方は、このシナリオは飛ばしてください。学園のアカウントの設定によっては使えません。シークレットウィンドウでも使えません。

④ パネルの入力欄に、次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の1か所だけです。埋めなくても動きます。

4. 個人情報や未公開資料の扱いについて書かれていること

## 8. この紙に印刷してある資料（シナリオ2・3・4で使います）

出典：大阪大学 全学教育推進機構 TLSC「授業における生成AIの利用について」（浦田 2023）

### 生成AIの不適切な利用を防ぐ対策（抜粋）

- 最新の出来事や資料を扱うテーマを設定する
- 事前に生成AIで試験問題を試してみて、対応できた場合は別の問題を検討する
- 授業内でディスカッションした内容を書かせる
- 口頭試験にする
- インタビュー、コンセプトマップ、動画、ディベートなど、レポート形式以外の課題にする
- ピアや教員との対面ミーティングを組み合わせて段階的に評価する
- 学生が引用した文献を抜き打ちで実在するかチェックする（ことを伝える）
- レポートの執筆プロセス（下書きや参考文献、編集履歴等）も提出させて評価対象にする
- 試験で許可する・しないツールを明記する
- AIの利用に関する方針をシラバスに明記する
- 学問的誠実性を強調し、不正行為の結果を理解させる

### 推奨されない対応

1. 生成AIに剽窃チェックをさせる — 出力自体が正確でない場合がある
2. 剽窃チェックツールで判定する — 検出率は4分の1程度といわれ、プライバシーポリシー上の問題もある
3. 手書きでの課題提出を強制する — 合理的配慮が必要な学生がいる場合がある
4. 学生に生成AIの利用を強制する — プライバシーへの配慮が必要

### 学生に伝えること（7項目）

1. 生成AIを適切に使用しない場合は、学業上の不正行為とみなされること
2. 生成AIの使用は、あくまでも学習サポートに限ること
3. 情報の分析などで生成AIを使用した場合は、その旨を明記すること
4. 意図しない盗用、著作権侵害、個人情報・機密情報の漏洩の可能性といった法的リスクがあること
5. 「ハルシネーション」や、参考文献は実在しないものが多いといった出力の信頼性の問題があること
6. 詐欺への注意として、安易にインストールしたり課金したりしないこと
7. 生成AIの不正な使用は、アカデミック・インテグリティの原則に違反しうること
