# グループE 手順書

グループE 手順書 ── 教育現場の業務改善を考える
「教育現場の業務改善を考える」（教員3名／1班）

使う道具：Gemini アプリ（gemini.google.com）と Gemini Notebook が中心です。学園のM365アカウントで Copilot をお使いの方には、Copilot の手順も並べて書いてあります。

## 1. このグループでやること

日ごろの仕事の中から気になるものを選び、生成AIに実際にやらせてみます。小さなものを1本ずつ試して、使えそうなものを持ち帰ります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）**　たとえば、次のようなものです。

- スライドの下書き、挿絵、通知文の下書き、要約と論点の一覧、形をそろえた表
- メールの返信の下書きと、よく来る問い合わせへの返し方の型
- 資料を読み込ませた Gemini Notebook のノートブック
- 作った Gem の「指示」の欄の文章（省略せず全文）
- Workspace Studio で組んだフロー1本（ステップの並びと、貼ったプロンプトの全文）

1本でも、3本でも構いません。試したものを、そのまま出してください。

**② インフォグラフィック（やったことを1枚の図にしたもの）**　これもAIに作ってもらいます。次の5つが、見て分かるように並んだ1枚です。

1. グループと班（例：グループE 1班）
2. 選んだ題材
3. 使った道具
4. 作ったもの
5. やってみて分かったこと

作り方は、共通ページの Step 3 をご覧ください。

## 3. あなたの道具はどれですか

| 道具 | どこで開くか | 今日つかう場面 |
|---|---|---|
| Gemini アプリ | `gemini.google.com` | 文章を作る、絵を作る、文字にする、Gem を作る |
| Gemini Notebook | `https://notebook.google.com/?icid=home_maincta` | 自分の資料を読ませて、その中だけから答えさせる |
| Copilot | `m365.cloud.microsoft` | M365アカウントをお使いの方が、同じことを行う |
| Workspace Studio の ［Flows］ | `studio.workspace.google.com` | 決まった時刻に調べて、Chat に通知する流れを組む |
| 〈Gemini に相談〉 | Chrome の画面の右上にあるアイコン | いま開いているページについて、その場で聞く |

Gemini と Gemini Notebook は、学園のGoogleアカウントでサインインしてお使いください。個人のGmailアカウントのままにしないでください。

Word・Excel・PowerPoint・Outlook の中に Copilot のボタンは出ません。学園の契約に含まれていないためです。ファイルは Copilot のチャット画面に添付するか、中身をコピーして貼り付けてください。

Chrome の 〈Gemini に相談〉 は、Chrome に組み込まれているものです。いま画面に開いているページを、コピーして貼り直さずに、そのまま読ませて聞けます。使い方はシナリオ14にあります。学園のアカウントの設定や、お使いのパソコン・Chromeの状態によっては、このアイコンが出ないことがあります。画面に出ない方は、シナリオ14は飛ばしてください。

3人で1台の画面を一緒に見ながら進めても構いません。

アップロードするのは、ご自身が作った資料に限ってください。録音や議事録は、架空のものか、機密でないもので練習してください。学生・園児・生徒・利用者・教職員の個人情報は入力しません。

## 5. 各シナリオ

### シナリオ1　スライドの下書きをつくる

つくるもの：説明に使うスライドの下書き

① ブラウザで新しいタブを開き、アドレス欄に `gemini.google.com` と入力して Enter を押します。
→ 画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 入力欄に、次の文をコピーして貼り付け、〔　〕の1か所を埋めて送信します。

```
これから作る説明用スライドの構成案を作ってください。
題材は〔　　　　　　　　　　〕で、聞き手は学内の教職員です。
【出力の形】
・1行目にスライドの見出しを書いてください。見出しは20字以内にしてください。
・その下に、そのスライドで話す内容を3行の箇条書きで書いてください。1行は40字以内にしてください。
・これを8枚分つづけてください。
【書き方の約束】
・専門用語には、短い言い換えを丸かっこで添えてください。
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・題材に書かれていない事実、数字、日付を足さないでください。
```

→ 見出しと箇条書きが8枚分並んで出てくれば、正しく動いています。

③ 出てきた文をすべて選んでコピーします。
→ 文字の上をドラッグして選び、Ctrl キーを押しながら C（Mac は command キーを押しながら C）でコピーします。

④ Google スライドで新しいファイルを作り、見出しと箇条書きを1枚ずつ貼り付けます。
→ 8枚のスライドに文字が入っていれば、この手順は終わりです。

**Copilot をお使いの場合**

① `m365.cloud.microsoft` を開き、〈作成〉にあたる場所から「作成するストーリーを説明してください」と書かれた入力欄を選びます。
→ 入力欄と、ファイルを追加するボタンが見えていれば、正しい画面です。

② 上の②と同じ文を貼り付けて送信し、出てきた案から要らないページを削ります。
→ 見出しと箇条書きの並んだ案が出てくれば、正しく動いています。

### シナリオ2　絵をつくる

つくるもの：掲示物や資料にのせる挿絵が1枚

① `gemini.google.com` を開き、画面の左上にある ［サイドバーを開く］（横線が3本並んだアイコン）を押します。
→ 画面の左側に、メニューの一覧が開けば、正しい状態です。

② 開いたメニューの中から ［画像］ を選びます。
→ 画像を作るための入力欄が表示されていれば、正しい画面です。

③ 入力欄に、次の文をコピーして貼り付け、〔　〕の1か所を埋めて送信します。

```
掲示物にのせる挿絵を1枚作ってください。
題材は〔　　　　　　　　　　〕です。
【見た目の指示】
・線が細く、色数の少ない、平らな図（フラットなイラスト）にしてください。
・色は、白を背景に、青と灰色を中心にしてください。
・横長の構図にしてください。
・画像の中に文字を入れないでください。
・実在の人物、実在の建物、実在の園や学校に似せないでください。
```

→ 数十秒で絵が表示されれば、正しく動いています。連打せずにお待ちください。

④ 変えたいところが1つあれば、「〔変えたいところ〕を変えて、もう一度作ってください」と送ります。
→ 画像は1日に作れる枚数に限りがあります。作り直しは2回か3回までにしてください。

⑤ できた絵の上で右クリックして、「名前を付けて画像を保存」を選びます。
→ パソコンに画像が保存されていれば、この手順は終わりです。

**Copilot をお使いの場合**：`m365.cloud.microsoft` の「何を作りますか?」から 〈画像の作成〉にあたる項目を押し、上の③と同じ文を貼り付けます。できた絵は「マイ画像」に残ります。

### シナリオ3　紙の資料や録音を文字にする

つくるもの：写真や音声から起こした文字

使うものは、ご自身が作った資料の写真か、練習のためにご自身で吹き込んだ音声にしてください。実在の会議の録音や、個人情報の載った書類は使いません。

① `gemini.google.com` を開き、入力欄のそばにある ＋（プラス）のアイコンを押します。
→ ［ファイルをアップロード］や［ドライブから追加］が選べる状態になれば、正しい画面です。

② 資料の写真か、音声のファイルを1つ選んで送ります。
→ 入力欄のあたりにファイル名が表示されれば、読み込めています。

③ 入力欄に、次の文をコピーして貼り付け、送信します。埋めるところはありません。

```
添付したものの中身を、そのまま文字にしてください。
・聞き取れない部分、読み取れない部分は［不明］と書いてください。
・内容を要約したり、言い換えたりしないでください。
・書かれていないこと、話されていないことを足さないでください。
文字にしたあと、最後に「決まったこと」と「持ち帰ること」を、それぞれ箇条書きで並べてください。
```

→ 文字にした本文と、2つの箇条書きが出てくれば、正しく動いています。

④ 出てきた文を目で読み、［不明］の箇所と、数字の書き取りを直します。
→ 直した文を Google ドキュメントか Word に貼り付ければ、この手順は終わりです。

**Copilot をお使いの場合**：入力欄の「＋」から 〈画像とファイルのアップロード〉にあたる項目を選んでファイルを送り、上の③と同じ文を貼り付けます。

### シナリオ4　通知文の下書きをつくる

つくるもの：保護者あての通知文1本

① `gemini.google.com` を開き、画面の左上にある ［新しいチャット］ を押します。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

② 入力欄に、次の文をコピーして貼り付け、〔　〕の2か所を埋めて送信します。

```
次の内容で、保護者あての通知文の下書きを作ってください。

・件名：〔　　　　　　　　　　〕
・伝えること：〔　　　　　　　　　　〕

【書き方の約束】
・お願いすることと問い合わせ先は、上に書かれていません。本文の該当する場所に〔要確認〕と書いて、空けておいてください。
・本文は400字以内にしてください。
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・専門用語は使わないでください。使う場合は、短い言い換えを丸かっこで添えてください。
・上に書かれていない事実、数字、日付を足さないでください。分からないところは〔要確認〕と書いてください。
・「革命」「激変」のような、あおる言葉を使わないでください。
```

→ 400字ほどの通知文が出てくれば、正しく動いています。

③ 出てきた文の中の、日付・場所・連絡先を1つずつ目で確かめます。
→ 〔要確認〕と書かれた箇所は、ご自身の言葉で埋めてください。

④ 直した文を Google ドキュメントか Word に貼り付けます。
→ そのまま配れる形になっていれば、この手順は終わりです。

### シナリオ5　長い文書を要約して、論点を抜き出す

つくるもの：200字の要約と、論点の一覧

ご自身が作った資料をお使いください。手元にないときは、下の架空の会議メモをお使いください。

① `gemini.google.com` を開き、画面の左上にある ［新しいチャット］ を押します。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

② 入力欄に、次の文をコピーして貼り付けます。続けて、要約したい文章をそのまま貼り付けて、送信します。

```
このあとに貼る文章を読んで、次の3つを出してください。
1. 200字の要約
2. 決まったことの一覧
3. まだ決まっていない論点の一覧。それぞれに、決めるために必要な情報を1行で添えてください
【守ってください】
・文章に書かれていないことを足さないでください。
・書かれていない点について問われたら、「文章には書かれていません」と答えてください。
・日本語で、敬体（です・ます）で書いてください。
```

→ 要約と2つの一覧が出てくれば、正しく動いています。

③ 出てきた要約を元の文章と見比べ、元にない内容が混ざっていないかを確かめます。
→ 混ざっていたら、「元の文章に書かれていない部分を消して、書き直してください」と送ります。

④ 論点の一覧から、ご自身が引き取るものに印を付けます。
→ 要約と2つの一覧が手元にそろえば、この手順は終わりです。

練習用の架空の会議メモ（実在の会議とは関係ありません）

```
学内広報検討会 記録（架空）
出席：総務課3名、学生支援課2名、こども園1名
・行事の案内を、紙とWebのどちらで出すかを話した。紙は保護者に届きやすいが、印刷の締切が早い。
・Webのお知らせを更新する担当が決まっていない。当面は総務課が受け持つことにした。
・写真の写り込みを誰が確認するかが決まっていない。
・園の掲示は文字が小さいという声があり、次回までに見本を作ることにした。
・問い合わせ窓口の電話番号を案内のどこに載せるかは、次回に持ち越した。
・欠席した課への共有の仕方が決まっていない。
```

### シナリオ6　問い合わせへの返し方をそろえる

つくるもの：想定される問い合わせへの返信例3本

① `gemini.google.com` を開き、画面の左上にある ［新しいチャット］ を押します。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

```
【書き方の約束】
・返信例は1本あたり150字以内にしてください。
```

### シナリオ8　自分の資料に質問できるようにする

つくるもの：自分の資料を読み込ませたノートブック

① ブラウザで新しいタブを開き、アドレス欄に `https://notebook.google.com/?icid=home_maincta` と入力して Enter を押します。
→ 学園のGoogleアカウントでサインインを求められたら、そのままサインインします。ノートブックの一覧が出れば、正しい画面です。

② 画面の右上にある 〈新規作成〉にあたるボタンを押します。
→ 画面の左側に「ソース」の欄が出れば、正しい画面です。

③ 左側の 〈ソースを追加〉にあたるボタンを押して、ご自身が作った資料を入れます。
→ Google ドライブのドキュメントとスライドは、ダウンロードせずにそのまま選べます。手元のファイルは、ドロップするかアップロードします。
→ 左の「ソース」の欄に資料の名前が増えていれば、読み込めています。1つのノートブックに50件まで入ります。

④ 画面の下にある質問の入力欄に、次の文をコピーして貼り付け、送信します。

```
追加した資料だけを使って、次の3つを出してください。
1. この資料の要点を5つ
2. 資料の中で、書き方がそろっていない箇所
3. この資料を読んだ人から出そうな質問を5つと、資料の中にある答え
資料に書かれていないことは、「資料には書かれていません」と答えてください。
日本語で、敬体（です・ます）で書いてください。
```

- 今日かぎりで済む用なら、前半で終わりにします。何度も引くことになりそうな資料だけを、後半でノートブックに入れます。
- 同じ資料でも、聞き方を変えると別のことが出てきます。1回で終わりにせず、2回目の質問を必ずしてください。

## 7. うまくいかないとき

| 起きること | すること |
|---|---|
| Word や PowerPoint の中に Copilot のボタンが見あたらない | アプリの中の Copilot は学園の契約に含まれていません。`m365.cloud.microsoft` のチャット画面を開き、入力欄の「＋」からファイルを添付するか、中身を貼り付けてください |
| Gemini や Gemini Notebook が開かない | 個人のGmailアカウントで入っている場合があります。右上のアイコンから、学園のGoogleアカウントに切り替えます |
| 貼った文が途中で切れる | 文章を半分に分け、2回に分けて貼り付けます |
| サイドバーに ［Flows］ が出ない | 学園のアカウントの設定によるものです。シナリオ11と13は飛ばして、別のシナリオへ進みます |
| Chrome の右上に 〈Gemini に相談〉のアイコンが出ない | 学園のアカウントの設定や、Chrome の状態によるものです。シナリオ14は飛ばして、別のシナリオへ進みます。シナリオ15は、前半を飛ばして後半（Gemini Notebook）だけでも進みます |
| 重たいPDFが Gemini Notebook に読み込めない | 必要な章だけをページを指定して保存し直し、そのファイルを入れます。または、読みたい章の文字をPDFの画面で選んでコピーし、〈テキストを貼り付け〉にあたる欄に貼り付けます |
| 〈Gemini に相談〉が、開いているページと関係ない答えを返す | パネルの入力欄に貼る文を、「いま開いているこのページだけを読んで」から書き始めてください。それでも変わらないときは、ページを読み込み直してから、もう一度押します |
| フローが、返信を自動で送ってしまわないか心配になる | 作るのは下書きだけです。〈メールを送信する〉〈返信する〉にあたるアクションを入れていなければ、メールは送られません。ステップの並びを開いて、3つのステップだけであることを確かめてください |
