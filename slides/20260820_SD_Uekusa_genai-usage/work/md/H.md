# グループH 手順書

「データ活用・集計自動化」（教員の方4名＋広報の方2名＋職員の方4名）

Excel やスプレッドシートの中で動く Copilot は、別の契約が必要です。ここでは、データを Copilot のチャットに添付するか、中身を貼ります。数式はAIに書かせて、それをご自分の手で Excel やスプレッドシートに貼って動かします。これがこのグループの中心です（シナリオ3）。

使う道具：職員の方は Copilot、教員の方は Gemini、広報の方は Canva も使えます。全員が Excel か Google スプレッドシートを開いておきます。

## 1. このグループでやること

手作業でやっている集計を、AIに手伝わせます。自由記述の分類、集計表づくり、数式づくりを、架空の研修アンケートのファイルで試します。

数字を本格的に扱うシナリオも2本あります。千葉県が公開しているデータを使ってAIの数字を検算するもの（シナリオ8）と、架空の高校別受験実績から広報の行き先を考えるもの（シナリオ9）です。

## 2. 完成イメージ

提出するものは2点です。

① 成果物（今日つくった現物）。たとえば、次のようなものです。

- 自由記述50件を分類した表と、分類ごとの件数
- 回答率と順位を入れた、報告用の集計表と、職種別・年代別の満足度の平均
- Excel やスプレッドシートで実際に動く数式が1本
- 自由記述を分類する係（エージェント、または Gem）と、その指示文の全文
- 所属ごとの回答数のグラフが1つ（Google スプレッドシート、または Canva で作ったもの）
- 千葉県の公式データで作った、人口の多い市町村10件のグラフが1つと、AIが答えた数字との違いを書き出したもの
- 高校別の受験実績に、歩留まり率・シェア・伸びの3つを入れた一覧と、広報に行く高校の候補
- （関数が使える方だけ）表の中でAIが分類を入れた列が1本と、分類ごとの件数

② インフォグラフィック（やったことを1枚の図にしたもの）。これもAIに作ってもらいます。班の名前、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つが、見て分かるように並んだ1枚です。作り方は「8. 提出します」にあります。

### 道具の開き方（各シナリオの①で使います）

② 画面の右上にあるアカウントのアイコン（丸い画像や頭文字）を見ます。
→ 学園のGoogleアカウントになっていれば、正しい状態です。個人のGmailのアカウントになっていたら、そのアイコンを押して切り替えてください。

→ しばらく「生成中」のような表示が出ることがあります。数秒待ってください。
→ `=AI()` に渡せる範囲は**1つだけ**です。そのため、分類の候補は④の D列を指すのではなく、指示の文の中に直接書き込んであります。④で候補を変えた方は、この文の中の6つの言葉も、同じものに書き換えてください。

→ 自由記述がA列ではなくI列に入っている方（xlsx を読み込んだ方）は、いちばん最後の `A2` を `I2` に書き換えてください。

→ 合っていないマスがあれば、⑥の文の中の指示を1か所だけ書き直して、入れ直します。
→ 元の自由記述は、書き換えられていないことを確かめてください。

**結果を固定します（★これをやってください）**

⑨ B2 から B51 までを選び、Ctrl キーを押しながら C を押します。続けて、**〈編集〉→〈特殊貼り付け〉→〈値のみ貼り付け〉**の順に選びます。
→ 見た目は変わりませんが、マスの中身が数式から文字に変わっていれば、正しく固定できています。B2 をクリックして、上の欄に `=AI(` ではなく分類の名前が出ていれば、変わっています。
→ 〈特殊貼り付け〉が見つからないときは、Ctrl キーと Shift キーを押しながら V を押しても、同じことができます。
→ この関数は、同じ書き方でも**返ってくる答えが変わることがあります**。報告に使う分類は、ここで文字に変えて止めておきます。

⑩ 件数を数えます。空いているマスに、次の1行を貼り付けて Enter を押します。

```

```

→ 数字が出れば、その分類が何件あったかが分かります。下にドラッグすると、6つの分類それぞれの件数が出ます。
→ 合計が50件になっているかを確かめてください。

⑪ できた表をコピーして、提出用に手元に保存します。

**知っておいていただきたいこと**

| 事がら | 中身 |
|---|---|
| 渡せる範囲 | `=AI("指示", 範囲)` の形で、範囲は**1つだけ**渡せます。1つのマスでも、`A2:D7` のような広い範囲でも構いません。 |
| 別の書き方 | `=AI(` の代わりに `=GEMINI(` と書いても、同じものが動きます。 |
| 学園のアカウント | 学園の Google アカウントでは使えません。対象のプランに入っていないためです。 |
| 個人情報 | 実在の方の回答や、氏名・連絡先が入った表では使わないでください。 |

#### 考え方の例

シナリオ1と同じ仕事を、表の中でやっています。違うのは、**結果が表の中に残る**ことです。残るぶん、あとで数えたり並べ替えたりしやすくなります。一方で、開き直すたびに答えが変わりうるので、報告に使う数字は値に変えて止めます。手ではじめから分類するのに比べれば速いのですが、**分類の名前を決めるのは人の仕事**だと考えると、使いどころがはっきりします。
