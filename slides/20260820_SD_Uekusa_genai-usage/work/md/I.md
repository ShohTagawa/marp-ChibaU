# グループI 手順書

「生成AIによる業務自動化」（教員の方1名＋職員の方13名）

使う道具：Copilot（m365.cloud.microsoft）が中心です。教員の方は Gemini を使います。

## 1. このグループでやること

毎回ゼロから書いている作業を1つ選び、それを「係」にして、同僚がそのまま使える形にします。ここでの自動化は、機械に勝手に動かせることではなく、毎回の作業を係にして配ることです。

## 2. 完成イメージ

提出するものは2点です。

① 成果物（今日つくった現物）。たとえば、次のようなものです。

- 選んだ作業を、AIに1回頼んでみた結果
- その作業をする係（エージェント、または Gem）と、その指示文の全文
- 隣の方に使ってもらって、分かりにくかったところを直した指示文
- 同僚がそのまま使える、A4で1枚の手順書

② インフォグラフィック（やったことを1枚の図にしたもの）。これもAIに作ってもらいます。班の名前、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つが、見て分かるように並んだ1枚です。作り方は「7. 提出します」にあります。

## 3. あなたの道具はどれですか

| どなたが | 使う道具 | どこで開くか |
|---|---|---|
| 職員の方（13名） | Copilot | https://m365.cloud.microsoft |
| 教員の方（1名） | Gemini と Gem | https://gemini.google.com ／ https://gemini.google.com/gems/create |

この手順書に印刷してある文は、Copilot でも Gemini でも、そのまま同じものを貼って使えます。

決まった時刻にAIを自動で動かす仕組みは、学園の契約では使えません。係を作って、使いたいときに自分で呼び出す形にします。

1台の画面を二人や数人で一緒に見ながら進めても構いません。

### 道具の開き方（各シナリオの①で使います）

**Copilot を開きます（職員の方）**

① ブラウザ（Edge や Chrome など）の新しいタブを開きます。
→ 何も表示されていない、空のタブが開けば、正しい状態です。

② アドレス欄に `https://m365.cloud.microsoft` と入力して、Enter を押します。
→ サインインを求められたら、学園の Microsoft アカウント（ふだん学園のメールで使っているもの）でサインインします。個人のアカウントでは開けません。

③ 画面の下のほうにある、文章を打ち込む横長の入力欄をクリックします。
→ 入力欄のあたりに「このチャットには エンタープライズ データ保護 が適用されます」という趣旨の表示が出ていれば、正しい画面です。

**Gemini を開きます（教員の方）**

① ブラウザの新しいタブを開き、アドレス欄に `https://gemini.google.com` と入力して、Enter を押します。
→ 画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 画面の右上にあるアカウントのアイコン（丸い画像や頭文字）を見ます。
→ 学園のGoogleアカウントになっていれば、正しい状態です。個人のGmailのアカウントになっていたら、そのアイコンを押して切り替えてください。

## 5. この手順書で使う架空データ

架空の依頼メモです。実在の行事・部署・個人とは関係がありません。ご自分の作業がすぐに思いつかないときや、実在の資料を使いたくないときに、これを題材にしてください。

### 架空データ①　通知文のもとになる依頼メモ（架空）

```
依頼メモ（架空）

・件名：館内の電気設備の点検にともなう、一部の部屋の利用停止のお知らせ
・宛先：教職員の皆さま
・日時：2026年9月14日（月）9時から17時まで
・場所：架空学園 けやき館 2階と3階
・内容：電気設備の点検のため、2階と3階の部屋を終日利用できません。1階は通常どおり使えます。
・お願い：当日は2階と3階に私物を置かないでください。前日の17時までに片づけてください。
・代わりの部屋：さくら館 1階 多目的室を、当日に限り予約なしで使えます。
・問い合わせ：架空学園 総務課（内線 0000）
```

### シナリオ1　毎週の作業を1つ選ぶ

つくるもの：係にする作業を書き出した1行

下の候補から1つ選んでください。ご自分の作業がこの中に無ければ、書き足していただいて構いません。

| 番号 | 毎回くり返している作業 | 係にすると出てくるもの |
|---|---|---|
| 1 | 問い合わせへの返信 | 返信メールの下書き |
| 2 | 教職員向けの通知文 | 通知文と、確認が必要な点の一覧 |
| 3 | 会議の議事メモの整理 | 決まったこと・決まっていないこと・次にすること |
| 4 | 名簿の整形 | 決まった列の並びにそろえた表 |
| 5 | 日程調整の連絡文 | 候補日を並べた依頼文 |
| 6 | 報告書の下書き | 決まった見出しに沿った下書き |
| 7 | マニュアルの更新 | 変わった箇所だけを書き直した文 |
| 8 | 資料の要約 | 200字の要約と、論点の一覧 |
| 9 | 英語の文書の翻訳 | 日本語訳と、訳しにくかった箇所の注 |
| 10 | 掲示物の文言づくり | 見出しと、3行までの本文 |

① 上の表から、ご自分が毎回くり返している作業を1つ選び、番号に印を付けます。
→ 選べないときは、2番の「教職員向けの通知文」を選んでください。この手順書には、その題材の架空データが印刷してあります。

② 選んだ作業について、次の3つを、手元の紙かメモ帳に1行ずつ書き出します。
→ 「何を受け取るか」「何を出すか」「出したものを誰が読むか」の3つです。
→ 例：受け取るものは依頼メモ、出すものは通知文、読む人は教職員の皆さま。

③ 書き出した3行を、そのまま次のシナリオで使います。
→ 3行が書けていれば、次に進めます。

### シナリオ2　その作業をAIに頼んでみる

つくるもの：選んだ作業を、AIに1回頼んでみた結果

AIへの頼み方は、次の4つを書くと安定します。下の文は、この4つがそろった形になっています。

| 要素 | 何を書くか | 下の文のどこか |
|---|---|---|
| 役割 | AIに何者として答えてほしいか | 1行目 |
| 課題 | してほしいこと | 2行目 |
| 背景情報 | 相手・場面・条件 | 【材料】のところ |
| 出力形式 | 長さ・文体・構成 | 【書き方の約束】のところ |

① Copilot を開きます（教員の方は Gemini を開きます。開き方は「3. あなたの道具はどれですか」にあります）。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 次の文を、省略せずにそのままコピーして、入力欄に貼り付けます。

```
あなたは学校法人の事務職員です。
このあとに貼る依頼メモをもとに、教職員に向けた通知文を1本書いてください。
【材料】
・材料は、このすぐあとに貼る依頼メモだけです。
・読む人は、学園の教職員の皆さまです。
【書き方の約束】
・400字以内にしてください。
・日本語で、敬体（です・ます）で書いてください。
・体言止めを使わないでください。
・件名、本文、問い合わせ先の順に書いてください。
・日時、場所、代わりの部屋、問い合わせ先は、依頼メモのとおりに写してください。言い換えないでください。
・依頼メモに書かれていないことを足さないでください。分からないところは〔要確認〕と書いてください。
・最後に、こちらで確かめたほうがよい点を、箇条書きで3つまで添えてください。
依頼メモは次のとおりです。
```

③ 続けて、上の架空データ①を、そのままコピーして貼り付けます。ご自分の作業で試す場合は、代わりにご自分の材料を貼ります。
→ 貼ってよいのは、公開されている資料か、ご自分が作った資料に限ります。学生・園児・生徒・利用者・教職員の個人情報や、未公開の学内資料は貼りません。

④ 入力欄の右にある送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ 件名から始まる通知文が表示されれば、正しく動いています。

⑤ 出てきた通知文の、日時・場所・代わりの部屋・問い合わせ先を、架空データ①と1つずつ見比べます。
→ 違う内容が入っていたら、「日時は2026年9月14日の9時から17時までです。直してください。」のように、正しい内容を書いて続けて送ります。

⑥ ご自分の作業に置き換えるときは、上の表の4つの要素にあたる箇所を書き換えます。
→ 1行目の役割、2行目の課題、【材料】、【書き方の約束】の4か所を書き換えれば、別の作業にそのまま使えます。

### シナリオ3　係（エージェント）を作る

つくるもの：エージェント（または Gem）と、その指示文の全文

エージェントとは、指示をあらかじめ仕込んでおける、自分専用の Copilot のことです。一度作れば、毎回長い指示を打ち直さずに使えます。教員の方は、同じものを Gem（自分専用の Gemini）として作れます。

① Copilot を開きます。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。
→ 教員の方は、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` と入力して、Enter を押します。名前を入れる欄と、指示を入れる大きな欄が並んだ画面が出れば、正しい画面です。

② 画面の左側のサイドバーで、〈エージェント〉にあたる並びを探します。
→ 「Idea Coach」「新しいエージェント」「その他のエージェント」といった名前が並んでいれば、正しい場所です。

③ ［新しいエージェント］にあたる項目を押します。
→ 自分専用のエージェントを作る画面（Build your own specialist agent という趣旨の画面）が出れば、正しい画面です。
→ 「テンプレート」と「自分のエージェント」という2つのタブが出ることがあります。その場合は「テンプレート」の側から進みます。
→ 名前を入れる欄と、指示を入れる大きな欄が見つからないときは、この手順を飛ばして、シナリオ2の文を毎回貼る形で進めてください。

④ 「名前」にあたる欄に、次のように入力します。〔　〕は1か所だけです。ご自分の部署名を入れてください。

```
〔 総務課 〕の通知文づくり係
```

⑤ 「指示」にあたる大きな欄に、次の文を、省略せずにそのままコピーして貼り付けます。〔　〕は1か所だけです。同じく部署名を入れてください。

```
あなたは学校法人植草学園の〔 総務課 〕の事務職員です。教職員に向けた通知文の下書きを作る係です。
【受け取るもの】
・依頼メモ、または箇条書きの走り書きです。
【やること】
1. 受け取ったメモから、件名、日時、場所、内容、お願いしたいこと、問い合わせ先を拾って並べます。
2. そのうえで、通知文の下書きを1本書きます。
3. 最後に、こちらが確認しなければならないことを、箇条書きで3つまで並べます。
【書き方】
・400字以内にします。
・日本語で、敬体（です・ます）で書きます。体言止めを使いません。
・件名、本文、問い合わせ先の順に書きます。
・1つの文は60字以内にします。
・専門用語には、短い言い換えを添えます。
【守ること】
・日時、場所、金額、締切、問い合わせ先は、受け取ったメモのとおりに写します。言い換えません。
・メモに書かれていないことを足しません。分からないところは〔要確認〕と書いて残します。
・氏名、電話番号、住所、学籍番号は本文に書きません。〔　〕にして残します。
・学生、園児、生徒、利用者の個人にかかわることは書きません。
・「革命」「激変」のような、あおる言葉を使いません。
最初のやり取りでは、「依頼メモを貼ってください。」とだけ返します。
```

⑥ 〈作成〉または〈保存〉にあたるボタンを押します。
→ 作った係の名前が、画面の左側の一覧に増えていれば、保存できています。

⑦ チャットの入力欄で「＠」を入力し、作った係の名前を選びます。
→ 入力欄のあたりに、その係の名前が付いた状態になれば、正しい状態です。

⑧ 上の架空データ①を、そのままコピーして貼り付け、送信ボタンを押します。
→ 通知文の下書きと、確認が必要な点の一覧が返ってくれば、係として動いています。

### シナリオ4　隣の人に使ってもらう

つくるもの：分かりにくかったところを直した指示文

① シナリオ3で作った係を開いた状態で、パソコンを隣の方に渡します。
→ 入力欄のあたりに、係の名前が付いた状態になっていれば、正しい状態です。

② 隣の方に、上の架空データ①を貼って送っていただきます。作った方は、口を出さずに画面を見ます。
→ 隣の方が、どこで手が止まったかを見ておきます。

③ 隣の方に、次の2つを声に出して言っていただきます。
→ 「何を貼ればよいか、すぐに分かったかどうか」と、「返ってきた文をそのまま出せるかどうか」の2つです。

④ 言われたことのうち1つを、指示文に書き足します。〈編集〉にあたるボタンから「指示」の欄を開き、次のような1行を足します。

```
最初のやり取りでは、依頼メモに入れてほしい項目（件名、日時、場所、内容、お願いしたいこと、問い合わせ先）を並べて示してから、「依頼メモを貼ってください。」と返します。
```

→ 保存にあたるボタンを押して、もう一度隣の方に使っていただきます。

⑤ 直した指示文を、省略せずに全文コピーして、手元の Word かメモ帳に貼って保存します。
→ この全文が、提出する成果物になります。

### シナリオ5　手順書を1枚つくる

つくるもの：同僚がそのまま使える、A4で1枚の手順書

下のひな形を、そのまま使ってください。〔　〕を埋めれば、1枚の手順書になります。

① 下のひな形を、省略せずにそのままコピーして、手元の Word かメモ帳に貼り付けます。

```
────────────────────────────────
〔 係の名前 〕手順書

1. 何をする係ですか
　〔 例：依頼メモから、教職員向けの通知文の下書きを作る係です。 〕

2. どこを開きますか
　〔 例：https://m365.cloud.microsoft を開き、学園のアカウントでサインインします。
　　　入力欄で「＠」を押し、「総務課の通知文づくり係」を選びます。 〕

3. 何を入力しますか
　〔 例：依頼メモを貼ります。件名、日時、場所、内容、お願いしたいこと、
　　　問い合わせ先の6つが入っていれば、そのままで構いません。 〕

4. 出てきたものを、どう確かめますか
　〔 例：日時、場所、問い合わせ先が、依頼メモのとおりかを1つずつ見比べます。
　　　〔要確認〕と書かれた箇所を、自分の言葉で埋めます。
　　　そのまま送らずに、必ず一度読み直します。 〕

5. 入れてはいけない情報
　・学生、園児、生徒、利用者の個人情報（氏名、学籍番号、連絡先、成績、健康情報）
　・教職員の個人情報、人事に関する情報
　・未公開の学内資料（入試問題、決裁前の文書、契約書）

6. うまくいかないときの連絡先
　〔 例：総務課　内線 0000 〕
────────────────────────────────
```

② 1番から4番までの〔　〕を、ご自分が作った係の内容に書き換えます。
→ 5番はそのまま残してください。

③ 2番に、係を呼び出すときの操作を、実際の画面のとおりに書き足します。
→ ご自分がシナリオ3でたどった手順を、そのまま写せば十分です。

④ 書き上げた手順書を、隣の方に読んでいただきます。
→ 読んだだけで係を呼び出せれば、そのまま配れる手順書になっています。

⑤ 手順書をA4で1枚に収め、ファイルとして保存します。
→ 1枚に収まらないときは、4番の例を1つに減らします。

## 8. うまくいかないとき

| 起きていること | すること |
|---|---|
| Word や Outlook の中に Copilot のボタンが見つからない | アプリの中の Copilot は、別の契約が必要です。`https://m365.cloud.microsoft` のチャット画面を使い、ファイルは入力欄の「＋」から添付します。 |
| 決まった時刻に自動で動かしたい | 学園の契約では、決まった時刻に動かす仕組みは使えません。係を作って、使いたいときに「＠」で呼び出す形にします。 |
| 「＠」を押しても係が出てこない | 画面を再読み込みします。それでも出てこないときは、係の画面を開いて、そこから直接使います。 |
| 係が指示どおりに動かない | 「指示」の欄に、守ってほしいことを1行だけ足して保存し、もう一度試します。 |
| 文を貼っている途中で送信されてしまう | 改行は Shift キーを押しながら Enter キーを押して入れます。 |
