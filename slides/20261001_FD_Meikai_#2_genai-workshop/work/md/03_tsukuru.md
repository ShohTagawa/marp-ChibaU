# ③ 全く新しい授業課題を作る

使う道具：Gemini アプリ・Gem・Gemini Notebook

## 1. この章でやること

学生が生成AIを使える前提で、これまで出せなかった授業課題を作ります。手元に残るのは、学生に配る課題文と作業の手順、役を演じる Gem（ジェム。指示を仕込んでおける自分専用の Gemini）とその指示文、演習の進め方を書いた授業案、課題の評価基準の表です。作ったものは、ご自身の専門の目で見て判定し、直したうえで持ち帰ります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）**　たとえば、次のようなものです。

- 学生に出す課題文と、その課題で学生が行う作業の手順（シナリオ1）
- 買主・借主・自治体の担当者などの役を演じる Gem と、その「指示」の欄の文章（省略せず全文）（シナリオ2）
- 学生が役の Gem と対話したあとに「自分の言葉で書く答え」を提出する演習の、授業案1枚（シナリオ3）
- 課題の評価基準の表（観点4つ × 段階4つ）（シナリオ4）

**② インフォグラフィック（やったことを1枚の図にしたもの）**　作り方は共通ページをご覧ください。

## 3. シナリオ一覧

気になるものから始めてください。4本は独立していますので、どれから始めても進みます。シナリオ3は、シナリオ2で作った Gem をそのまま使うと、すぐに始められます。

| 番号 | シナリオ | つくるもの |
|---|---|---|
| 1 | 少し遠くまで行ける課題をつくる | 学生に出す課題文と、学生が行う作業の手順 |
| 2 | 役を演じる Gem をつくる | 買主・借主・自治体の担当者を演じる Gem と、指示文の全文 |
| 3 | 役割演技の演習を組み立てる | 演習の進め方を書いた授業案1枚 |
| 4 | ルーブリックをつくる | 課題の評価基準の表 |

実在の学生・顧客・取引の当事者・物件・会社の情報は、どの画面にも入力しません。例が必要なときは、架空の設定で行います。役を演じる Gem も、すべて架空の人物として作ります。

### シナリオ1　少し遠くまで行ける課題をつくる

つくるもの：学生に出す課題文と、その課題で学生が行う作業の手順

① 手元の紙に、「この授業で学生に体験してほしいこと」を1行だけ書きます。
→ 「◯◯ができるようになってほしい」ではなく、「◯◯を体験してほしい」という言い方で書くと、あとの手順が進みやすくなります。

② ブラウザ（Chrome など）で新しいタブを開き、アドレス欄に `gemini.google.com` と入力して Enter を押します。
→ 画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。
→ 右上の丸いアイコンに大学のメールアドレスが出ていることを確かめてください。個人のGmailになっていたら、そこから大学のアカウントに切り替えます。

③ 画面の左側にある 〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と、「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力して Enter を押してください。
→ 「名前」を入れる欄と、「指示」を入れる大きな欄が並んだ画面が出れば、正しい画面です。

④ 「名前」の欄に、次のとおり入力します。

```
課題づくりの相談相手
```

→ 名前の欄に文字が入っていれば、正しい状態です。

⑤ 「指示」の大きな欄に、次の文をすべてコピーして貼り付けます。埋めるところはありません。そのまま貼れば動きます。

```
# あなたの役割
あなたは、不動産学部（経済・法律・建築や都市・語学など、専門の異なる教員がいます）で教える教員の、相談相手です。
教員が学生に出す課題を、いまより少し遠くまで行ける課題に練り上げることが、あなたの仕事です。
教員の代わりに課題を決めるのではなく、教員が自分で決められるように材料を出してください。

# 進め方（この順番で行ってください）
1. 最初に、次の3つを教員に質問してください。3つまとめて聞いて、答えを待ってください。
   ・学生に体験してほしいことは何ですか。
   ・いま出している課題は何ですか。
   ・その課題に学生が使える時間は、授業の中ですか、授業の外ですか。
2. 答えを受け取ってから、課題案を3つ作ってください。3つとも、学生が生成AIを使ってよい前提で考えてください。生成AIがあることで、これまで学部生には手が届かなかった到達点を狙ってください（例：複数の物件データを比べて活用提案を1枚にまとめる、契約書の条文を読み比べて依頼者に説明する）。3つは、学生が届く距離を変えてください。
   ・案1は、いまの課題を少し広げたものにしてください。
   ・案2は、実務で実際に起きる条件を1つ足したものにしてください。
   ・案3は、学生自身が問いを立てるものにしてください。
3. 案ごとに、次の4つを1行ずつ書いてください。
   ・学生が実際に行う作業
   ・学生が使う資料や道具
   ・学生がつまずきそうなところ
   ・教員が評価のために受け取る提出物
4. 最後に、3つのうちどれを勧めるかを、理由を3文添えて書いてください。

# してはいけないこと
・実在の学生・顧客・取引の当事者・物件・会社の情報を扱わないでください。例が必要なときは、架空の設定にしてください。
・確かめられない文献名・URL・統計・法令の条文を書かないでください。確かでないことは「確認が必要です」と書いてください。
・手書きでの提出を学生に強制する案は出さないでください。
・学生に生成AIの利用を強制する案は出さないでください。
・一度に出す案は3つまでにしてください。

# 書き方の約束
・日本語で、敬体（です・ます）で書いてください。
・体言止めを使わないでください。
・「革命」「激変」のような、あおる言葉を使わないでください。
・前置きを付けずに、本文だけを書いてください。
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。

⑥ 画面の ［保存］ にあたるボタンを押します。
→ Gem の一覧に「課題づくりの相談相手」が並んで見えれば、保存できています。試しに使っただけでは保存されませんので、必ず押してください。

⑦ 保存した「課題づくりの相談相手」を開いて、入力欄に次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の2か所だけです。

```
学生に体験してほしいことは〔　　　　　　　　　　〕です。
いま出している課題は〔　　　　　　　　　　〕です。
この2つをもとに、課題案を3つ作ってください。
```

→ 「いま出している課題」が手元に無いときは、記憶で書き直したもので構いません。それも難しいときは、下の架空の例から1つ選んで貼ってください。

| 分野 | 架空の課題文の例 |
|---|---|
| 経済系 | 授業で配った架空の市の人口・地価・家賃の表を読み、家賃が上がった理由を2つ挙げて説明しなさい。 |
| 法学系 | 授業で配った架空の賃貸借契約書を読み、借主にとって注意が必要な条文を3つ選び、理由を書きなさい。 |
| 工学系 | 授業で配った架空の敷地条件をもとに住宅の配置図を描き、日当たりと騒音についての工夫を説明しなさい。 |
| 語学系 | 授業で配った英語の物件案内文を日本語に訳し、日本の物件案内と表現が違う点を3つ挙げなさい。 |

→ 案1・案2・案3が並び、それぞれに「学生が実際に行う作業」などの4行が付いていれば、正しく動いています。
→ 3つの案が出ずに質問だけが返ってきたときは、その質問に答えてから、もう一度「案を3つ作ってください」と送ってください。

⑧ 3つの中から1つを選んで、次の文を送信します。

```
案〔1〕を選びます。この課題を、学生にそのまま配れる課題文にしてください。あわせて、学生が最初に行う作業を、学生が読んで動ける手順の形で書いてください。
```

→ 課題文と、学生向けの手順が並んで出てくれば、この手順は終わりです。
→ 出てきた課題文は、ご自身の専門の目で読み、直すところがあれば「〔直す箇所〕を〔こう〕直してください」と送って直してから持ち帰ります。

→ 共有の範囲を選ぶ画面が出れば、正しい画面です。範囲は「組織内」、権限は「閲覧者」を選びます。「編集者」にすると学生が指示文を書き換えられますので、「閲覧者」のままにしてください。

→ 共有について貴学の方針があれば、それを優先してください。共有ができないときは、「指示」の欄の文章を全文配れば、学生が自分の手元に同じ Gem を作れます。

### シナリオ3　役割演技の演習を組み立てる

つくるもの：学生が役の Gem と対話したあと「自分の言葉で書く答え」を提出する演習の、授業案1枚

① シナリオ2で作った役の Gem を1つ開きます。まだ作っていないときは、シナリオ2の①〜④で1つだけ作ってから戻ります。
→ 画面の上のほうに、自分が付けた名前が出ていれば、その役と話している状態です。

② 入力欄に `はじめてください。` と送ります。
→ 役から話しかけてくれば、正しく動いています。

③ 学生になったつもりで、返ってきた発言にご自身の言葉で答えて送ります。これを3回続けます。
→ 役から、さらに質問が返ってくれば、会話が続いています。

④ 次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の1か所だけです。

```
ここまでのやりとりについて、〔買主〕の立場から納得できない点を3つ挙げて、反論してください。遠慮はしないでください。反論のあとに、どこまでなら納得できたかを1文で書いてください。
```

→ 反論が3つと、納得できた範囲の1文が返ってくれば、正しく動いています。
→ ここまでの①〜④が、学生に授業で行ってもらう作業です。次の⑤で、これを学生に配る手順の形にします。

⑤ 画面の左上にある ［新しいチャット］ を押し、入力欄に次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の2か所だけです。

```
次の演習の授業案を、A4で1枚に収まる長さで作ってください。

・科目は〔　　　　　　　　　　〕です。
・学生が対話する相手と、学生自身の役は次のとおりです：〔例：相手＝中古マンションの買主を演じる Gem、学生＝不動産会社の担当者〕
・Gem（指示を仕込んでおける自分専用の Gemini）は教員が作って、共有リンクで学生に配ります。

【授業案に入れるもの】この順番で、見出しを付けて書いてください。
1. 授業の進め方。教員が行うことを、授業の前・授業中・授業のあとに分けて、それぞれ箇条書きで書いてください。授業の前に、Gem の共有リンクを学生に配ることを入れてください。
2. 学生に配る手順。学生がそのまま読んで動ける形で、番号を付けて書いてください。次の4つを必ず入れてください。
   ・Gem を開いて「はじめてください。」と送る
   ・相手の発言に自分の言葉で答える、を3回以上続ける
   ・「ここまでのやりとりについて、あなたの立場から納得できない点を3つ挙げて、反論してください」と送る
   ・反論を読んだうえで、相手への説明を自分の言葉で書き直す（400字ほど）。AIに書かせた文をそのまま出さない
3. 提出するもの。やりとりの記録（画面のコピーか、文章のコピー）と、自分の言葉で書き直した説明の2点にしてください。
4. 学生への注意。実在の人物・物件・会社の情報を入力しないこと、Gem の答えを事実として扱わず自分で確かめること、の2つを書いてください。

【書き方の約束】
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・確かめられない法令名・数値・文献を書かないでください。必要なところは「〔教員が確認〕」と書いてください。
・「革命」「激変」のような、あおる言葉を使わないでください。
・前置きを付けずに、本文だけを書いてください。
```

→ 「授業の進め方」「学生に配る手順」「提出するもの」「学生への注意」の4つの見出しが並んで出てくれば、正しく動いています。

⑥ 出てきた授業案を、ご自身の専門の目で読み、直すところがあれば次の文を送ります。埋めていただくのは〔　〕の1か所だけです。

```
いまの授業案のうち、次の箇所を直してください。
〔直す箇所と、直す理由〕
直したうえで、どこをどう直したかを1文ずつ書いてください。他の箇所は変えないでください。
```

→ 直った授業案をコピーして、Google ドキュメントに貼り付けます。「授業の前」のところに、シナリオ2の⑧で得た Gem の共有リンクを書き足せば、この手順は終わりです。

学生に配る手順の中で「画面のコピー」を求めるときの撮り方（Windows の場合）：キーボードの Windows キー ＋ Shift ＋ S を同時に押し、撮りたい範囲をドラッグで囲みます。Mac の場合は command ＋ shift ＋ 4 です。

### シナリオ4　ルーブリックをつくる

つくるもの：課題の評価基準の表（観点4つ × 段階4つ）

① `gemini.google.com` を開き、大学の Google アカウントでサインインします。
→ 画面の下に横長の入力欄が見えていれば、正しい画面です。

② 画面の左上にある ［新しいチャット］ を押します。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

③ 入力欄に、次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の2か所だけです。

```
次の課題を評価するルーブリック（評価の観点と段階を組み合わせた表）を作ってください。

・読み手は〔　　　　　　　　　　〕の学生です。
・課題の内容は〔　　　　　　　　　　〕です。

【表の条件】
・評価の観点を4つにしてください。観点には、専門用語の使い方と、根拠（資料・データ・条文）の示し方を必ず入れてください。
・段階を4つにしてください。段階の名前は「たいへんよい」「よい」「もう一歩」「これから」にしてください。
・観点と段階が交わるマスには、提出物に何が書かれていればその段階になるのかを、1文で書いてください。
・観点ごとの配点を、合計が100点になるように付けてください。
・表のあとに、学生に配るときの説明を、敬体で3行付けてください。

【守ってください】
・実在の学生・顧客・取引の当事者・物件・会社の情報は扱わないでください。例が必要なときは、架空の設定にしてください。
・確かめられない法令名・数値・文献を書かないでください。
・日本語で書いてください。体言止めを使わないでください。
・「革命」「激変」のような、あおる言葉を使わないでください。
```

→ 「課題の内容」が手元に無いときは、シナリオ1の⑦にある架空の課題文の例から1つ選んで貼ってください。
→ 観点が縦、段階が横に並んだ表が出れば、正しく動いています。

④ 出てきた表に、観点が4つ、段階が4つそろっているかを目で確かめます。足りないときは、同じ画面で「観点を4つ、段階を4つにして作り直してください」と送ります。
→ 4つ×4つの表になっていれば、正しい状態です。

⑤ 次の文を送って、例を足します。

```
各段階に、学生の提出物でよく見られる例を1つずつ足してください。例はすべて架空のものにしてください。
```

→ 各マスに例が1つずつ付いていれば、正しく動いています。

⑥ 表のマスを1つずつ、ご自身の専門の目で判定して直します。専門用語の使い方や根拠の示し方が、この分野の作法から外れているマスを見つけたら、次の文を送ります。埋めていただくのは〔　〕の1か所だけです。

```
いまの表のうち、次のマスを直してください。
〔直すマス（観点と段階）と、この分野の作法から外れている理由〕
この分野で通用する言い方に直したうえで、どこをどう直したかを1文ずつ書いてください。他のマスは変えないでください。
```

→ 直した表と、直した箇所の説明が並んで出てくれば、正しく動いています。直すマスが無くなるまで、同じ文で繰り返します。
→ 直った表をコピーして、Google ドキュメントに貼り付けます。表の形のまま貼り付けられていれば、この手順は終わりです。

## 4. 提出します

提出するものは2点です。2点そろわなくても提出してください。詳しくは共通ページをご覧ください。

## 5. うまくいかないとき

| 起きること | すること |
|---|---|
| Gem の一覧に、作った Gem が出ない | ［保存］を押していないことが多いです。もう一度作成画面に戻り、［保存］を押します。それでも出ないときは、ブラウザの画面を再読み込みします |
| 役の Gem が、客や担当者ではなく教員のような話し方で返す | 「あなたは説明を受ける側です。相手が望む答えをすぐには言わないでください」と送ります |
| 〈共有〉にあたる項目が見つからない | 「指示」の欄の文章を全文コピーして学生に配ります。学生が自分の手元に同じ Gem を作れます |
| 答えが長すぎて読み切れない | 「3つに絞って、短く書いてください」と送ります |
