## はじめに

グループの方と教え合いながら、進めて下さい。二人や数人で、1台のPCに入力する形でも、全員が生成AIを使う形でも、構いません。

前半で聞いた話を、ご自身の関心近いところで1回試してみます。うまくいかなくても大丈夫です。「試した」ということが、今日の成果です。

この時間のゴールは、ひとつだけです。

> **自分の仕事を助けてくれるAIやアイデアを1つ作って、同僚に配れる状態にして帰ること。**

完璧なものでなくて構いません。作りかけでも、提出してください。

**注意点：機密情報・個人情報は生成AIや共有する資料には入れないようにお願い致します。**

## いちばん大事なルール：困ったら、この紙をAIに貼って聞く

手が止まったら、この手順書の困っているところを、そのままコピーしてAIに貼ってください。そして、こう聞いてみてください。

```
いまこの手順に取り組んでいます。
〔ここに手順書の該当箇所を貼る〕
〔　　　　　〕のところで詰まりました。
次に何をすればよいか、パソコンに詳しくない人にも分かるように、順番に教えてください。
```

これは「ずるい方法」ではありません。本日、いちばん練習してほしいことです。やりたいことを実現する過程で、AIをどんどん使ってください。

**相談の順番：隣の人に聞く → AIに聞く → 手を挙げる**

AIへの入力とその回答を周囲の方と共に、試行錯誤することが、最初期では、最もよい学び方だと講師は感じます。そのうち、YouTubeで調査したり、AIに尋ねれば使えるようになります。自分がいなくてもうまくいくのが、到達点です。

## AIへの頼み方の基本（4つの要素）
うまく答えが返らないときは、次の4つが書けているかを確かめてください。

| 要素 | 書くこと | 例 |
|---|---|---|
| 役割(ペルソナ) | AIに何者として答えてほしいか | あなたは大学の広報担当です。 |
| 課題(タスク) | してほしいこと | 案内文の下書きを作ってください。 |
| 背景情報 | 相手・場面・条件 | 読み手は高校2年生と保護者です。8月◯日、本学さくらホールで開催します。 |
| 出力形式 | 長さ・文体・構成 | 300字程度、敬体、最後に申込先を1行。 |

人に仕事を頼むときと同じ書き方です。新人の方に頼むつもりで書くと、ちょうどよい詳しさになります。出力方法の見本を1つ付けると、さらに安定します。

## 今日、AIに入れてはいけないもの
- 学生・園児・生徒・利用者の個人情報（氏名、学籍番号、連絡先、成績、健康情報）
- 教職員の個人情報、人事に関する情報
- 未公開の学内資料（入試問題、決裁前の文書、契約書）
今日は、公開されている情報か、手順書に印刷してある架空のデータで実施して下さい。
会議の録音や議事録も、機密でないもので練習してください。

Canvaを使える方は、Canvaで作るのもおすすめです。Gemini Notebookでの作り方は、「はじめに」にあります。
Gemini上のNanobanana（Geminiを開いて、画像を作成を押す）で「インフォグラフィック」の作成を依頼するのでもOKです。
十分なファイル（実施したメモ）や出来上がった内容をAIに読み込ませたうえで、解答をするようにしましょう。

| 道具 | 作り方 |
|---|---|
| Copilot | 「画像の作成」、または「作成ハブ（ストーリー）」に5項目を渡します。詳細は「はじめに」にあります。 |
| Gemini | チャット左下のプラスボタンから、画像生成、または Canvas で1枚にまとめます |
| Notebook | 十分な情報をソースに入れたうえで、インフォグラフィックを選択し、プロンプトを入力します。 |
| Canva | マジック生成とテンプレートで仕上げます（いちばん見栄えがします） |

**★ Canva でテンプレートを探すとき**

Canva は、無料のプランのままでもテンプレートを選んでインフォグラフィックを作れます。
（Canva for Education は、幼稚園から高校までの先生と生徒が対象です。大学・短期大学の職員は対象外の可能性がありますので、無料のプランで進められる形にしてあります。）

① Canva を開き、画面の上のほうにある検索の欄に、次のどれかを入力して Enter を押します。

　インフォグラフィック ／ 報告会 ／ 掲示

→ テンプレートが並んだ画面が出れば、正しい画面です。
→ 「インフォグラフィック」は、見出しと短い文の枠が縦に並ぶ型が多い言葉です。「報告会」は、やったことと分かったことを並べる型です。「掲示」は、1枚で貼り出す前提の型で、文字が大きめです。
→ 目当てのものが出ないときは、「学校紹介」「ポスター」「一覧」でも探せます。

② 右下に王冠のマークが付いていないテンプレートを選んで押します。
→ 王冠のマークは有料の印です。王冠の付いた素材を残したままだと、ダウンロードできません。
→ 無料のものだけを見たいときは、検索の欄の近くにある〈フィルター〉にあたるボタンから「無料」を選びます。

③ 文字の部分を押して、班の名前、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つに書き換えます。
→ 5つがそろっていれば、提出できる中身になっています。

④ ページが何枚もあるときは、使わないページを消して、1枚だけ残します。
→ ページの一覧に1枚だけ残っていれば、正しい状態です。

⑤ 画面の右上にある〈共有〉にあたるボタンを押し、〈ダウンロード〉にあたるボタンを押します。
→ ファイルの種類を選ぶ欄が出れば、正しい画面です。

⑥ ファイルの種類を PNG にして、〈ダウンロード〉にあたるボタンを押します。
→ ページがまだ複数あるときは、「すべてのページ」と出ているところを押して、〈ページを選択〉にあたる項目から、出したい1ページだけにチェックを入れてください。
→ お金の支払いを求める画面が出たときは、有料の素材（右下に王冠のマークが付いているもの）がデザインの中に残っています。その素材を消すか、王冠のマークが付いていない別のテンプレートを選び直してください。
→ ファイルがパソコンに保存されれば、上のスライドに貼り付けられます。
