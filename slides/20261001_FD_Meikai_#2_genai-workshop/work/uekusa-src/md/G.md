# グループG 手順書

「Microsoft 365 Copilot活用」（教員の方3名＋広報の方5名＋職員の方14名＝22名）

Word や Excel の中で動く Copilot は、別の契約が必要です。ここでは、いま使えるCopilotで試します。

使う道具：Copilot（m365.cloud.microsoft）が中心です。教員の方は Gemini でも同じ文をそのまま使えます。

> **★ 今日は、メールにつながるエージェント（Mail Pro など）は使いません。本物のメールが動いてしまうためです。**

## 1. このグループでやること

問い合わせへの返信、議事メモの整理、長い文書の要約といった、ふだんの仕事そのものを Copilot に手伝わせて、どこまで進むかを確かめます。

## 2. 完成イメージ

提出するものは2点です。

① 成果物（今日つくった現物）。たとえば、次のようなものです。

- 問い合わせメールへの返信の下書き（400字以内）
- 走り書きのメモから整えた議事メモ（決まったこと／決まっていないこと／次にすること）
- 長い文書の要約200字と、話し合うべき論点の一覧
- 自分の部署用の係（エージェント、または Gem）と、その指示文の全文
- 添付した資料の要約と、見出しの付け直し案
- 掲示物にのせる挿絵1枚、または6枚以内のストーリー
- Webで調べてもらった内容と、自分の目で開いて確かめたページのURL
- フラッシュカード、空欄補充問題、一致のうち1つ
- 課題を評価するルーブリック1枚
- かたい案内文を、やさしい言い回しに書き直したもの
- 記入例の入った Excel のブック1つ
- 学生が「AIの使い方を教える教材」を作る、授業内のワークの手順書1本
- エージェントを入れる前に確かめた3点のメモと、直してもらった頼み方の文
- 学生に配れる学習素材1つ（理解する、フラッシュカード、テストなど）
- 開いているページについて聞いた答えと、そのページのURL

② インフォグラフィック（やったことを1枚の図にしたもの）。これもAIに作ってもらいます。班の名前、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つが、見て分かるように並んだ1枚です。作り方は「7. 提出します」にあります。

## 3. あなたの道具はどれですか

| どなたが | 使う道具 | どこで開くか |
|---|---|---|
| 職員の方（14名） | Copilot | https://m365.cloud.microsoft |
| 広報の方（5名） | Copilot と Canva | https://m365.cloud.microsoft ／ https://www.canva.com |
| 教員の方（3名） | Gemini と Gemini Notebook | https://gemini.google.com ／ https://notebook.google.com/?icid=home_maincta |

この手順書に印刷してある文は、Copilot でも Gemini でも、そのまま同じものを貼って使えます。

1台の画面を二人や数人で一緒に見ながら進めても構いません。

### 道具の開き方（各シナリオの①で使います）

**Copilot を開きます（職員の方・広報の方）**

① ブラウザ（Edge や Chrome など）の新しいタブを開きます。
→ 何も表示されていない、空のタブが開けば、正しい状態です。

② アドレス欄に `https://m365.cloud.microsoft` と入力して、Enter を押します。
→ サインインを求められたら、学園の Microsoft アカウント（ふだん学園のメールで使っているもの）でサインインします。個人のアカウントでは開けません。

③ 画面の下のほうにある、文章を打ち込む横長の入力欄をクリックします。
→ 入力欄のあたりに「このチャットには エンタープライズ データ保護 が適用されます」という趣旨の表示が出ていれば、正しい画面です。

**Gemini を開きます（教員の方）**

① ブラウザの新しいタブを開き、アドレス欄に `https://gemini.google.com` と入力して、Enter を押します。
→ 画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 画面の右上にあるアカウントのアイコン（丸い画像や頭文字）を見ます。
→ 学園のGoogleアカウントになっていれば、正しい状態です。個人のGmailのアカウントになっていたら、そのアイコンを押して切り替えてください。

## 5. この手順書で使う架空データ

すべて架空です。実在の会議・行事・個人とは関係がありません。実在の学生・教職員の個人情報や、未公開の学内資料は入力しません。

### 架空データ①　議事メモ（架空）

```
学園見学の受け入れ手順　見直し打合せ　メモ（架空）

出席：総務系2名、教務系2名、広報系1名
場所：本館の小会議室

・見学の申込がメールと電話に分かれていて、受付の記録が2か所にある。
・メールは共有アドレスに届くが、誰が返信したかが分からない。
・電話は用紙に書いて回しているが、用紙が見当たらないことがある。
・先月の申込は32件。うち団体が7件、個人が25件。
・団体は人数の確定が直前になるため、部屋の割り当てが決まらない。
・個人は当日のキャンセルが多い。前日の連絡は入れていない。
・返信の文面が担当者ごとに違う。持ち物の案内が入っていないことがある。
・駐車場の台数を聞かれることが多いが、案内に書いていない。
・雨天のときの集合場所を聞かれることが多い。
・申込フォームを1本にする案が出た。反対はなかった。
・フォームにする場合、電話で申し込む方の入力を誰が代行するかが決まっていない。
・返信の定型文を作ることになった。担当は総務系。
・持ち物、集合場所、駐車場、雨天のときの扱いの4点を定型文に入れる。
・前日の確認連絡を入れるかどうかは次回に持ち越しになった。
・記録の置き場所は共有フォルダに1本化する。フォルダ名は次回に決める。
・過去の申込記録は移さず、今後の分だけ新しい場所に置く。
・団体の人数確定の締切を、見学日の3日前にする案が出た。
・締切を過ぎた変更の扱いは決まらなかった。
・次回は、定型文の案と、フォームの項目案を持ち寄る。
```

### シナリオ1　問い合わせへの返信を下書きする

つくるもの：架空の問い合わせ1件に対する、返信メールの下書き

① Copilot を開きます（教員の方は Gemini を開きます。開き方は「3. あなたの道具はどれですか」にあります）。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 次の文を、省略せずにそのままコピーして、入力欄に貼り付けます。

```
あなたは学校法人の事務職員です。このあとに貼る問い合わせメールに対する、返信の下書きを書いてください。
【書き方の約束】
・日本語で、敬体（です・ます）で書いてください。
・体言止めを使わないでください。
・宛名、あいさつ、回答、問い合わせ先の順に書いてください。
・400字以内にしてください。
・聞かれていることに、1つずつ答えてください。
【必ず守ること】
・こちらが伝えていない事実を書かないでください。分からないところは〔要確認〕と書いて残してください。
・料金、日程、締切、駐車場の台数は、推測で書かないでください。すべて〔要確認〕にしてください。
・氏名、電話番号、住所は本文に書かず、〔　〕にして残してください。
・最後に、こちらが確認しなければならないことを、箇条書きで3つまで並べてください。
問い合わせメールは次のとおりです。
```

③ 続けて、上の架空データ②か③を、そのままコピーして貼り付けます。
→ 入力欄の中に、指示の文と問い合わせメールの両方が入っていれば、正しい状態です。

④ 入力欄の右にある送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ 宛名から始まる返信の下書きが表示されれば、正しく動いています。

⑤ 出てきた下書きを読み、直したいところを1つだけ書いて、続けて送ります。
→ 「もう少し短くしてください。」「締めの1文を足してください。」のように、1回に1つだけ伝えると、思ったものに近づきます。

⑥ できた下書きをコピーして、手元の Word かメモ帳に貼って保存します。
→ 〔要確認〕と書かれた箇所が、ご自分で答えられる内容になっていれば、そのまま提出できます。

① Copilot を開きます（教員の方は Gemini を開きます）。

```
このあとに貼るのは、打合せの走り書きのメモです。読める形に整えてください。
【やってほしいこと】
1. 「決まったこと」「決まっていないこと」「次にすること」の3つに分けてください。次にすることには、担当と、いつまでにするかが書かれている場合はそれも書いてください。
2. それぞれを箇条書きにしてください。1行は40字以内にしてください。
3. 最後に、100字以内の概要を付けてください。
【必ず守ること】
・メモに書かれていないことを補わないでください。
・担当者が書かれていない項目は、「担当は未定」と書いてください。

・体言止めを使わないでください。
メモは次のとおりです。
```

→ 入れ違いがあれば、「前日の確認連絡は、決まっていないことに移してください。」のように、項目の名前を書いて続けて送ります。

### シナリオ4　自分の係（エージェント）を作る

つくるもの：自分の部署用のエージェントと、その指示文の全文

エージェントとは、指示をあらかじめ仕込んでおける、自分専用の Copilot のことです。教員の方は、同じものを Gem（自分専用の Gemini）として作れます。

① Copilot を開きます。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。
→ 教員の方は、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` と入力して、Enter を押します。名前を入れる欄と、指示を入れる大きな欄が並んだ画面が出れば、正しい画面です。

② 画面の左側のサイドバーで、〈エージェント〉にあたる並びを探します。
→ 「Idea Coach」「新しいエージェント」「その他のエージェント」といった名前が並んでいれば、正しい場所です。

③ ［新しいエージェント］にあたる項目を押します。
→ 自分専用のエージェントを作る画面（Build your own specialist agent という趣旨の画面）が出れば、正しい画面です。
→ 「テンプレート」と「自分のエージェント」という2つのタブが出ることがあります。その場合は「テンプレート」の側から進みます。
→ 名前を入れる欄と、指示を入れる大きな欄が見つからないときは、この手順を飛ばして、シナリオ1の文を毎回貼る形で進めてください。

④ 「名前」にあたる欄に、次のように入力します。〔　〕は1か所だけです。ご自分の部署名を入れてください。

```
〔 総務課 〕の問い合わせ返信係
```

⑤ 「指示」にあたる大きな欄に、次の文を、省略せずにそのままコピーして貼り付けます。〔　〕は1か所だけです。同じく部署名を入れてください。

```
あなたは学校法人植草学園の〔 総務課 〕の事務職員です。外部から届いた問い合わせに対する、返信の下書きを作る係です。
【やること】
1. 受け取った問い合わせの本文を読み、聞かれていることを箇条書きで並べます。
2. そのうえで、返信メールの下書きを1本書きます。
3. 最後に、こちらが確認しなければならないことを、箇条書きで3つまで並べます。
【書き方】
・日本語で、敬体（です・ます）で書きます。体言止めを使いません。
・宛名、あいさつ、回答、問い合わせ先の順に書きます。
・400字以内にします。
・専門用語には、短い言い換えを添えます。
【守ること】
・伝えられていない事実を書きません。分からないところは〔要確認〕と書いて残します。
```

### シナリオ19　Excel の `=COPILOT()` 関数を使う（使える方だけ）

**学園の標準では使えません。個人や別の契約で有償ライセンスをお持ちの方だけ、お試しください。関数が使えない方は、このシナリオは飛ばしてください。**

つくるもの：表の中で、AIが自動的に分類を入れてくれる列が1本

`=COPILOT()` は、Excel のセルの中に直接書ける関数です。ふつうの関数と同じように書くと、そのマスにAIの答えが入ります。

**★ この関数は、2026年9月14日から使えなくなることが、Microsoft のページに書かれています。**今日は使えますが、これから先ずっと使えるものではありません。長く使う仕組みには、しないでください。

**表を用意します**

③ A1 のマスをクリックして、Delete キーを押し、②で入れた文を消します。そのうえで、A1 から B6 までに、次のように打ち込みます。B列は、この手順書の「5.」にある架空データ①（議事メモ）の中から、5行分を短くしたものです。手で打ち込んでも、コピーして貼り付けても構いません。

```
分類の候補	いただいた声
受付の仕方	見学の申込がメールと電話に分かれていて、受付の記録が2か所にある。
案内の中身	返信の文面が担当者ごとに違う。持ち物の案内が入っていないことがある。
場所と設備	駐車場の台数を聞かれることが多いが、案内に書いていない。
記録の置き場	用紙が見当たらないことがある。
決まっていないこと	前日の確認連絡を入れるかどうかは次回に持ち越しになった。
```

**後半　添付して、何度でも引ける形にします**

⑤ PDFを開いたタブの右上にある、下向きの矢印（ダウンロード）にあたるボタンを押して、答申をパソコンに保存します。

→ 入力欄のあたりに「このチャットには エンタープライズ データ保護 が適用されます」という趣旨の表示が出ていることを、ここでも確かめてください。

⑦ 入力欄の「＋」を押して、答申のPDFを添付します。
→ 「コンテンツの追加」「画像とファイルのアップロード」「クラウド ファイルを添付」「機能を追加」「エージェントとチャット」といった項目が並んだメニューが出れば、正しい状態です。
→ パソコンに保存したファイルを使う場合は［画像とファイルのアップロード］を選び、⑤で保存したPDFを選びます。OneDrive などにあるファイルを使う場合は［クラウド ファイルを添付］を選びます。
→ 入力欄の上に、選んだファイルの名前が表示されれば、添付できています。
→ 100ページある資料は、読み込みに時間がかかります。ファイルの名前の横に読み込み中の表示が出ているうちは、そのまま待ってください。1〜2分かかることがあります。

```
3. その5つのそれぞれについて、資料の何章・何ページに書かれていたかを添えてください。

【必ず守ること】
・資料に書かれていないことは、「資料には書かれていません」と書いてください。
・数字、年月日、機関の名前は、資料に書かれている表記のまま書き写してください。
・良し悪しの評価を書かないでください。
```

→ 添付したファイルの中身に触れた答えが返ってくれば、正しく読み込まれています。
→ 出てきた事柄のうち1つだけ、書かれているとされたページをPDFで開いて、本当にそこにあることを確かめてください。

⑨ 同じチャットの中で、続けて質問します。たとえば「2つ目について、もっと詳しく説明してください。」「この資料の中に、私立大学について書かれているところはありますか。」のように、思いついたことをそのまま送ります。

## 8. うまくいかないとき

| 起きていること | すること |
|---|---|
| Word や Excel の中に Copilot のボタンが見つからない | アプリの中の Copilot は、別の契約が必要です。`https://m365.cloud.microsoft` のチャット画面を使い、ファイルは入力欄の「＋」から添付します。 |
| サインインの画面から先に進めない | 個人のアカウントではなく、学園のアカウント（学園のメールアドレス）で入り直します。 |
| 文を貼っている途中で送信されてしまう | 改行は Shift キーを押しながら Enter キーを押して入れます。 |
| 返ってきた文が長い、または硬い | 「300字以内にしてください。」「もう少しやわらかい言い方にしてください。」と続けて送ります。 |
| 前のやり取りが混ざる | 新しいチャットを開いてから、もう一度貼り直します。 |
| 教育ツールの画面（フラッシュカード、ルーブリックなど）が見つからない | ブラウザのアドレス欄に `https://m365.cloud.microsoft/teach` と直接入力します。左の分類が出ないときは、上の検索窓に道具の名前を入力します。 |
| エージェント ストアに、手順書に書いてある名前が見つからない | 並んでいるものは変わることがあります。近い名前のものを1つ選んでください。ただし、メールにつながるもの（Mail Pro など）は選びません。 |
| 画面の右側に Copilot が出てこない | まず、ブラウザが Microsoft Edge かどうかを確かめます。Edge であれば、アドレス欄に `edge://settings/appearance/copilotAndSidebar` と入力し、〈ツール バーの Copilot の表示〉にあたるトグルをオンにします。それでも出ないときは、`https://m365.cloud.microsoft` のチャット画面に、ページの文章をコピーして貼り付けます。 |
| 盾（たて）のアイコンが見当たらない | 個人のアカウントで開いている可能性があります。画面の右上のアカウントのアイコンを押して、学園のアカウントに切り替えてから、開き直します。 |
| シナリオ18で、Word や PowerPoint の中に Copilot のアイコンが無い（リボンにも右下の隅にも無い） | 有償ライセンスが入っていません。壊れているのではありません。シナリオ18は飛ばして、シナリオ1から16のどれかに進んでください。同じことは、チャットの画面でもできます。 |
| シナリオ19で、`=COPILOT(` と入れたら `#NAME?` と表示される | この関数は使えません。シナリオ19は飛ばして、シナリオ13（Excel のブックを作ってもらう）に進むか、グループHの手順書のシナリオ3と同じ形で、チャットに数式を書かせてご自分の手で貼ってください。 |
| シナリオ19で、途中の行から計算が止まる | 10分あたり100回までという上限に当たっています。しばらく待つか、行数を減らしてください。 |
| シナリオ20で、重たいPDFが添付できない、または読み込みが終わらない | 1〜2分は待ってください。それでも終わらないときは、同じ答申の「概要」（1ページ）のほうを添付します。または、必要な章だけをページを指定して保存し直して添付するか、読みたい章の文字をPDFの画面で選んでコピーして、チャットの入力欄に直接貼り付けます。 |
| シナリオ20で、添付したはずの資料について答えてくれなくなった | 〈新しいチャット〉を押すと、添付した資料は引き継がれません。画面の左側の履歴から、添付したチャットを開き直すか、同じファイルをもう一度添付します。 |
