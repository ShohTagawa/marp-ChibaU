## AIへの頼み方の基本（4つの要素）
うまく答えが返らないときは、次の4つが書けているかを確かめてください。

| 要素 | 書くこと | 例 |
|---|---|---|
| 役割(ペルソナ) | AIに何者として答えてほしいか | あなたは大学の不動産学部の教員です。 |
| 課題(タスク) | してほしいこと | 演習課題の下書きを作ってください。 |
| 背景情報 | 相手・場面・条件 | 受講者は2年生60名です。90分の授業の後半30分で取り組みます。 |
| 出力形式 | 長さ・文体・構成 | 300字程度、敬体、最後に提出方法を1行。 |

人に仕事を頼むときと同じ書き方です。新人の方に頼むつもりで書くと、ちょうどよい詳しさになります。出力方法の見本を1つ付けると、さらに安定します。

- 未公開の学内資料（入試問題、決裁前の文書、契約書）
今日は、公開されている情報か、ご自身が作った資料か、手順書に印刷してある架空のデータで実施して下さい。
会議の録音や議事録も、機密でないもので練習してください。貴学に生成AIの利用方針があれば、そちらを優先してください。

### Step 3  インフォグラフィックを作成してみましょう

作り方は2通りあります。どちらでも構いません。

**Gemini アプリで作る場合**
① https://gemini.google.com を開きます。
② 画面下の〈Canvas〉にあたるボタンを押します。
③ 以下をコピーして、入力欄に貼ってください。続けて、班名・題材・使った道具・作ったもの・分かったことを箇条書きで貼ります。

```
今日のワークのまとめを1枚のインフォグラフィックに。班名・題材・道具・作ったもの・分かったことを入れて
```

④ 文章が出たら、右上の〈作成〉にあたるボタンを押し、〈インフォグラフィック〉を選びます。
→ 1枚の図が出れば、正しい画面です。

**Gemini Notebook で作る場合**
① Gemini Notebook https://notebook.google.com/?icid=home_maincta を開き、今日使ったノートを開きます。
→ ノートを作っていない方は、右上の〈新規作成〉にあたるボタンを押し、「ソースを追加」から、今日作ったものや手順書の該当箇所を貼ります。
② 右側の〈スタジオ〉にある〈インフォグラフィック〉を押します。
③ 言語とレイアウトはそのまま(日本語と横向き)。ビジュアルスタイルは好きに選択してOK。
④ 指示の欄に、上と同じ文を入力します。

良い回答が出るまで、指示などを修正しながら、いくつか確かめて下さい。ハルシネーションや言い過ぎ、省きすぎがあるか、確認してみましょう。

うまく出ないときは、紙やホワイトボードに5つ（班名・題材・道具・作ったもの・分かったこと）を書いて、写真を撮ったものでも構いません。
