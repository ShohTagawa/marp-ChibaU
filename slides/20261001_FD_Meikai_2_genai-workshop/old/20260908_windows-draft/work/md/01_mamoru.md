# ① 既存の課題をAIから守る（AIを使わない課題にする）

使う道具：Gemini アプリ・Gemini Notebook（旧 NotebookLM）・Chrome の〈Gemini に相談〉が中心です。

---

## 1. この章でやること

この章が終わるとき、手元に次のどれかができあがります。いま出している課題を Gemini に解かせて「AIだけでどこまで解けるか」を班で書いた判定表、AIだけでは解けない形に書き直した課題文、学生に見せる「この授業での生成AIの使い方」の1枚、「AIを使ったのでは」と思ったときに教員が踏む対応手順の1枚です。どれも、次の授業でそのまま使える形にします。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）。** たとえば、次のようなものです。

- もとの課題文と、Gemini が書いた答案と、班で書いた判定表（AIだけで満点が取れるか／弱いところ／確かめた項目が実在したか）（シナリオ1）
- 書き直した課題文：「賃貸住宅の募集広告を1枚持参し、授業中に、借主として確かめたい点を3つその場で書き、隣の人に口頭で説明しなさい。説明の要点を教員が聞き取り、評価します」（シナリオ2）
- 他大学の方針2〜3件と大阪大学TLSCの資料を、6つの項目で並べた比較表（シナリオ3）
- 学生に見せる「〇〇学 授業における生成AIの利用について（第1版・班で作成）」の全文（シナリオ4）
- 「AIを使ったのでは」と思ったときの対応手順1枚（確かめる順番と、やらないこと）（シナリオ5）

**② インフォグラフィック（やったことを1枚の図にしたもの）。** 作り方は、共通ページをご覧ください。

## 3. シナリオ一覧

気になるものから始めてください。どれから始めても構いません。5本は独立しています。

| 番号 | シナリオ | つくるもの |
|---|---|---|
| 1 | 自分の課題をAIに解かせて、どこまで解けるかを見ます | Gemini が書いた答案と、班で書いた判定表 |
| 2 | AIが解けない形に、課題を直します | 書き直した課題文と、Gemini による点検の結果 |
| 3 | 他大学の方針を調べて比べます | 方針ページを5つの観点で書き出したメモと、2〜3件を並べた比較表 |
| 4 | 自分の科目の方針文を書いて、AIに点検させます | 学生に見せる「この授業での生成AIの使い方」の全文 |
| 5 | 「AIを使ったのでは」と思ったときの対応手順を決めます | 教員が踏む対応手順の1枚 |

この章の手順は、どれも大学の Google アカウントでサインインした状態で行います。実在の学生の氏名・成績・提出物は、どの画面にも入力しません。

### シナリオ1　自分の課題をAIに解かせて、どこまで解けるかを見ます

つくるもの：自分の課題に対して Gemini が書いた答案と、班で書いた判定表

① Gemini アプリを開きます（開き方は共通ページをご覧ください）。
→ 画面の下のほうに、横長の入力欄が見えていれば、正しい画面です。

② 自分が実際に出している課題文を、手元に用意します。
→ シラバス、レジュメ、Google ドキュメント、紙、どこにあるものでも構いません。手元になければ、記憶で書き直したもので十分です。1〜3行で構いません。
→ 持ち合わせがない方は、下の架空の課題文のどれかを使ってください。

| 分野 | 架空の課題文 |
|---|---|
| 経済系 | 同じ路線で、駅前の物件と駅から徒歩15分の物件の家賃に差が出る理由を、需要と供給の考え方を使って1200字で説明しなさい。 |
| 法学系 | 授業で配った賃貸借契約書の見本を読み、借主にとって不利になりうる条項を3つ挙げ、それぞれなぜ不利なのかを説明しなさい。 |
| 工学系 | 木造2階建ての住宅を想定し、地震に備えて設計で配慮する点を5つ挙げ、それぞれの理由を説明しなさい。 |
| 語学系 | 不動産会社の担当者として、外国人の入居希望者に物件の設備を説明する英文メールを150語で書きなさい。 |

③ 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔授業名と対象〕と〔課題文〕の2か所です。

```
あなたは、この授業を受けている不動産学部の学生です。
これから示す課題に、実際に提出するつもりで答えてください。

【授業名と対象】〔 例：不動産経済学・2年生・受講60名 〕

【課題文】
〔 ここに、いま出している課題文をそのまま貼り付けてください 〕

条件：
- 実際に学生が提出しそうな文量で書いてください。
- 参考文献が必要な形式であれば、参考文献も付けてください。
- 書き終わったあとに「この課題を解くのにどのくらい苦労したか」を3行で書いてください。
```

④ 入力欄の右にある送信ボタン（紙飛行機のような形のボタン）を押します。
→ 文字が少しずつ表示されはじめれば、動いています。最後まで表示されるのを待ちます。

⑤ 出てきた答案を、班で一緒に読み、下の判定表を埋めます。記録役が書き留めます。
→ 答案の中から、確かめられるもの（参考文献の題名、統計の数字、法令や指針の名前、年号）を1つ選びます。新しいタブを開いて、Google 検索（`google.com`）で、その名前をそのまま検索します。「実在した」「似たものはあるが、著者や年が違う」「見つからなかった」のどれに当たるかを、表に書きます。

判定表（見本）

| 見るところ | 班の判定 | 一言 |
|---|---|---|
| AIだけで満点が取れるか | 取れる ・ 部分点まで ・ 取れない | 例：論の運びは満点相当ですが、授業で扱った事例が一つも入っていません |
| 弱いところ（AIが書けなかったこと） |  | 例：現地の物件の話、授業内の議論、自分の経験 |
| 確かめた項目と、その結果 | 実在した ・ 似たものはある ・ 見つからなかった | 例：挙がった統計の出典名が、検索で見つかりませんでした |
| これが提出されてきたら、単位を出すか | 出す ・ 条件付きで出す ・ 出さない | 理由を一言 |

⑥ 答案と判定表をコピーして、提出用の文書に貼ります。
→ シナリオ2に進む方は、判定表の「弱いところ」の欄を、そのまま使います。

### シナリオ2　AIが解けない形に、課題を直します

つくるもの：書き直した課題文と、Gemini による点検の結果

① 下の表から、課題の型を1つ選びます。

| 型 | 課題の形 | 課題文の例（架空） |
|---|---|---|
| 1 口頭試問・対面での説明 | 提出物について、教員または隣の学生に口頭で説明し、その場の質問に答えます | レポートの要点を口頭で説明し、教員からの質問2つに答えなさい |
| 2 授業中にその場で書く | 授業の時間内に、その場で書きます。手書きに限りません。合理的配慮が必要な学生には、別の手段を用意します | 今日の授業で扱った事例について、授業の最後に、自分の考えをその場で400字で書きなさい |
| 3 過程の提出 | 完成したものと一緒に、下書き・メモ・参考にした資料の一覧を提出します | 最終稿と、途中の下書き2回分と、参考にした資料の一覧を提出しなさい |
| 4 自分の経験・現地観察を含める | 実際に見に行った場所や、自分が経験したことを材料にします | 自宅または大学の最寄り駅の周辺を歩き、撮った写真2枚を添えて、そのまちの課題を1つ挙げなさい |
| 5 授業内の議論を材料にする | 授業内のディスカッションで出た論点を書きます | 第4回のグループ討議で出た論点のうち1つを取り上げ、討議で出た反対意見に答える形で論じなさい |

② 選んだ型に合わせて、自分の課題文を手元で書き直します。1〜3行で構いません。
→ シナリオ1を進めた方は、判定表の「弱いところ」に書いた内容を、課題文に入れます。

③ Gemini アプリを開き、画面の左上にある ［新しいチャット］ を押して、まっさらな状態にします（開き方は共通ページをご覧ください）。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

④ 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔授業名と対象〕と〔書き直した課題文〕の2か所です。

```
あなたは、この授業を受けている不動産学部の学生です。
下の課題を、生成AIだけを使って、授業に出席せずに、自分では何も調べずに解こうとしてください。

【授業名と対象】〔 例：不動産経済学・2年生・受講60名 〕

【課題文】
〔 ここに、書き直した課題文をそのまま貼り付けてください 〕

【答えてほしいこと】必ずこの形で出してください。
1.【AIだけで済むところ】課題のうち、生成AIの出力をそのまま出せば済む部分を、課題文の言葉を引用して挙げてください。無ければ「ありません」と書いてください。
2.【AIだけでは足りないところ】学生本人が、授業に出る、現地に行く、自分で話す、自分で書く、のいずれかをしないと埋められない部分を挙げてください。
3.【すり抜ける方法】学生が、この課題を生成AIだけで済ませようとしたら、どういう手を使いそうかを2つ挙げてください。
4.【教員への提案】3のすり抜けを防ぐために、課題文に1行だけ足すとしたら何を足すかを提案してください。

【書き方の約束】
・日本語で、敬体（です・ます）で書いてください。
・実在を確認できない文献名・統計の数値・法令の条文を書かないでください。
・ここに書かれていない一般論を付け足さないでください。
```

⑤ 送信ボタンを押します。
→ 1〜4の見出しが付いた形で答えが返ってくれば、指示どおりに動いています。
→ 形式がバラバラなときは、「【答えてほしいこと】のとおりに、もう一度出してください。」と続けて送ってください。

⑥ 2.【AIだけでは足りないところ】と 4.【教員への提案】を班で読み、課題文を直します。直した課題文と、点検の結果をコピーして、提出用の文書に貼ります。
→ 1.【AIだけで済むところ】が「ありません」になるまで、④からくり返しても構いません。

### シナリオ3　他大学の方針を調べて比べます

つくるもの：他大学の方針ページを5つの観点で書き出したメモと、2〜3件を並べた比較表

前半は Chrome の〈Gemini に相談〉で、開いているページを1件ずつ読みます。後半は Gemini Notebook で、2〜3件を並べて比較表にします。前半だけ、後半だけでも構いません。〈Gemini に相談〉のアイコンが画面に出ない方は、後半から始めてください。

読み込ませるのは、公開されている資料に限ります。学生の個人情報が入ったものや、未公開の学内資料は入れません。

**前半　開いているページについて、その場で聞きます**

〈Gemini に相談〉 は、Chrome にログインしているアカウントで動きます。個人のGoogleアカウントで Chrome にログインしていると、大学のアカウントのデータ保護が効きません。

① Chrome の画面の右上にある丸いアイコン（自分のアカウントのアイコン）を押して、大学のGoogleアカウントでログインしていることを確かめます。
→ 大学のメールアドレスが表示されていれば、正しい状態です。
→ 個人のアカウント（ふだんの私用のGmail）になっていたら、大学のアカウントに切り替えてから進めてください。

② 他大学の方針が載っている公式サイトのページを、ふつうにタブで開きます。
→ ページの本文が画面に表示されていれば、正しい状態です。PDFのページでも構いません。
→ ページの探し方：新しいタブで Google 検索（`google.com`）を開き、「大学名 生成AI 利用 方針」のように検索して、その大学の公式サイトのページを開きます。個人のブログ、まとめ記事、ニュース記事は使いません。

③ 画面の右上にある 〈Gemini に相談〉にあたるアイコンを押します。
→ 画面の右側に細長いパネルが開き、文章を打ち込む欄が出れば、正しい画面です。
→ 初めて使うときは、画面に出てくる案内に沿って、有効にしてください。
→ アイコンが画面に出ない方は、前半は飛ばして、後半へ進んでください。大学のアカウントの設定によっては使えません。シークレットウィンドウでも使えません。

④ パネルの入力欄に、次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の1か所だけです。埋めなくても動きます。

```
いま開いているこのページだけを読んで、次の5つについて、それぞれ何と書かれているかを書き出してください。
1. 学生が生成AIを使ってよい場面と、使ってはいけない場面
2. 使った場合に、申告や明記を求めているかどうか
3. 教員が課題を出すときに気をつけるように書かれていること
4. 個人情報や未公開資料の扱いについて書かれていること
5. ルールを守らなかった場合にどう扱うと書かれていること

【書き方の約束】
・このページに書かれていない項目は、想像で埋めずに「このページには書かれていません」と書いてください。
・このページの外にある知識で補わないでください。
・それぞれの項目について、このページの中の文を1つだけ、そのまま引用して添えてください。
・全体で〔 例：20行以内 〕にまとめてください。
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
```

→ 5つの項目が番号つきで並んで出てくれば、正しく動いています。

⑤ 出てきた引用を1つ選んで、ページの本文の中から同じ文を目で探します。
→ ページの中に同じ文が見つからない引用があったら、その項目は使わないでください。
→ 別の大学のページで同じことをするときは、そのページのタブに切り替えて、同じ文をもう一度送ります。パネルは、いま開いているページのほうを見に行きます。

⑥ 出てきたメモをコピーして、提出用の文書に貼ります。
→ 後半に進む方は、この文をノートブックの「コピーしたテキスト」に貼っても構いません。

**後半　2〜3件を Gemini Notebook で並べて比べます**

① Gemini Notebook を開きます（開き方は共通ページをご覧ください）。
→ ノートブックの一覧と、右上に［新規作成］にあたるボタンが見えていれば、正しい画面です。

② ［新規作成］または［新しいノートブック］にあたるボタンを押します。
→ 画面の左側に「ソース」という欄があり、そこに資料を追加するように促す表示が出ていれば、正しい画面です。まだ何も入っていない、空っぽの状態で構いません。

③ 左の「ソース」欄にある ［＋ 追加］にあたるボタンを押します。
→ 資料の種類（ウェブサイト、コピーしたテキスト、Google ドライブ、ファイル）を選ぶ画面が出れば、正しい画面です。

④ 「ウェブサイト」にあたる欄に、他大学の方針が載っている公式サイトのページのアドレスを貼り付けて追加します。これを2〜3件くり返します。
→ 左の「ソース」欄に、資料の名前が1行ずつ増えていれば成功です。
→ 前半で作ったメモは、「コピーしたテキスト」にあたる欄から追加できます。

⑤ この章の巻末にある「資料」を、「コピーしたテキスト」にあたる欄に貼り付けて追加します。
→ 「ソース」欄に3件ほど並んでいれば、準備ができています。1つのノートブックには50個まで入れられます。

⑥ 画面の下にある、質問を打ち込む欄をクリックして、次の文をコピーして貼り付け、送信します。

```
読み込んだ資料だけを使って、比較表を作ってください。

【行（たてに並べる項目）】
1. 学生が生成AIを使ってよい場面
2. 学生が生成AIを使ってはいけない場面
3. 使ったときに申告や明記を求めているか
4. 教員が課題を出すときの工夫
5. 個人情報・未公開資料の扱い
6. ルールを守らなかった場合の扱い

【列（よこに並べる項目）】
・他大学のポリシー（大学ごとに1列）
・大阪大学の資料（浦田 2023）

【書き方の約束】
・資料に書かれていない項目は、想像で埋めずに「記載なし」と書いてください。
・それぞれのマス目の最後に、どの資料から取ったかが分かるようにしてください。
・日本語で、敬体（です・ます）で書いてください。
```

→ 表が表示され、文章のところどころに小さな数字やマークが付いていれば、正しく動いています。
→ その数字を1つ押すと、画面の左側に、元の資料の該当箇所が表示されます。
→ 気に入った表が出たら、［メモに保存］にあたるボタンで残します。ボタンが見つからないときは、表をコピーして、提出用の文書に貼ってください。

### シナリオ4　自分の科目の方針文を書いて、AIに点検させます

つくるもの：学生に見せる「この授業での生成AIの使い方」の全文（下書きと、点検を反映した書き直し）

① 下の表の7つの観点について、この科目での答えを班で決め、手元の紙に書きます。

| 観点 | 班の答え |
|---|---|
| 1 いつ・なぜ生成AIの使用を許可し、いつ・なぜ禁止するか |  |
| 2 ブレインストーミング（案出し）に使ってよいか | はい ・ いいえ ・ 条件付き |
| 3 生成AIの使用が、この科目の学習を強める場面と、妨げる場面 |  |
| 4 使ったときに、入力した文（プロンプト）の提出を求めるか | はい ・ いいえ |
| 5 使ったことを、どこに、どう書いて明記させるか | 例：末尾に「使用したAIと用途」を1行 |
| 6 AIの限界として学生に伝えること | 例：誤り、実在しない参考文献 |
| 7 検出ツールをどう扱うか | 使わない ・ 参考にとどめる |

② Gemini アプリを開き、次の文をコピーして、入力欄に貼り付けます（開き方は共通ページをご覧ください）。埋めていただくのは〔担当科目名〕と〔到達目標〕の2か所です。到達目標は、シラバスの文をそのままコピーして貼ってください。

```
あなたは、大学の教務に詳しいアドバイザーです。
私の授業で学生に見せる「授業における生成AIの利用について」という文章の下書きを作ってください。

【立場】
・書き手は、不動産学部の〔 例：不動産経済学 〕を担当する教員です。
・読み手は、その科目を受けている学生です。
・この科目の到達目標は、次のとおりです。
　〔 シラバスの到達目標をそのまま貼り付けてください 〕

【必ず入れること】
1. 次の7つの観点について、この科目での方針を1つずつ書いてください。それぞれ「してよい」「してはいけない」「条件付きでよい」のどれかを明示し、理由を1文添えてください。
```

## 巻末：課題を守るときの工夫と、推奨されない対応

シナリオ2・3・4・5で使います。シナリオ3の後半では、この巻末をまるごとコピーして、Gemini Notebook の「コピーしたテキスト」に貼ります。

出典：大阪大学 全学教育推進機構 TLSC「授業における生成AIの利用について」（浦田 2023）

### 生成AIの不適切な利用を防ぐ対策（抜粋）

- 最新の出来事や資料を扱うテーマを設定する
- 事前に生成AIで試験問題を試してみて、対応できた場合は別の問題を検討する
- 授業内でディスカッションした内容を書かせる
- 口頭試験にする
- インタビュー、コンセプトマップ、動画、ディベートなど、レポート形式以外の課題にする
- ピアや教員との対面ミーティングを組み合わせて段階的に評価する
- 学生が引用した文献を抜き打ちで実在するかチェックする（ことを伝える）
- レポートの執筆プロセス（下書きや参考文献、編集履歴等）も提出させて評価対象にする
- 試験で許可する・しないツールを明記する
- AIの利用に関する方針をシラバスに明記する
- 学問的誠実性を強調し、不正行為の結果を理解させる

### 推奨されない対応

1. 生成AIに剽窃チェックをさせる — 出力自体が正確でない場合がある
2. 剽窃チェックツールで判定する — 検出率は4分の1程度といわれ、プライバシーポリシー上の問題もある
3. 手書きでの課題提出を強制する — 合理的配慮が必要な学生がいる場合がある
4. 学生に生成AIの利用を強制する — プライバシーへの配慮が必要

### 学生に伝えること（7項目）

1. 生成AIを適切に使用しない場合は、学業上の不正行為とみなされること
2. 生成AIの使用は、あくまでも学習サポートに限ること
3. 情報の分析などで生成AIを使用した場合は、その旨を明記すること
4. 意図しない盗用、著作権侵害、個人情報・機密情報の漏洩の可能性といった法的リスクがあること
5. 「ハルシネーション」や、参考文献は実在しないものが多いといった出力の信頼性の問題があること
6. 詐欺への注意として、安易にインストールしたり課金したりしないこと
7. 生成AIの不正な使用は、アカデミック・インテグリティの原則に違反しうること
