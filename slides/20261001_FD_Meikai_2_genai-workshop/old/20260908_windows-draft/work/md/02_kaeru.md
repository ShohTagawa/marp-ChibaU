# ② 既存の課題をAIで変える

使う道具：Gemini アプリ・Gem・Gemini Notebook

---

## 1. この章でやること

このワークが終わるとき、みなさんの手元に、いま出している課題をAIで作り替えたもの（AIに解かせた答案と班で決めたこと、書き直した課題文、自分の講義資料から作った小テスト、課題を点検する自分専用のAI、成果物と過程と振り返りを評価する表）ができあがり、次の授業でそのまま使える状態になります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）。** たとえば、次のようなものです。

- もとの課題文：「借地借家法の改正が賃貸市場に与える影響について、1500字で論じなさい」（第5回・2年生向け）
- AIに解かせた結果：Gemini で30秒で1400字の答案が出た。参考文献が3件挙がったが、うち1件は検索しても実在しなかった
- 改訂した課題文：「授業第4回で扱った『駅前の空き店舗をどう活用するか』という論点について、まず自分の考えを400字で手元に書き、そのあとAIに同じ問いを解かせ、両者の違いを300字で説明しなさい。AIの出力は添付すること」
- 自分の講義資料から作った小テストの問題と、その答え
- 作った Gem の名前：「レポート課題 確認用の伴走者」／指示文の全文
- 成果物・対話記録・振り返りの3つの観点を、3段階で評価する表（ルーブリック）

**② インフォグラフィック（やったことを1枚の図にしたもの）。** 班の名前、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つが、見て分かるように並んだ1枚です。作り方は、共通ページをご覧ください。

**手元に課題文が無い方へ。** 記憶で書き直したもので十分です。それも難しければ、次の架空の課題文をそのまま使ってください。

```
借地借家法の改正が賃貸市場に与える影響について、1500字で論じなさい。
参考文献を2件以上挙げること。
```

## 4. 各シナリオ

### シナリオ1　自分の課題をAIに解かせて、作り替えのサインを見つけます

つくるもの：自分の課題に対してAIが書いた答案と、「AIが解けた部分・解けなかった部分」の記録

① Gemini アプリを開きます（開き方は共通ページをご覧ください）。
→ 画面の下のほうに、横長の入力欄が見えていれば、正しい画面です。

② 自分が実際に出している課題文を、手元に用意します。
→ シラバス、レジュメ、Google ドキュメント、紙、どこにあるものでも構いません。手元になければ、記憶で書き直したもので十分です。1〜3行で構いません。「2. 完成イメージ」の架空の課題文を使っても構いません。

③ 次の文をコピーして、入力欄に貼り付け、入力欄の右にある送信ボタン（紙飛行機のような形のボタン）を押します。埋めていただくのは〔授業名と対象〕と〔課題文〕の2か所です。

```
あなたは、この授業を受けている不動産学部の学生です。
これから示す課題に、実際に提出するつもりで答えてください。

【授業名と対象】〔 例：不動産経済学・2年生・受講60名 〕

【課題文】
〔 ここに、いま出している課題文をそのまま貼り付けてください 〕

条件：
- 実際に学生が提出しそうな文量で書いてください。
- 参考文献が必要な形式であれば、参考文献も付けてください。
- 書き終わったあとに「この課題を解くのにどのくらい苦労したか」を3行で書いてください。
```

→ 文字が少しずつ表示されはじめれば、動いています。最後まで表示されるのを待ちます。

④ 出てきた答案を、班で一緒に読みます。「これが提出されてきたら、単位を出すか」を決めて、記録役が書き留めます。
→ 出す、出さない、条件付きで出す、どれでも構いません。理由を一言添えてください。
→ 参考文献の題名、統計の数字、法令や指針の名前、年号のうち、確かめられるものを1つ選び、新しいタブを開いて Google 検索（`google.com`）でその名前をそのまま検索します。「実在した」「似たものはあるが、著者や年が違う」「見つからなかった」のどれに当たるかを、記録役が書き留めます。

⑤ 同じ画面の入力欄に、次の文をコピーして貼り付け、送信します。〔　〕はありません。そのまま貼って動きます。

```
いま書いた答案について、次の3つに答えてください。
1. 答案のうち、あなたが根拠を持って書けた部分はどこですか。
2. 答案のうち、推測や一般論で埋めた部分はどこですか。その箇所を引用して示してください。
3. この課題で、学生が自分で考えたり、自分で調べたりしなければ書けない部分はどこですか。無ければ「無い」と答えてください。
```

→ 3つの答えが番号つきで返ってくれば、正しく動いています。

⑥ 返ってきた答えを読み、記録役が次の3行を書き留めます。「AIが解けた部分」「AIが解けなかった部分」「学生に残す部分」。
→ AIの答案に単位を出すと決めた（AIで満点が出る）場合は、この課題は作り替えのサインです。書き留めた3行を、シナリオ2かシナリオ5の材料にします。

### シナリオ2　「まず自分で書く→AIに解かせる→差を論じる」型に課題を作り替えます

つくるもの：3段（事前・本課題・事後）に書き直した課題文

① Gemini アプリを開きます（開き方は共通ページをご覧ください）。
→ 画面の下のほうに、横長の入力欄が見えていれば、正しい画面です。

② 作り替える課題文を、手元に用意します。
→ 自分が実際に出している課題文で構いません。手元になければ、「2. 完成イメージ」の架空の課題文を使ってください。

③ 次の文をコピーして、入力欄に貼り付け、送信します。埋めていただくのは〔課題文〕の1か所です。

```
次の課題文を、学生が「AIの答えと自分の答えを比較して論じる」形に書き直してください。

【もとの課題文】
〔 ここに課題文をそのまま貼り付けてください 〕

書き直しの条件：
- 次の3段に分けて、学生にそのまま配れる文章として書いてください。
  【事前】学生がAIを使わずに、自分の考えを手元に書く段階。字数を指定してください。
  【本課題】学生が同じ問いをAIに解かせ、自分の答えとの違いを論じる段階。
  　AIを使ってよい範囲と、使ってはいけない範囲を明記してください。
  　AIの出力をどのように引用し、どのように添付するかを明記してください。
  【事後】学生が「AIの答えのどこを採用し、どこを採用しなかったか、それはなぜか」を短く振り返る段階。
- 提出するものを、箇条書きで最後にまとめてください。
- 日本語で、敬体（です・ます）で書いてください。
- 課題の題材と難しさは、もとの課題文から変えないでください。
```

→ 【事前】【本課題】【事後】の3つの見出しが付いた課題文が出てくれば、正しく動いています。

④ 出てきた課題文を、班で一緒に読みます。字数、AIを使ってよい範囲、提出するものの3点を、自分の授業に合わせて直す箇所に印を付けます。
→ 直す箇所は、記録役が書き留めます。

⑤ 同じ画面の入力欄に、次の文をコピーして貼り付け、送信します。埋めていただくのは〔直したいこと〕の1か所です。

```
いまの課題文を、次の点だけ直して、もう一度全文を書いてください。
〔 例：事前の字数を400字にする。AIの出力は画面のスクリーンショットではなく文章の全文を添付させる。受講60名なので提出物を2点までにする 〕
```

→ 直した箇所が反映された課題文が、全文で出てくれば、正しく動いています。

⑥ 使う課題文をコピーして、提出用の文書に貼ります。

### シナリオ3　自分の講義資料から小テストを作ります

つくるもの：自分の講義資料から作った小テストの問題と、答え

アップロードしてよいのは、自分が作った資料に限ります。教科書、他の先生の資料、購入した書籍のPDF、論文の本文はアップロードしないでください。学生の個人情報や成績が入ったファイルも入れません。

① Gemini アプリか Gemini Notebook（旧 NotebookLM）を開きます（開き方は共通ページをご覧ください）。
→ 資料が数ページ〜十数ページなら Gemini アプリ、それより長ければ Gemini Notebook が向いています。

② 自分が作った講義資料を読み込ませます。

- Gemini アプリの場合：入力欄のすぐ下にある ＋（プラス）のアイコンを押し、〈ファイルをアップロード〉にあたる項目を選んで、資料を選びます。
- Gemini Notebook の場合：［新規作成］にあたるボタンでノートブックを作り、左の「ソース」欄の ［＋ 追加］にあたるボタンから、パソコンのファイルか、Google ドライブのドキュメント／スライドを選びます。

→ ファイルの名前が画面に表示されれば、読み込めています。

③ 次の文をコピーして、質問を打ち込む欄に貼り付け、送信します。〔　〕はありません。そのまま貼って動きます。

```
いま読み込ませたのは、私が作った講義資料です。
この資料だけを根拠にして、小テストの問題を作ってください。
・四択問題を5問、記述問題を2問作ってください。
・四択問題は、選択肢を4つ、正解を1つにしてください。
・問題ごとに、根拠になった資料の見出しか、ページ番号を書いてください。
・資料に書かれていないことからは、出題しないでください。
・最後に、正解と、採点のときに見る点を、まとめて書いてください。
・日本語で、敬体（です・ます）で書いてください。
```

→ 問題が番号つきで並んで出てくれば、正しく動いています。

④ 出てきた問題を1問選び、資料の該当箇所を開いて、同じことが書いてあるかを確かめます。
→ Gemini Notebook では、答えに付いている小さな数字を押すと、元の資料の場所が画面の左側に表示されます。

⑤ 残りの問題と答えを、専門の目で1問ずつ判定します。正解が間違っている問題、選択肢のどれもが正解になり得る問題、資料に無いことを問う問題は、その場で書き直すか、削ります。
→ 判定の結果（そのまま使う／直して使う／削る）を、記録役が問題ごとに書き留めます。

⑥ 使う問題をコピーして、提出用の文書に貼ります。

### シナリオ4　課題を点検する Gem を作ります

つくるもの：課題を点検する自分専用のAI（Gem）と、その指示文の全文

Gem（ジェム）とは、指示をあらかじめ仕込んでおける、自分専用の Gemini のことです。一度作れば、次からは同じ指示を打ち直さずに使えます。そして、同僚や学生に配れます。

貼り付ける文案は3つあります。どれか1つを選んでください。

| 文案 | 誰が使うか | 中身 | 長さ |
|---|---|---|---|
| 文案1 | 教員 | くわしい版。教員への質問 → 改訂案3つ → この改訂で失われるもの、まで細かく決めてあります | 長い |
| 文案2 | 教員 | みじかい版。同じ流れを短く書いたものです | 短い |
| 文案3 | 学生 | 学生が提出前に自分のレポートを点検する版。答えは書かず、確かめる点を返します | 短い |

迷ったら、文案1で構いません。長いほど、動きが安定します。

① Gemini アプリを開きます（開き方は共通ページをご覧ください）。

② 画面の左上にある「三本線」のボタン（［サイドバーを開く］）を押して、左側のメニューを開きます。
→ 左に、細長いメニューが出てくれば、正しい画面です。

③ メニューの中から、〈Gem〉にあたる項目を探して押します。
→ 画面によって 「Gem」 と表示されている場合と 「Gem を表示」 と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に次を直接入力してください。
　 `https://gemini.google.com/gems/create`
→ 「新しい Gem」を作る画面（名前を入れる欄と、指示を入れる大きな欄がある画面）が出れば、正しい画面です。

④ 一覧の画面が出た方は、［Gem を作成］にあたるボタン（＋のボタン）を押します。
→ 名前を入れる欄と、指示を入れる大きな欄が出てきます。

⑤ 「名前」の欄に、次のように入れます。

```
レポート課題 確認用の伴走者（〔 あなたのお名前 〕）
```

→ お名前を入れておくと、班で共有したときに、どれが誰のものか分かります。文案3を選んだ方は「レポート提出前の点検係（〔 あなたのお名前 〕）」としてください。

⑥ 「指示」の大きな欄に、下の文案1・文案2・文案3のどれかを、まるごとコピーして貼り付けます。埋めていただくのは〔担当科目名〕だけです（文案の中に2か所出てきますが、どちらにも同じ科目名を入れてください）。

**文案1（くわしい版）**

```
# 役割
あなたは、大学・短期大学・専門職養成課程の教員と一緒に、授業課題を「生成AIがある前提でも
成立する課題」へ作り替えることを手伝う、確認用の伴走者です。
あなたがする仕事：教員に質問し、選択肢を示し、それぞれの長所と短所を整理すること。
あなたがしない仕事：教員の代わりに課題を決めること。完成した課題文を勝手に1つだけ提示すること。
最終的に決めるのは教員です。あなたは、教員が自分で決められるように材料をそろえる係です。
私が担当している科目は〔担当科目名〕です。この科目の授業を前提に助言してください。

# 前提知識
以下の知識だけに基づいて助言してください。ここに書かれていないことを、
一般論として付け足さないでください。

## A. 不適切な利用を防ぐ対策の4つの型
（大阪大学 全学教育推進機構 TLSC「授業における生成AIの利用について」浦田 2023）
① 問題作成と試験形式の工夫
　最新の出来事や資料を扱うテーマにする／事前に生成AIで解かせて確かめる／
　授業内でディスカッションした内容を書かせる／授業内で短いライティング課題を頻繁に課す／
　口頭試験にする／長い文章を要約させる／
　インタビュー、コンセプトマップ、動画、ディベートなどレポート以外の形式にする
② 評価とフィードバック
　対面ミーティングを組み合わせて段階的に評価する／生成AIで作成した成果物ではない旨に署名させる／
　AIを使っていない時に書いた文章と比較する／引用を多用する課題にする／
　引用文献が実在するか抜き打ちでチェックする（と伝える）／プレゼン課題でQAも行う／
　手書きか口頭でリフレクションを提出させる／ピア評価を取り入れる／AIに書かせた文章を批評させる
③ 課題の提出
　注釈を付けさせる／作成過程についての考察を課す／個人的な経験と統合させる／
　執筆プロセス（下書き・参考文献・編集履歴）も提出させる／引用文献のスクリーンショットを提出させる
④ 方針の明示と周知
　許可するツール・しないツールを明記する／出力の不正確さや偏りの例を学生に示す／
　AI利用方針をシラバスに明記する／学問的誠実性を強調する／
　書くプロセスがなぜ学びに大切かを伝える／内発的動機づけを促す

## B. 学習の順序について
AIに先に書かせて後から直させるより、まず学生自身に自分の考えを書かせ、
そのうえでAIを使わせるほうが、学生自身の思考の負荷が保たれる、という報告があります。
したがって改訂案には、必ず「学生が自分で書く段階」を、AIを使う段階より前に置いてください。

## C. AIアセスメントスケール（AIAS）の5段階
（Perkins, Furze, Roe & MacVaugh, 2024。大阪大学 TLSC 訳）
1 AIは使用できない（NO AI）
2 AIで構想・計画する（AI PLANNING）
3 AIとコラボする（AI COLLABORATION）
4 AIを全面活用する（FULL AI）
5 AIを応用する（AI EXPLORATION）

# 手順
必ずこの順番で進めてください。順番を飛ばさないでください。
【第1段階】教員が課題文を貼ったら、改訂案を出す前に、まず次の4点を質問してください。
　(a) 授業名・対象学年・受講人数
　(b) この課題で本当に測りたい力を、ひとことで言うと何か
　(c) 評価の配点と提出形式（レポート／試験／発表 など）
　(d) 授業時間内の対面の時間を、この課題のために使えるか（使えるなら何分か）
　教員が答えるまで、改訂案を出してはいけません。
【第2段階】答えを受け取ったら、もとの課題が生成AIでどの程度代替されうるかを、3行以内で述べてください。
　「代替されやすい」と述べる場合は、その理由をもとの課題文の言葉を引用しながら書いてください。
【第3段階】前提知識Aの4つの型から、この授業で現実に実施できる改訂案を3つ提案してください。
　3案は、できるだけ異なる型から選んでください。各案には次を必ず付けてください。
　・使った型の番号（①〜④）
　・改訂した課題文の本文（学生にそのまま配れる文章として、完成した形で書く）
　・教員の追加作業量（小・中・大のいずれか）と、その根拠を1行
　・想定される学生からの不満と、それへの答え方を1行
【第4段階】教員が1案を選んだら、その案について次を作ってください。
　・AIAS のどの段階に当たるか（1〜5の番号と名称）と、そう判断した理由を1行
　・シラバスまたは課題文に載せる、AI利用方針の文章（3行以内、学生に向けた敬体）
【第5段階】最後に必ず「この改訂で失われるもの」を1つ挙げてください。
```
