# ④ 自習と個別最適な学びのためのAIツールを作る

使う道具：Gemini Notebook（旧 NotebookLM）・Gem（ジェム。指示を仕込んでおける自分専用の Gemini）・Gemini アプリ

## 1. この章でやること

ご自身の講義資料を Gemini Notebook に読み込ませて、学生が質問できる自習用のノートブックにし、あわせて、答えを直接教えずに問い返す自習用の Gem を作ります。どちらも、組織内で共有してリンクをコピーするところまで進め、学生に配れる状態にして持ち帰ります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）。** たとえば、次のようなものです。

- 講義資料を入れた Gemini Notebook の共有リンク（例：「不動産市場の基礎 第5回 自習用」）
- 学習ガイドと確認問題（四択5問）を、専門の目で直したもの
- 通学中に聞ける復習用の音声解説（日本語）が入ったノートブック
- 作った Gem の名前（例：「賃貸借契約の基礎 自習の付き添い」）と、その「指示」の欄の全文、共有リンク
- 学生向けの「この授業の自習AIの使い方」1枚（LMS やシラバスに貼る文章）

**② インフォグラフィック（やったことを1枚の図にしたもの）。** 班名、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つが入った1枚です。作り方は、共通ページの Step 3 をご覧ください。

## 3. シナリオ一覧

気になるものから始めてください。5本は独立していますので、どれから始めても進みます。

| 番号 | シナリオ | つくるもの |
|---|---|---|
| 1 | 自分の講義資料を「質問できる教材」にする | 学生に共有できる状態の Gemini Notebook（共有リンク） |
| 2 | 学習ガイドと確認問題を作って、専門の目で直す | 用語の説明と四択問題5問（直したもの） |
| 3 | 音声解説を作る | 通学中に聞ける、日本語の復習用の音声 |
| 4 | 答えを教えず、問い返す自習 Gem を作る | 学生に配れる Gem と、その指示文の全文 |
| 5 | 学生向けの使い方案内を1枚にする | LMS やシラバスに貼れる「自習AIの使い方」1枚 |

手元に講義資料が無い方は、Google ドキュメントの新しい文書に、担当科目の1回分の内容を記憶で書き出したもの（見出し5つと、それぞれ3〜4行）で進めてください。

### シナリオ1　自分の講義資料を「質問できる教材」にする

つくるもの：自分の講義資料を読み込ませ、学生に共有できる状態にした Gemini Notebook（共有リンク）

ソースに入れてよいのは、ご自身が作った資料か、公開されている資料に限ります。教科書、他の先生の資料、購入した書籍のPDF、論文の本文を丸ごと入れないでください。学生の個人情報や成績が入ったファイルも入れません。

① ブラウザで新しいタブを開き、アドレス欄に `https://notebook.google.com/?icid=home_maincta` と入力して Enter を押します。
→ 大学のGoogleアカウントでサインインを求められたら、そのままサインインします。ノートブックの一覧が出れば、正しい画面です。

② 画面の右上にある 〈新規作成〉にあたるボタンを押します。
→ 画面の左側に「ソース」の欄が出れば、正しい画面です。

③ 左側の 〈ソースを追加〉にあたるボタンを押して、ご自身が作った講義資料を入れます。
→ Google ドライブのドキュメントとスライドは、ダウンロードせずにそのまま選べます。手元のファイル（PDF）は、ドロップするかアップロードします。
→ 左の「ソース」の欄に資料の名前が増えていれば、読み込めています。1つのノートブックに50件まで入ります。
→ 画面の上のほうに出ているノートブックの名前（「無題のノートブック」など）にあたる部分を押すと、名前を変えられます。「〔科目名〕 第〇回 自習用」のようにしておくと、学生に配ったときに分かります。

④ 画面の下にある質問の入力欄に、次の文をコピーして貼り付け、送信します。〔　〕はありません。そのまま貼って動きます。

```
あなたは、この授業を受けている学生です。追加した資料だけを使って、次の3つの質問に答えてください。
1. この回でいちばん大事な用語を1つ挙げて、初めて聞く人にも分かるように説明してください。
2. この回の内容で、学生がいちばん間違えやすいところはどこですか。資料の見出しを挙げて答えてください。
3. 試験に出るとしたら、どこですか。資料の見出しを挙げて答えてください。
資料に書かれていないことは、「資料には書かれていません」と答えてください。
日本語で、敬体（です・ます）で書いてください。
```

→ 答えのところどころに小さな数字やマークが付いていれば、資料にもとづいて答えています。1つ押して、元の文を見てください。
→ 続けて、学生から実際に聞かれたことのある質問を1つ、そのまま入力欄に打って送ります（例：「敷金と礼金は何が違いますか」「容積率と建ぺい率はどちらを先に見ますか」）。資料に無いことを聞くと「資料には書かれていません」と返ることを確かめます。

⑤ 画面の右上にある 〈共有〉にあたるボタンを押します。
→ 誰に見せるかを決める画面が出れば、正しい画面です。

⑥ 見せる範囲を 「組織内」（大学のGoogleアカウントを持つ人）にあたるものにし、権限を 「閲覧者」 にして、〈リンクをコピー〉にあたるボタンを押します。
→ リンクがコピーされた、という表示が出れば、学生に配れる状態です。このリンクを、提出用のメモに貼ります。
→ 「編集者」にすると、学生がソースを消したり足したりできてしまいます。学生に配るときは「閲覧者」にします。
→ 〈共有〉が押せない、エラーが出る、というときは深追いしないでください。ノートブックの名前と、入れた資料の名前を提出用のメモに書いて、次のシナリオに進みます。

### シナリオ2　学習ガイドと確認問題を作って、専門の目で直す

つくるもの：講義資料にもとづく用語の説明10個と四択問題5問を、専門の目で直したもの

① Gemini Notebook（`https://notebook.google.com/?icid=home_maincta`）を開き、講義資料を入れたノートブックを開きます。
→ まだノートブックを作っていない方は、シナリオ1の①〜③のとおりに作ってから、ここに戻ります。
→ 左の「ソース」の欄に講義資料の名前が見えていれば、正しい画面です。

② 画面の右側にある 〈スタジオ〉にあたるパネルから、〈クイズ〉 を押します。
→ 作成中の表示が出て、しばらく待つと、問題が並んで出てきます。
→ 〈学習ガイド〉にあたる項目が並んでいる方は、そちらも押して構いません。出ない方は、次の③で同じものを文章で作ります。

③ 画面の下にある質問の入力欄に、次の文をコピーして貼り付け、送信します。〔　〕はありません。そのまま貼って動きます。

```
追加した資料だけを使って、学生の自習用の「学習ガイド」を作ってください。
・この資料で押さえるべき用語を10個、それぞれ1〜2文の説明つきで並べてください。
・資料の内容を確かめる四択問題を5問作ってください。選択肢は4つ、正解は1つにしてください。
・問題ごとに、根拠になった資料の見出しか、ページ番号を書いてください。
・最後に、正解と、その理由を1問ずつ書いてください。
・資料に書かれていないことからは、出題しないでください。
・日本語で、敬体（です・ます）で書いてください。
```

→ 用語の一覧と、番号つきの問題が出てくれば、正しく動いています。

④ 出てきた問題を1問選び、資料の該当箇所を開いて、同じことが書いてあるかを確かめます。
→ Gemini Notebook では、答えに付いている小さな数字を押すと、元の資料の場所が画面の左側に表示されます。
→ 見るところは3つです。正解とされている選択肢が本当に正しいか、誤りの選択肢が「実は正しい」ものになっていないか、資料に無い数値や条文番号が足されていないか。

⑤ 出てきた文章をすべてコピーして、Google ドキュメントの新しい文書に貼り、間違っているところ、言い過ぎているところを、ご自身の専門の目で直します。
→ 判断に迷うところは、消さずに〔要確認〕と書き添えておきます。
→ 文書の名前を「〔科目名〕 学習ガイド」のようにしておきます。

⑥ 直した文書を、ノートブックの 〈ソースを追加〉にあたるボタンから、Google ドライブのドキュメントとして追加します。
→ 左の「ソース」の欄に文書の名前が増えていれば、読み込めています。これで、学生は直したあとの学習ガイドにも質問できます。

### シナリオ3　音声解説を作る

つくるもの：講義資料の内容を、通学中に聞ける日本語の音声にしたもの

① Gemini Notebook（`https://notebook.google.com/?icid=home_maincta`）を開き、講義資料を入れたノートブックを開きます。
→ まだノートブックを作っていない方は、シナリオ1の①〜③のとおりに作ってから、ここに戻ります。
→ 左の「ソース」の欄に講義資料の名前が見えていれば、正しい画面です。

② ［Studio］にあたるパネルから ［音声解説］ を選び、日本語の音声を作って聞いてみます。
→ 作成中の表示が出て、しばらく待つと再生ボタンが現れます。1日に作れる数に限りがありますので、班に1本にしてください。
→ 動画で作る解説は、いまのところ英語だけです。日本語で聞きたいときは、音声解説を選びます。
→ 言語を選ぶ欄が出た方は、日本語になっていることを確かめます。

③ 再生して、冒頭の部分を聞きます。
→ 聞くところは2つです。資料に書いていないことを話していないか、専門用語の読み方が違っていないか。気づいたことは提出用のメモに書いておきます。

④ 作成中のまま進まない、エラーが出る、というときは、代わりに次の文をコピーして質問の入力欄に貼り付け、送信します。〔　〕はありません。そのまま貼って動きます。

```
追加した資料だけを使って、通学の電車の中でスマートフォンで読み返せる、復習用のまとめを作ってください。
・全体を400字以内でまとめてください。
・そのあと、覚えておく用語を5つ、1行ずつの説明つきで並べてください。
・最後に、自分で説明できるかを確かめる問いを3つ書いてください。答えは書かないでください。
・資料に書かれていないことは書かないでください。
・日本語で、敬体（です・ます）で書いてください。
```

→ 400字のまとめと、用語5つと、問い3つが出てくれば、正しく動いています。文章として学生に配れます。

⑤ シナリオ1の⑤〜⑥のとおりに共有してある方は、班の別の方のアカウントで共有リンクを開き、音声解説が見えて再生できるかを確かめます。
→ 見えない場合は、音声はご自身のノートブックの中に残しておき、④の文章のほうを配ります。

### シナリオ4　答えを教えず、問い返す自習 Gem を作る

つくるもの：答えを直接教えず、学生の考えを引き出す質問を返す自分専用のAI（Gem）と、その指示文の全文、共有リンク

Gem（ジェム）とは、指示をあらかじめ仕込んでおける、自分専用の Gemini のことです。一度作れば、次からは同じ指示を打ち直さずに使えます。そして、学生に配れます。

① `gemini.google.com` を開き、画面の左側にある 〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と、「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力して Enter を押してください。

② ［Gem を作成］ を押し、「名前」の欄に次のとおり入力します。

```
〔担当科目名〕 自習の付き添い（〔 あなたのお名前 〕）
```

→ 名前の欄に文字が入り、その下に「指示」を入れる大きな欄が見えていれば、正しい画面です。
→ お名前を入れておくと、班で共有したときに、どれが誰のものか分かります。

③ 「指示」の大きな欄に、次の文をすべてコピーして貼り付けます。埋めていただくのは〔担当科目名〕だけです（文の中に3か所出てきますが、すべてに同じ科目名を入れてください）。

```
# あなたの役割
あなたは、〔担当科目名〕を受講している大学生の自習に付き添う係です。
答えを直接教えるのではなく、学生が自分で答えにたどり着けるように、問いを返します。
知識として添付してある授業資料が、あなたの手元にある唯一の教材です。

# 進め方
1. 学生が質問してきたら、答えを言わずに、まず「いま自分ではどう考えていますか」と聞いてください。
2. 学生の答えに対して、考えを一歩進める質問を1つだけ返してください。質問は1回に1つにしてください。
3. 学生が自分の言葉で正しく説明できたら、「その説明で合っています」と伝えて、次の論点に進んでください。
4. 学生が3回続けて行き詰まったら、答えそのものではなく、添付した授業資料のどこを読めばよいか（見出しやページ）を示してください。
5. 学生が「もう答えを教えてください」と言ったときも、まず資料の該当箇所を示し、そのうえで要点を2文以内で述べてください。

# 必ず守ること
・添付した授業資料の範囲から外れないでください。資料に書かれていないことを聞かれたら、「この授業の資料の範囲外です。担当の先生に聞いてください」と答えてください。
・資料に無い事実、数値、法令の条文番号を、自分で補って述べないでください。
・レポートや課題の答案そのものを書かないでください。頼まれたら、代わりに、構成を考えるための質問を返してください。
・学生の考えを否定する言い方をしないでください。間違っているときは、どこで食い違ったかが分かる質問を返してください。
・日本語で、敬体（です・ます）で書いてください。1回の返事は200字以内にしてください。

# 最初の一言
「〔担当科目名〕の自習に付き添います。いま考えている問題や、分からないところを書いてください。まず、あなたがいまどう考えているかを聞かせてください。」
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。

④ 「知識」にあたる欄の ［ファイルをアップロード］にあたるボタンから、講義資料を添付します。
→ パソコンのファイル（PDF）か、Google ドライブのファイルを選べます。欄に資料の名前が表示されれば、添付できています。
→ 添付してよいのは、ご自身が作った資料か、公開されている資料に限ります。

⑤ 画面の右側にある「プロンプト」の欄に、次の1行を入れて送り、試しに動かします。

```
重要事項説明とは何ですか。答えを教えてください。
```

→ 答えが返ってこず、「いま自分ではどう考えていますか」のような質問が返ってくれば、指示文が効いています。
→ 質問が返らずに答えがすぐ出てきたら、「指示」の欄の「# 進め方」の1行目が入っているかを確かめてください。
→ 続けて、学生になったつもりで自分の言葉の説明を打ち、「その説明で合っています」まで進むかを見ます。

⑥ 画面の ［保存］ を押します。そのあと、Gem の一覧で ［共有］ を押し、範囲は 「組織内」、権限は 「閲覧者」 を選んで、［リンクをコピー］ を押します。
→ Gem の一覧に、いま付けた名前が並んでいれば、保存できています。右側で試しに動かしただけでは保存されません。
→ リンクがコピーされた、という表示が出れば、学生に配れる状態です。このリンクと、「指示」の欄の全文を、提出用のメモに貼ります。
→ 共有ボタンが押せない、エラーが出る、というときは深追いしないでください。「指示」の欄の文章をまるごとコピーして渡せば、受け取った方は同じものを作れます。

### シナリオ5　学生向けの使い方案内を1枚にする

つくるもの：LMS やシラバスに貼れる、学生向けの「この授業の自習AIの使い方」1枚

① `https://gemini.google.com` を開きます。
→ 画面の下のほうに、文字を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 次の文をコピーして入力欄に貼り、〔科目名〕と、いちばん下の〔作った教材と Gem のリンクを貼る〕の2か所を埋めて、送信します。リンクは、シナリオ1でコピーしたノートブックのリンクと、シナリオ4でコピーした Gem のリンクです。まだ作っていないものは、その行を消して構いません。

```
あなたは大学の不動産学部の教員です。
私が担当する〔科目名〕の学生に配る、「この授業の自習AIの使い方」という案内を1枚で作ってください。
A4の紙1枚に収まる長さで、次の6つの見出しをこの順に立ててください。
1. 使えるもの（下のリンクを、それぞれ何ができるかの一言を添えて載せてください）
2. 使ってよい場面（授業の復習、試験前の確認、レポートの構成を考えるとき）
3. 使ってはいけない場面（レポートの本文を書かせること、試験の最中）
4. 入力してはいけないもの（自分や他人の氏名・学籍番号・連絡先、成績、授業資料の外から持ってきた他人の著作物）
5. 質問の仕方の例を3つ（「〜とはどういうことですか」「〜と〜の違いを、まず自分で説明するので聞いてください」のような形）
6. うまく答えが出ないときにすること（質問を短くする、資料のどの部分の話かを添える、担当教員に聞く）
日本語で、敬体（です・ます）で書いてください。見出しの下は箇条書きにしてください。
リンク：
〔作った教材と Gem のリンクを貼る〕
```

→ 6つの見出しが順に並び、それぞれの下に箇条書きが付いた文章が出てくれば、正しく動いています。

③ 出てきた文章をすべてコピーして、Google ドキュメントの新しい文書に貼ります。
→ 文書の名前を「〔科目名〕 自習AIの使い方」のようにしておきます。

④ 班で読み合わせて、次の3か所を、ご自身の授業に合わせて書き直します。
→ 「使ってよい場面」と「使ってはいけない場面」が、実際に出している課題や試験のやり方と合っているか。
→ 「入力してはいけないもの」に、この科目で扱う資料の事情（配布した資料の再配布、実務で預かった書類など）が足りているか。貴学に生成AIの利用方針があれば、そちらの言い方に合わせます。
→ 「質問の仕方の例」が、この科目の学生が実際に打ちそうな言葉になっているか。1つは自分の科目の用語に置き換えます。

⑤ 直した文書の本文をコピーして、LMS のお知らせ欄やシラバスの該当欄に貼ります。今日のところは、文書のままで提出用のメモに貼っておきます。

## 5. うまくいかないとき

| 起きること | すること |
|---|---|
| Gemini や Gemini Notebook が開かない | 個人のGmailアカウントで入っている場合があります。右上のアイコンから、大学のGoogleアカウントに切り替えます |
| ノートブックや Gem の〈共有〉が押せない、「組織内」が選べない | 大学のアカウントの設定によるものです。深追いせず、ノートブックの名前と入れた資料、Gem の指示文の全文を提出用のメモに貼ります |
| 重たいPDFが Gemini Notebook に読み込めない | 必要な章だけをページを指定して保存し直し、そのファイルを入れます。または、読みたい章の文字をPDFの画面で選んでコピーし、〈テキストを貼り付け〉にあたる欄に貼り付けます |
| 音声解説が作成中のまま進まない | シナリオ3の④の文章のまとめに切り替えます。音声は、あとで同じノートブックを開いて確かめます |
| ボタンや欄が、この紙と違う名前で出ている | 名前が違っても、同じはたらきの場所です。近い名前のものを押してください |
