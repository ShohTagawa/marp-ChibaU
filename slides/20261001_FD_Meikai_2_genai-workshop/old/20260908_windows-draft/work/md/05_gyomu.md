# ⑤ 業務で便利なツールを作る

使う道具：Gemini アプリ・Gem・Gemini Notebook・Workspace Studio

## 1. この章でやること

授業準備・学生対応・委員会・研究室運営の中から気になる仕事を1つ選び、生成AIに実際にやらせてみます。よく使う頼み方を仕込んだ Gem、規程や履修案内に質問できるノートブック、決まった流れを自動で動かすフローのうち、明日から自分の業務で1回使える現物を1つ持ち帰ります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）**　たとえば、次のようなものです。

- 学生からの問い合わせ3本への返信例と、返し方の型
- 委員会資料の要約と、論点の一覧
- 作った Gem の「指示」の欄の文章（省略せず全文）と、共有のリンク
- 履修案内や規程を読み込ませた Gemini Notebook のノートブック
- Workspace Studio で組んだフロー1本（ステップの並びと、貼ったプロンプトの全文）

1本でも、3本でも構いません。試したものを、そのまま出してください。

**② インフォグラフィック（やったことを1枚の図にしたもの）**　班名／選んだ題材／使った道具／作ったもの／分かったこと の5つを入れた1枚です。作り方は、共通ページの Step 3 をご覧ください。

## 3. シナリオ一覧

気になるものから始めてください。6本は独立していますので、どれから始めても進みます。

| 番号 | シナリオ | つくるもの |
|---|---|---|
| 1 | 学生からの問い合わせへの返し方をそろえる | 想定問答3本 |
| 2 | 長い文書を要約して、論点を抜き出す | 要約と、論点の一覧 |
| 3 | よく使う頼み方を Gem にする | 同僚に配れる自分専用の Gemini |
| 4 | 規程やマニュアルに質問できるようにする | 公開資料を読み込ませたノートブック |
| 5 | 決まった時刻の通知を Workspace Studio で自動にする | Workspace Studio のフロー1本 |
| 6 | Forms の回答が来たら返信の下書きを作るフローにする | 下書きを作って自分に送るフロー1本 |

### シナリオ1　学生からの問い合わせへの返し方をそろえる

つくるもの：学生から寄せられそうな問い合わせ3本と、それぞれへの返信例

実際に届いた学生からの問い合わせは使いません。学生の氏名・学籍番号・連絡先・成績は入力しません。科目名だけを入れて、想定の問い合わせを作らせます。

① `gemini.google.com` を開き、画面の左上にある ［新しいチャット］ を押します。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

② 入力欄に、次の文をコピーして貼り付け、〔　〕の1か所を埋めて送信します。埋めていただくのは〔担当科目名〕の1か所だけです。

```
〔　　　　　　　　　　〕の授業について、学生から寄せられそうな問い合わせを3つ挙げて、それぞれへの返信例を書いてください。
3つは、履修登録について、欠席の扱いについて、レポートの提出期限の延長について、の順にしてください。

【書き方の約束】
・返信例は1本あたり150字以内にしてください。
・3本とも、言い方の調子をそろえてください。
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・分からないことを断定しないでください。確かめる必要があるところは「確認のうえ、あらためてご連絡いたします」と書いてください。
・上に書かれていない事実、数字、日付を足さないでください。分からないところは〔要確認〕と書いてください。
・最後に、この3本を学生に返すときに気をつける点を、3行で書いてください。
```

→ 問い合わせ3つと、返信例3本が出てくれば、正しく動いています。

③ 3本を並べて読み、言い方がそろっていないところを直します。
→ 直りにくいときは、「3本とも、1本目の言い方に合わせて書き直してください」と送ります。
→ 〔要確認〕と書かれた箇所（締切・提出先・公欠の範囲など）は、ご自身の科目の決まりで埋めてください。

④ できた3本を Google ドキュメントに貼り付けます。
→ 3本が並んだ文書になっていれば、この手順は終わりです。

### シナリオ2　長い文書を要約して、論点を抜き出す

つくるもの：200字の要約と、論点の一覧

ご自身が作った資料か、公開されている資料をお使いください。決裁前の委員会資料や未公開の答申は使いません。手元にないときは、下の架空の会議メモをお使いください。

① `gemini.google.com` を開き、画面の左上にある ［新しいチャット］ を押します。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

② 入力欄に、次の文をコピーして貼り付けます。続けて、要約したい文章をそのまま貼り付けて、送信します。

```
このあとに貼る文章を読んで、次の3つを出してください。
1. 200字の要約
2. 決まったことの一覧
3. まだ決まっていない論点の一覧。それぞれに、決めるために必要な情報を1行で添えてください
【守ってください】
・文章に書かれていないことを足さないでください。
・書かれていない点について問われたら、「文章には書かれていません」と答えてください。
・日本語で、敬体（です・ます）で書いてください。
```

→ 要約と2つの一覧が出てくれば、正しく動いています。

③ 出てきた要約を元の文章と見比べ、元にない内容が混ざっていないかを確かめます。
→ 混ざっていたら、「元の文章に書かれていない部分を消して、書き直してください」と送ります。

④ 論点の一覧から、ご自身が引き取るものに印を付けます。
→ 要約と2つの一覧が手元にそろえば、この手順は終わりです。

練習用の架空の会議メモ（実在の会議・委員会とは関係ありません）

```
不動産学部 教務委員会 記録（架空）
出席：学部長、教務委員4名、事務2名
・生成AIの授業での使い方を、学部として1枚にまとめるかどうかを話した。科目ごとに決めるべきだという意見と、学部で最低限の線を示すべきだという意見があった。
・履修案内の改訂は、来年度分から行うことにした。担当は教務委員のうち2名が引き受けた。
・欠席の扱い（公欠の範囲）を科目間でそろえるかどうかは、次回に持ち越した。
・レポートの提出をオンラインにそろえる案が出たが、提出先のしくみを誰が管理するかが決まっていない。
・資格試験に関連する科目の時間割の重なりは、事務が確認することにした。
・新入生向けのガイダンスで、AIの使い方を説明する時間を設けるかどうかは決まっていない。
```

### シナリオ3　よく使う頼み方を Gem にする

つくるもの：同僚に配れる、自分専用の Gemini（Gem）

作る Gem は、次の2つから1つ選びます。②で入れる「名前」と、③で貼る「指示」が違うだけで、操作は同じです。

| | Gem の名前 | 何をする Gem か |
|---|---|---|
| A | シラバスを点検する係 | シラバスを貼ると、到達目標と評価方法の対応、分かりにくい語、確かめる点を返します |
| B | アンケートの自由記述を分ける係 | 授業アンケートの自由記述を貼ると、4つに分類して件数を数え、次回に対応できそうな点を返します |

① `gemini.google.com` を開き、画面の左側にある 〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と、「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力して Enter を押してください。

② ［Gem を作成］ を押し、「名前」の欄に、選んだほうの名前を入力します。

A を選んだ方

```
シラバスを点検する係
```

B を選んだ方

```
アンケートの自由記述を分ける係
```

→ 名前の欄に文字が入り、その下に「指示」を入れる大きな欄が見えていれば、正しい画面です。

③ 「指示」の大きな欄に、選んだほうの文をすべてコピーして貼り付けます。埋めるところはありません。

A を選んだ方

```
# あなたの役割
あなたは、大学の教員が書いたシラバスを点検する係です。

# 出力の形（この順に出してください）
1. 到達目標と、成績評価の方法が対応しているかを、対応表で示してください。対応する評価方法が無い目標には「評価方法なし」と書いてください。
2. 学生が読んで分かりにくい語を5つまで挙げ、短い言い換えを1行ずつ添えてください。
3. 書き手に確かめてほしい点（授業回数・締切・配点の合計・教科書名・連絡先）を箇条書きで

# 文体の決まり
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・1文は60字以内にしてください。
・専門用語を使うときは、短い言い換えを丸かっこで添えてください。
・あおる言い方をしないでください。感嘆符は1つの文書に1つまでにしてください。

# 必ず守ること
・シラバスに無い事実、数字、日付を足さないでください。分からないところは〔要確認〕と書いてください。
・数字・日付・配点・教科書名は、元の文のまま写してください。言い換えないでください。
・シラバスの文章を書き直すときは、元の意味を変えないでください。
・個人名や連絡先が含まれていたら、そのまま出さずに〔氏名〕〔連絡先〕に置き換えてください。
・利用者が「短く」と言ったら、意味を落とさずに文字数を半分にしてください。
```

B を選んだ方

```
# あなたの役割
あなたは、大学の授業アンケートの自由記述を分類する係です。

# 出力の形（この順に出してください）
1. 貼られた自由記述を、「授業の進め方」「資料・教材」「課題・評価」「その他」の4つに分けた表。1つの記述は1つの分類にだけ入れてください。
2. 分類ごとの件数
3. 次回の授業で対応できそうな点を3つまで。それぞれに、根拠になる記述をそのまま引用してください。

# 文体の決まり
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・1文は60字以内にしてください。
・あおる言い方をしないでください。感嘆符は1つの文書に1つまでにしてください。

# 必ず守ること
・貼られた記述に無い意見を足さないでください。
・引用は、言い換えずに、書かれている文字のまま写してください。
・個人名や連絡先が含まれていたら、そのまま出さずに〔氏名〕〔連絡先〕に置き換えてください。
・利用者が「短く」と言ったら、意味を落とさずに文字数を半分にしてください。
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。

④ ［保存］ にあたるボタンを押します。
→ Gem の一覧に、入力した名前が並んで見えれば、保存できています。

⑤ 一覧で ［共有］ を押し、「組織内」と「閲覧者」を選んで、［リンクをコピー］ を押します。
→ リンクがコピーされたという表示が出れば、配れる状態です。
→ ［共有］が押せないときは、大学の設定によるものです。「指示」の欄の文章をコピーして提出用のメモに貼れば、受け取った方が同じものを作れます。

⑥ 作った Gem を開き、入力欄に試す文を貼って送信します。A を選んだ方はご自身のシラバスを、B を選んだ方は下の架空の自由記述を貼ります。
→ 「指示」で決めた形（A は対応表、B は4つに分けた表）で答えが返ってくれば、この手順は終わりです。

練習用の架空の自由記述（実在の授業・学生とは関係ありません）

```
・説明が速くて、スライドを写す前に次に進んでしまうことがあった。
・配布資料が授業の前日に出るので、予習に使えて良かった。
・レポートの採点の基準が最後まで分からなかった。
・例に出てくる契約書が実際に近くて、イメージしやすかった。
・小テストの返却が遅く、どこを間違えたか分からないままだった。
・教室が寒かった。
```

### シナリオ4　規程やマニュアルに質問できるようにする

つくるもの：公開されている履修案内や規程を読み込ませた、学生から聞かれたときに引けるノートブック

読み込ませるのは、大学のウェブサイトで公開されている履修案内・学則・規程・学生向けマニュアルに限ります。未公開の学内文書は使いません。公開資料が見つからないときは、ご自身が作った授業のルール（シラバスや初回の配布資料）で同じ手順を試してください。

① ブラウザで新しいタブを開き、アドレス欄に `https://notebook.google.com/?icid=home_maincta` と入力して Enter を押します。
→ 大学のGoogleアカウントでサインインを求められたら、そのままサインインします。ノートブックの一覧が出れば、正しい画面です。

② 画面の右上にある 〈新規作成〉にあたるボタンを押します。
→ 画面の左側に「ソース」の欄が出れば、正しい画面です。

③ 左側の 〈ソースを追加〉にあたるボタンを押して、公開されている履修案内や規程を入れます。入れ方は2つあります。どちらか一方でできていれば、それで構いません。

**方法1　アドレスを貼る**　〈ウェブサイト〉または〈リンク〉にあたる欄を選び、公開ページかPDFのアドレスを貼り付けて、追加します。

**方法2　ダウンロードして読み込ませる**　PDFをパソコンに保存してから、〈ソースを追加〉 の画面にドロップするか、〈アップロード〉にあたるボタンから選びます。方法1で入らないときは、こちらに移ってください。

→ 左の「ソース」の欄に資料の名前が増えていれば、読み込めています。1つのノートブックに50件まで入ります。
→ Google ドライブのドキュメントとスライドは、ダウンロードせずにそのまま選べます。

④ 画面の下にある質問の入力欄に、次の文をコピーして貼り付け、送信します。埋めるところはありません。

```
追加した資料だけを使って、次の3つを出してください。
1. この資料の要点を5つ
2. 学生から聞かれそうな質問を10個と、資料の中にある答え。答えには、資料のどこに書かれていたかを添えてください。
3. 資料を読んでも答えが決まらない質問を3つまで。誰に確かめればよいかが資料に書かれていれば、それも添えてください。
資料に書かれていないことは、「資料には書かれていません」と答えてください。
日本語で、敬体（です・ます）で書いてください。
```

→ 答えのところどころに小さな数字やマークが付いていれば、資料にもとづいて答えています。1つ押して、元の文が資料の中に本当にあることを確かめてください。

⑤ 同じ入力欄に、ご自身が学生からよく聞かれる質問を1つ、そのまま打ち込んで送信します。
→ 資料の該当箇所を示した答えが返ってくれば、この手順は終わりです。あとで `https://notebook.google.com/?icid=home_maincta` を開き直すと、いま作ったノートブックが一覧に残っています。
→ 「資料には書かれていません」と返ってきた質問は、資料に無いか、資料が足りていません。③に戻って、関係する資料を足します。

### シナリオ5　決まった時刻の通知を Workspace Studio で自動にする

つくるもの：決まった時刻に調べて、Chat に通知するフロー1本

Workspace Studio の ［Flows］ は、「開始条件」と「アクション」を上から順に並べて、決まった流れを自動で動かすしくみです。ここでは、いちばん短い3ステップのフローを1本作ります。

① ブラウザの新しいタブを開き、アドレス欄に `studio.workspace.google.com` と入力して Enter を押します。
→ 大学のGoogleアカウントでログインを求められたら、ログインしてください。
→ 画面の左側にサイドバーが見えていれば、正しい画面です。

② 左のサイドバーにある ［Flows］ を押します。
→ フローの一覧が出れば、正しい画面です。
→ サイドバーに ［Flows］ が見当たらない方は、ここでこのシナリオを終わりにして、別のシナリオへお進みください。

③ 新しいフローを作ります。ステップ1の「開始条件」に ［設定スケジュールで実行］ を選び、動かす時刻を決めます。
→ ステップが上から順に並び、いちばん下に ［＋ ステップを追加］ が見えていれば、正しい画面です。
→ ステップ1に、決めた時刻が表示されていれば、正しい状態です。

④ ［＋ ステップを追加］ を押して、［Gemini に相談］ を選びます。
→ 「プロンプトを入力」という欄が出れば、正しい画面です。この欄は必ず埋めます。

⑤ 「プロンプトを入力」の欄に、次の文をコピーして貼り付けます。埋めていただくのは〔　〕の1か所だけです。

```
〔　　　　　　　　　　〕について、この24時間のあいだに新しく公開された情報を、ウェブを検索して調べてください。

【1件ごとに拾うこと】
1. 見出し
2. 公開された日付
3. 1行の要約
4. 出典のページ名とURL

【書き方の約束】
・公的機関または大学の公式サイトに掲載されている情報に限ってください。
・個人のブログ、まとめ記事は使わないでください。
・新しい情報が見つからないときは、「新しい情報はありません」とだけ書いてください。
・確かめられなかった項目は「記載なし」と書き、推測で埋めないでください。
・全体で10行以内にしてください。
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
```

→ 欄の中に文章がまるごと入っていれば、正しい状態です。
→ 〔　〕には、たとえば「国の住宅・土地に関する報道発表」「都市計画に関する自治体の公表資料」のように、授業や研究で追いかけている題材を入れます。
→ 前のステップの結果を文の中に差し込みたいときは、［＋ 変数］ を押して選びます。このフローでは使いません。

⑥ 同じ画面の「Gemini が使用できるソース」で ［すべてのソース］ を選び、「ウェブ検索」にチェックを入れます。
→ 「Gemini はウェブを検索できます」という説明が付いた項目です。チェックが入っていれば、正しい状態です。
→ 大学の中の資料も見に行かせたいときは、「Workspace」にもチェックを入れます。こちらは、ご自身がアクセスできる Workspace の中身だけが対象になります。

⑦ 「回答の形式」で ［テキスト］ を選びます。

⑧ ［＋ ステップを追加］ を押して、［Chat で通知する］ を選び、通知を送る先を指定します。
→ ステップが「設定スケジュールで実行 → Gemini に相談 → Chat で通知する」の3つ並んでいれば、正しい状態です。

⑨ フローを保存します。同僚にも使ってもらうときは、画面の右上にある共有のボタンから配ります。
→ フローの一覧に、作ったフローの名前が並んで見えれば、保存できています。

**★ テストの前に、必ずお読みください**

これから行うテスト実行は、練習ではありません。本当に動きます。メールを送るフローならメールが実際に送られ、予定を作るフローなら予定が実際に作られ、文書を書き換えるフローなら文書が実際に書き換わります。取り消しはできません。

いま作ったフローは、Chat に通知を送ります。⑧で指定した通知先が、ほかの方のいるスペースのままだと、テストのつもりで押しても、その方々に本当に通知が届きます。

テストの前に、⑧に戻って、通知先を **自分あてのスペース（自分ひとりしかいないスペース）か、自分だけのチャット** に変えてください。
→ 自分ひとりのスペースをお持ちでない方は、Chat で〈自分あて〉にあたる宛先（自分の名前が付いたチャット）を選んでください。
→ うまくいくことを確かめてから、通知先を本来の相手に変えます。

⑩ 画面の中の 〈テスト実行〉にあたるボタンを押します。
→ 画面によって 「テスト実行」 と表示されている場合と 「テスト実行してオンにする」 と表示されている場合があります。どちらでも同じものです。
→ このボタンは、フローを保存する前でも押せます。保存したあとで押しても構いません。
→ 見当たらないときは、フローを作る画面の下のほうと、画面の上のほうの両方を見てください。画面によって置き場所が違います。

⑪ 次に出てくる 〈起動〉にあたるボタンを押します。
→ このフローは決まった時刻に動くフローですので、〈起動〉です。時刻を待たずに、その場で1回だけ動きます。
→ 自分で始めるフローのときは、聞かれたことを入力してから 〈実行〉にあたるボタンを押します。
→ ステップが上から順に進んでいく表示が出れば、正しく動いています。

⑫ 結果が出るのを待って、表示の色を見ます。
→ 「テスト完了」と出て、⑧で指定した先に通知が届いていれば、うまくいっています。
→ Chat への通知は、その場に文章が出るのではなく、リンクの形で出ることがあります。そのリンクを押すと、Chat の画面で実物を確認できます。
→ **赤い** 「テスト完了」 が出たときは、**設定が足りていません。** 必須の欄が空か、道具のつながりができていません。ステップを開いて、空いている欄を埋めてから、⑩をやり直します。
→ **黄色い** 「テストを完了できませんでした」 が出たときは、**データのほうが合っていません。** 入れたデータを変えてから、⑩をやり直します。

⑬ うまくいったら、〈オンにする〉にあたるボタンを押します。
→ 画面によって 「オンにする」 と表示されている場合と 「有効にする」 と表示されている場合があります。どちらでも同じものです。
→ ボタンは、フローを作る画面の下のほうにあります。
→ フローの一覧で、そのフローがオンになった表示に変われば、正しい状態です。ここから、決めた時刻に自動で動きます。

⑭ 止めたいときは、フローの横にある 〈その他〉（点が3つ縦に並んだ印）を押して、〈オフにする〉を押します。
→ 動いている途中のものも、すぐに止まります。
→ あとからいつでも、同じところからオンに戻せます。

⑮ あとから動いたかどうかを見るときは、〈アクティビティ〉にあたる項目を押します。
→ フローを開いているときは、画面の右上にある、折れ線グラフのような形のアイコンです。
→ 画面の左側のメニューからも開けます。こちらは、すべてのフローの実行がまとめて並びます。
→ 1つのフローだけ見たいときは、フローの横の 〈その他〉 からも開けます。
→ 実行の一覧が出れば、正しい画面です。完了・進行中・問題あり で絞り込めます。
→ 実行に問題が起きていると、〈アクティビティ〉に赤い点が付きます。赤い点を見つけたら、押して中身を確かめてください。

### シナリオ6　Forms の回答が来たら返信の下書きを作るフローにする

つくるもの：Google フォームに回答があったときに、Gemini で返信の下書きを作り、自分あてにメールで送るフロー1本

**★★ 作るのは下書きだけです。回答した学生に自動で返信する設定にはしません。送る先は必ず自分のメールアドレスにし、学生への返信は、届いた下書きを読んで直してから、ご自身で送ります。**

練習では、ご自身で作った練習用のフォームに、ご自身で回答して試します。実在の学生の回答は使いません。練習用の回答に、学生の氏名・学籍番号・連絡先を入れません。本番で学生からの回答に使うときは、回答に個人情報が含まれることを踏まえ、貴学に生成AIの利用方針があればそちらを優先してください。

画面の開き方、ステップの足し方、テスト実行の押し方は、シナリオ5と同じです。

① Google フォームで、練習用のフォームを1つ作ります。質問は「質問の内容」という記述式の1つだけにします。
→ フォームの名前を「練習用」にしておくと、あとで選ぶときに見つけやすいです。
→ 回答を受け付ける状態になっていれば、正しい状態です。

② ブラウザの新しいタブを開き、アドレス欄に `studio.workspace.google.com` と入力して Enter を押し、左のサイドバーにある ［Flows］ を押して、新しいフローを作ります。
→ ステップが上から順に並び、いちばん下に ［＋ ステップを追加］ が見えていれば、正しい画面です。

③ ステップ1の「開始条件」に、〈フォームの回答が送信されたとき〉にあたる項目を選び、①で作った練習用のフォームを指定します。
→ 開始条件の一覧から選びます。「フォーム」や「Forms」という語が付いた項目です。
→ ステップ1に、練習用のフォームの名前が表示されていれば、正しい状態です。
→ フォームを指定する欄が見あたらないときは、このフローはオンにせず、テスト実行までで止めてください。

④ ［＋ ステップを追加］ を押して、［Gemini に相談］ を選びます。「プロンプトを入力」の欄に、次の文をコピーして貼り付け、〔　〕の1か所を埋めます。埋めていただくのは〔担当科目名〕の1か所だけです。
→ このフローでは、ウェブを検索させる必要はありません。「ウェブ検索」のチェックは入れなくて構いません。
→ 「回答の形式」は ［テキスト］ を選びます。

```
〔　　　　　　　　　　〕の授業に対して、学生からフォームで届いた質問への、返信の下書きを作ってください。送信はしません。下書きの文章だけを作ってください。

【出力の形】
1. 件名
2. 返信の本文
3. 送る前に、教員が確かめておく点の一覧

【書き方の約束】
・本文は300字以内にしてください。
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・質問に書かれていない事実、数字、日付、担当者名を足さないでください。分からないところは〔要確認〕と書いて、空けておいてください。
・答えられないことを断定しないでください。確かめる必要があるところは「確認のうえ、あらためてご連絡いたします」と書いてください。
・この文章は、教員が読んで直してから送るための下書きです。そのまま送られる前提で書かないでください。

【学生からの質問】
```

→ 欄の中に文章がまるごと入っていれば、正しい状態です。

⑤ フォームの回答を、この文の中に差し込みます。文の最後（「【学生からの質問】」の次の行）にカーソルを置き、［＋ 変数］ を押して、ステップ1の回答の内容にあたる項目を選びます。
→ 文の中に、選んだ項目の名前が入った印が現れれば、差し込めています。

⑥ ［＋ ステップを追加］ を押して、〈メールを送信〉にあたるアクションを選びます。宛先の欄に **ご自身のメールアドレス** を入れ、件名の欄に次の文を入れます。

```
【下書き】フォームの質問への返信案
```

→ 本文の欄にカーソルを置き、［＋ 変数］ を押して、ステップ2の Gemini の回答にあたる項目を選びます。本文の欄に印が入れば、差し込めています。
→ ステップが「フォームの回答が送信されたとき → Gemini に相談 → メールを送信」の3つ並んでいれば、正しい状態です。
→ **★★ 宛先には、ご自身のメールアドレス以外を入れないでください。** 回答した学生のアドレスにあたる変数を宛先に入れると、AIの書いた文章が、人の目を通らずに学生へ届きます。
→ 〈メールを送信〉にあたるアクションが見あたらないときは、代わりに ［Chat で通知する］ を選び、通知を送る先を自分あてにします。届いた文章をコピーして、ご自身で下書きに貼り付けてください。

⑦ フローを保存してから、テスト実行の前に、練習用のフォームをもう一度開き、ご自身で回答を1件送ります。
→ 回答の内容は、たとえば「レポートの提出期限を過ぎてしまった場合、受け取ってもらえますか。」のような、個人情報を含まない文にします。

⑧ フローを作る画面に戻り、〈テスト実行〉にあたるボタンを押します。
→ テスト実行は練習ではなく、本当に動きます。⑥の宛先が自分あてになっていることを、押す前にもう一度確かめてください。
→ このフローはフォームの回答で動くフローですので、どの回答で試すかを選ぶよう求められることがあります。求められたら、⑦でご自身が送った回答を選び、〈起動〉にあたるボタンを押します。
→ 「テスト完了」と出て、ご自身の受信トレイに「【下書き】フォームの質問への返信案」という件名のメールが届いていれば、うまくいっています。
→ **赤い** 「テスト完了」 が出たときは、必須の欄が空か、道具のつながりができていません。ステップを開いて、空いている欄を埋めてから、やり直します。
→ **黄色い** 「テストを完了できませんでした」 が出たときは、入れたデータが合っていません。⑦の回答を変えてから、やり直します。

⑨ うまくいったら、〈オンにする〉にあたるボタンを押します。止めたいときは、フローの横にある 〈その他〉（点が3つ縦に並んだ印）を押して、〈オフにする〉を押します。あとから動いたかどうかは、〈アクティビティ〉にあたる項目で確かめます。
→ 本番のフォームに付け替えるときは、③に戻ってフォームを選び直します。宛先は自分のままにしておきます。

**フローがうまく作れないとき**

シナリオ3の Gem に、同じことをさせられます。シナリオ3の手順で Gem を作り、「指示」の欄に④の文（〔担当科目名〕を埋めたもの。「【学生からの質問】」の行まで）を貼って保存します。フォームの回答が届いたら、その Gem を開いて回答の文を貼り付けると、同じ形の下書きが返ってきます。自動では動きませんが、作るものは同じです。
