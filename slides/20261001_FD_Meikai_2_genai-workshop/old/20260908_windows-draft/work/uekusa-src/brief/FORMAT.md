# 書式の正本（★ `ref/A.md` が見本です。必ず先に読んでください）

`ref/A.md` は**講師本人が書いた手順書**です。**書き方・用語・操作の細かさは、これに合わせます。**
ただし、`ref/A.md` に残っている「レベル」「時間」「メタ的な言葉」は、**新しい方針で取り除きます**（下記）。

---

## 1. 用語（★必ずそろえる）

| 使う言葉 | 使わない言葉 |
|---|---|
| **Gemini Notebook** | NotebookLM |
| **インフォグラフィック** | インフォグラフ |
| **手順書** | 指令書 |
| Gem（ジェム。指示を仕込んでおける自分専用の Gemini） | ― |

Gemini Notebook のアドレスは `https://notebook.google.com/?icid=home_maincta` です。

## 2. 操作の細かさ（★ここが最重要）

講師の版は、**パソコンに不慣れな方でも迷わない細かさ**で書かれています。同じ細かさにします。

- 操作は **①②③** の丸数字で、**1つずつ**書く
- 「ブラウザの新しいタブを開きます」「アドレス欄に〜と入力して Enter を押します」の粒度まで書く
- **各操作のあとに、矢印で画面の確認を書く**：

```
② メニューの中から、〈Gem〉にあたる項目を探して押します。
→ 画面によって 「Gem」 と表示されている場合と 「Gem を表示」 と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に次を直接入力してください。
　 https://gemini.google.com/gems/create
→ 「新しい Gem」を作る画面（名前を入れる欄と、指示を入れる大きな欄がある画面）が出れば、正しい画面です。
```

- **確信の持てないボタン名は断定しない**。`〈Gem〉にあたる項目`、`［＋ 追加］にあたるボタン` のように書く
- 見つからないときの逃げ道（直接URL など）を、その場に書く

## 3. コピーする文

- **省略せず全文**をコードブロックで書く
- 直前に「以下をコピーして、〜の欄に貼ってください。」と書く
- 埋める箇所は 〔　〕。**1〜2か所まで**。「埋めていただくのは〔担当科目名〕の1か所だけです」のように明示する
- 選べる文案が複数あるときは、**一覧の表**を先に置く（講師の版の「文案の一覧表」を参照）

## 4. 手順書の構成（この順番・この見出し）

```
# グループ〇 手順書
「テーマ名」（人数・班構成）

使う道具：〜が中心です。

## 1. このグループでやること
（このワークが終わるとき、手元に何ができているか。1〜2文）

## 2. 完成イメージ
提出するものは2点です。
① 成果物（今日つくった現物）… 具体例を箇条書きで
② インフォグラフィック（やったことを1枚の図にしたもの）… 5項目を書く

## 3. あなたの道具はどれですか
（誰が何を使うか。道具の説明を1行ずつ。使い分けの一言があるとよい）

## 4. シナリオ一覧
（表：番号／シナリオ名／つくるもの。「気になるものから始めてください」と1行）

## 5. 各シナリオ
### シナリオ1　〇〇〇
つくるもの：〜
①〜 → 〜
②〜 → 〜
［コピーする文］

## 6. 提出します
（共通ページを参照。短く）

## 7. うまくいかないとき
（表で3行程度）
```

## 5. ★新しい方針で取り除くもの（講師の版に残っていても、書かない）

| 取り除くもの | 例 |
|---|---|
| **時刻・所要時間** | 「10:32–10:42」「目安15分」「残り時間が5分を切ったら」 |
| **レベル／山** | 「レベル1」「レベル2-1」「【第1の山】」「レベル3（応用）」 |
| **ゴール・達成の宣言** | 「このレベルのゴール」「これができていれば達成です」「ここまでできていれば提出できます」 |
| **ふりかえりの指示** | 「良かったところを1つ言いましょう」「2周してください」 |
| **励まし・ねぎらい** | 「うまくいかなくても大丈夫です」「何も失っていません」「とても良い進み方です」 |
| **レベル3の内容** | 応用として置いていたもの。高度すぎるので載せない |

代わりに、**独立した短いシナリオを並べて、好きなものを選んでもらいます**（アラカルト方式）。
1つのシナリオは**操作3〜6ステップ**で終わる長さにします。

## 6. 「つくるもの：」の書き方

各シナリオの冒頭は、メタな「ゴール」ではなく、**できあがる物**を1行で書きます。

- ○ `つくるもの：他大学のポリシーを5つの観点で整理した文章`
- × `このレベルのゴール：〜を手元に持っている状態にします`

## 7. 提出（共通ページに詳しく書いてあるので、各グループでは短く）

インフォグラフィックの作り方は、講師が共通ページに書いています。各グループでは繰り返さず、
「共通ページの Step 3 をご覧ください」と案内するだけにします。参考までに、共通ページの要点：

- **Gemini Notebook**：ノートを開き、右側の［スタジオ］にある **［インフォグラフィック］** を押す。
  言語とレイアウトはそのまま（日本語・横向き）。ビジュアルスタイルは自由。
  指示の例「〇〇というタイトルで、スライドからまとめて下さい。上部にタイトル、左側に背景、右側になぜそれが重要かをまとめて下さい。」
- **Copilot**：［機能を追加］→［画像を生成する］→タイプで **［インフォグラフィック］** を押す。
  チャットに資料をアップロードし、同じ指示を入れる。画像でなく解説が返ってきたら、同じスレッドで
  「インフォグラフィックにして下さい」ともう一度頼む。
