## 1. 時間の表記を書かない

- 時刻（10:32 など）、所要分数（10分・20分・45分）、「はじめの5分で」「残り時間で」を**一切書かない**
- 「時計役」も置かない
- 締切にも触れない（共通ページにだけ書いてあります）

## 2. メタ的な記載を書かない

次のような文は**すべて削除**します。手順だけを書きます。

- 「ふりかえりましょう」「良かったところを1つ言いましょう」「2周してください」
- 「ここまでできていれば提出できます」「ここまで来られたら十分です」
- 「ここが今日いちばん面白いところです」「うまくいかなくても大丈夫です」
- 「このレベルのゴール」「これができていれば達成です」
- 学習効果の説明、ねらいの解説、励まし、ねぎらい

## 3. アラカルト方式にする

- 各グループに、**独立した短いシナリオを複数**用意する（目安 4〜6本）
- 冒頭に**シナリオの一覧**を置き、「気になるものから選んでください」とだけ書く
- シナリオどうしは**依存させない**。どれから始めても成立させる
- 1つのシナリオは、**手順3〜6ステップ**で終わる長さにする

## 4. 1つのシナリオの書き方（この型で統一）

```
### シナリオ名（短く。何をするかがそのまま分かる名前）

つくるもの：〔1行〕

1. 〔操作〕
2. 〔操作〕
3. 下の文をコピーして貼ります。

［コピーする文をコードブロックで全文］

4. 〔操作〕
```

- 手順は**番号つきで1ステップ1操作**
- 画面のどこを押すかを書く（URL・ボタン名）。**確信の持てないボタン名は書かない**。
  その場合は「〈◯◯〉にあたるボタン」と幅を持たせるか、その手順自体を外す
- **貼る文は省略せず全文**。埋める箇所は〔　〕にする（1シナリオにつき多くて2か所）
- 説明を足さない。手順だけ書く

## 5. 文体

- 敬体。体言止めを使わない。煽り語を使わない
- 専門用語には短い言い換えを添える（例：Gem（自分専用のGemini））。1回だけでよい
- 語りかけを減らし、**淡々と手順を書く**

## 6. 安全

- 実在の学生・園児・生徒・患者・利用者・教職員の個人情報、成績、未公開資料を入力させない
- 架空データが要るシナリオでは、**手順書の中に架空データを印刷する**
- 自分が作った資料以外はアップロードさせない

## 7. 手順書の構成（この順番）

1. `# グループ〇　〇〇〇`
2. **このグループですること**（1〜2行）
3. **使う道具**（誰が何を使うか。1行ずつ）
4. **シナリオ一覧**（表。番号・名前・つくるもの）
5. 各シナリオ（上の型）
6. **提出するもの**（成果物とインフォグラフ。共通ページを参照と書き、ここでは短く）
7. **うまくいかないとき**（3行程度の表）

★「講師が当日までに確認すること」節は**書かない**。
