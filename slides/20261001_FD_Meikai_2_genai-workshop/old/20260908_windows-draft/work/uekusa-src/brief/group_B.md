# グループB「既存の授業をAIで進化させる」（教員9名）

**使う道具**：Gemini アプリ、NotebookLM。**Copilot の教育ツールも使う**（教職員は使えます）

**このグループですること**：担当している授業の材料を、AIで作り替える。

## ★講師の指定

「課題確認用のGem」だけでなく、**もっと単純に取りかかれるシナリオ**も用意すること。
具体的には次の2本を必ず入れる。

- **Copilot の教育ツールで四択問題を作る**（クイズ。Microsoft Forms を使う）
- **Gemini か NotebookLM で問題を作る**

## シナリオ（5本。短く、独立させる）

1. **自分の課題をAIに解かせてみる** … いま出している課題文をそのまま貼って、解かせる。
   出てきた答えを見て、そのまま通してよいかを班で決める。手順はこれだけ。
2. **Copilot の教育ツールで四択問題を作る** … `m365.cloud.microsoft/teach` を開き、
   ［クイズ］を選ぶ。教科・学年を選び、範囲を書いて作らせる。**Microsoft Forms に書き出す**ところまで。
   ★画面の項目名は FACTS.md の表のとおりに書く。確信の持てない操作は書かない。
3. **Gemini か NotebookLM で問題を作る** … 自分が作った講義資料をアップロードして、
   小テスト用の問題を作らせる。NotebookLM ならソースに追加してから作らせる。
   ※アップロードするのは自分が作った資料に限る、と1行。
4. **課題確認用の Gem を作る** … 「この課題はAIでどこまで解けてしまうか」を点検する Gem を作る。
   指示文は**完成した文案を全文**載せる（〔担当科目名〕だけ埋める）。
   Gemの作り方は FACTS.md の導線どおりに書く。
5. **教育ツールで教材の言い回しを変える** … ［読み取りレベルを変更する］で、
   自分の配布資料をやさしい言い回しに直す。［サポートの例を追加］で例を足す。

## 完成文案を載せるもの

- シナリオ4の Gem の指示文（①役割 ②前提 ③手順 ④してはいけないこと ⑤出力の形 ⑥最初のひとこと を含む）
- シナリオ3の問題作成プロンプト
