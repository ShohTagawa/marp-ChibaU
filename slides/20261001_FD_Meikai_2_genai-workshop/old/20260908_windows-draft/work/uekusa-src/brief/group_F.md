# グループF「広報・情報発信の効率化」（広報Canva 1名＋職員8名）

**使う道具**：職員8名は Copilot、広報1名は Canva。**Canvaを持っていない人が大半**なので、
全員がCanvaを触る前提にしない。文章と画像は Copilot で作れるように書く。

**このグループですること**：1つの広報ネタを、いくつもの出し先に作り分ける。

## シナリオ（5本）

1. **案内文を1本つくる** … 役割・課題・背景・形式の4つを書いた文を貼って、案内文の下書きを作らせる
2. **同じネタを4つの出し先に広げる** … Webのお知らせ／保護者向け／SNSの短文／掲示の文言。
   1本の指示で4つ出させる
3. **広報文をつくる係を作る** … Copilot の Agent Builder でエージェントを作る。
   文体・呼称のルール・使わない表現を仕込む。指示文は**完成した文案を全文**
4. **挿絵をつくる** … Copilot の「画像の作成」。スタイル・色・サイズの指定の書き方を1行添える
5. **（Canvaが使える方）見た目を仕上げる** … マジック作文で文言を整え、マジック生成で画像を作り、
   写真は AI背景生成／マジック消しゴム／マジック切り抜き／マジック拡張 で直す。
   ★有料プラン限定の機能があるため、使えないものは飛ばしてよいと1行添える

## 手順書に印刷する架空データ

広報ネタの設定を2件、架空で用意して印刷する（オープンキャンパス、公開講座など）。
日付・会場・対象・内容を書いておき、そのまま使えるようにする。実在の行事と紛らわしくない名前にする。
