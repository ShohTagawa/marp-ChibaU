# グループG「Microsoft 365 Copilot活用」（教員3名＋広報5名＋職員14名＝22名）

**使う道具**：Copilot が中心。教員は Gemini でも試せる。広報は Canva も使える

**このグループですること**：Copilot でどこまで仕事が進むかを、実際に手を動かして確かめる。

## 冒頭に1行だけ書くこと

「Word や Excel の中で動く Copilot は、別の契約が必要です。ここでは、いま使えるCopilotで試します。」
これ以上の説明はしない。

## シナリオ（6本。22名なので、班ごとに違うものを選べるように多めに）

1. **問い合わせへの返信を下書きする**
2. **議事メモを整える** … 手順書に架空のメモを印刷して、それを貼って整形させる
3. **長い文書を要約して、論点を出す**
4. **自分の係（エージェント）を作る** … Agent Builder。指示文は**完成した文案を全文**。
   〔部署名〕だけ埋める形にする
5. **ファイルを添付して読ませる** … 「＋」→「画像とファイルのアップロード」または「クラウド ファイルを添付」。
   手元のPDFやWordを読ませて、要約や書き直しをさせる
6. **画像やスライドを作る** … 「画像の作成」／「作成ハブ（ストーリー）」

## 手順書に印刷する架空データ

- 架空の議事メモ（20行程度。植草学園らしい会議名・議題で、実在と紛らわしくないもの）
- 架空の問い合わせメール（2件）
