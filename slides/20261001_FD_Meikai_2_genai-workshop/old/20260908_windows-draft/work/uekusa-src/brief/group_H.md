# グループH「データ活用・集計自動化」（教員4名＋広報2名＋職員4名）

**使う道具**：職員は Copilot、教員は Gemini、広報は Canva

**このグループですること**：手作業になっている集計を、AIに手伝わせる。

## ★守ること

**Excel の中の Copilot は使えない。**「Excelで Copilot ボタンを押す」と書いたらその班は詰む。
**Copilot のチャットにデータを貼り付ける／ファイルを添付する**。
数式は AI に書かせて、**それを自分の手で Excel やスプレッドシートに貼って動かす**。

## シナリオ（5本）

1. **自由記述を分類する** … 手順書に印刷した架空の自由記述を貼って、分類させる
2. **集計表にする** … 分類の結果を表にまとめさせる
3. **数式を書いてもらう** … やりたい集計を言葉で伝えて、数式を書かせる。
   それを自分で貼って動かす。エラーが出たら、エラーの文をそのまま貼って直してもらう
4. **分類する係を作る** … エージェント（Copilot）または Gem。指示文は**完成した文案を全文**
5. **（Canvaが使える方）グラフにする** … 集計結果を Canva でグラフにする

## ★手順書に印刷する架空データ（必須）

- **研修アンケートの自由記述15件**。植草学園らしい内容で、長さはバラバラに、現実味のある書きぶりで。
  実在の人物を思わせないように
- **部署×回答数の小さな表**（5行程度）

※古いExcelでも動くよう、プロンプトに「FILTER や TEXTSPLIT は使わないでください」と入れておく
