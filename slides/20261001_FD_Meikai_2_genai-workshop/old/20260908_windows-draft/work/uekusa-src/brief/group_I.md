# グループI「生成AIによる業務自動化」（教員1名＋職員13名）

**使う道具**：ほぼ全員 Copilot。教員1名は Gemini

**このグループですること**：毎回くり返している作業を、使い回せる形にして、同僚に渡せるようにする。

## ★守ること

「自動化」で Power Automate や API に踏み込まない。契約とIT権限が要る話になり、その場で詰む。
ここでの自動化は**「毎回ゼロから書いている作業を、係にして配ること」**とする。
**予約アクション（定期実行）は使えないので書かない。**

## シナリオ（5本）

1. **毎週の作業を1つ選ぶ** … 候補を10本ほど並べて、選んでもらう（問い合わせ返信、通知文、議事メモ、
   名簿の整形、日程調整、報告書の下書き、マニュアルの更新、資料の要約、翻訳、掲示物の文言 など）
2. **その作業をAIに頼んでみる** … 役割・課題・背景・形式の4つを書いた文で1回頼む
3. **係（エージェント）を作る** … Copilot の Agent Builder。指示文は**完成した文案を全文**。
   〔部署名〕だけ埋める形にする。教員は Gem で同じことをする
4. **隣の人に使ってもらう** … 自分は口を出さずに、隣の人に係を使ってもらう。分かりにくいところを直す
5. **手順書を1枚つくる** … 同僚がそのまま使えるように書く。
   ★**手順書のひな形を、実物として印刷する**（何をする係か／どこを開くか／何を入力するか／
   出てきたものをどう確かめるか／入れてはいけない情報）
