# グループC 手順書

「AI時代の新しい学びを創る」（教員6名／3名×2班）

使う道具：Gemini アプリ（gemini.google.com）と Gemini Notebook が中心です。学園のM365アカウントで Copilot をお使いの方には、Copilot の手順も並べて書いてあります。

## 1. このグループでやること

授業を一段高度にするための材料を、生成AIで作ります。作った材料は、ご自身の専門の目で見て判定し、直したうえで持ち帰ります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）**　たとえば、次のようなものです。

- 学生に出す課題文と、その課題で学生が行う作業の手順（シナリオ1）
- 自分の資料から作った小教材（説明・用語・確認問題）と、◎○△×を書き込んだ判定表（シナリオ2）
- 課題の評価基準の表（シナリオ3）
- 作った Gem やエージェントの「指示」の欄の文章（省略せず全文）

**② インフォグラフィック（やったことを1枚の図にしたもの）**　これもAIに作ってもらいます。次の5つが、見て分かるように並んだ1枚です。

1. グループと班（例：グループC 1班）
2. 選んだ題材
3. 使った道具
4. 作ったもの
5. やってみて分かったこと

作り方は、共通ページの Step 3 をご覧ください。

## 3. あなたの道具はどれですか

| 道具 | どこで開くか | 今日つかう場面 |
|---|---|---|
| Gemini アプリ | `gemini.google.com` | 課題を練り上げる、ルーブリックを作る、Gem を作る |
| Gemini Notebook | `https://notebook.google.com/?icid=home_maincta` | 自分のレジュメを読ませて、小教材を作る |
| Copilot | `m365.cloud.microsoft` | M365アカウントをお使いの方が、エージェントを作る |
| Copilot の教育ツール | `m365.cloud.microsoft/teach` | ルーブリックなど、授業で使う書式を作る |

Gemini と Gemini Notebook の違いを、先に一言で覚えてください。Gemini は「その場でwebから調べて書く」道具、Gemini Notebook は「渡した資料の中だけで答える」道具です。教材のように、自分の資料から外れると困るものは、Gemini Notebook が向いています。

Gemini と Gemini Notebook は、学園のGoogleアカウントでサインインしてお使いください。個人のGmailアカウントのままにしないでください。

実在の学生・子ども・保護者・利用者・患者の情報は、どの画面にも入力しません。例が必要なときは、架空の設定で行います。

## 4. シナリオ一覧

気になるものから始めてください。3本は独立していますので、どれから始めても進みます。

| 番号 | シナリオ | つくるもの |
|---|---|---|
| 1 | 少し遠くまで行ける課題をつくる | 学生に出す課題文と、学生が行う作業の手順 |
| 2 | 自分の資料から小教材をつくって、専門の目で判定する | 小教材（説明・用語・確認問題）と、書き込んだ判定表 |
| 3 | ルーブリックをつくる | 課題の評価基準の表 |

## 5. 各シナリオ

### シナリオ1　少し遠くまで行ける課題をつくる

つくるもの：学生に出す課題文と、その課題で学生が行う作業の手順

① 手元の紙に、「この授業で学生に体験してほしいこと」を1行だけ書きます。
→ 「◯◯ができるようになってほしい」ではなく、「◯◯を体験してほしい」という言い方で書くと、あとの手順が進みやすくなります。

② ブラウザ（Chrome など）で新しいタブを開き、アドレス欄に `gemini.google.com` と入力して Enter を押します。
→ 画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。
→ 右上の丸いアイコンに学園のメールアドレスが出ていることを確かめてください。個人のGmailになっていたら、そこから学園のアカウントに切り替えます。

③ 画面の左側にある 〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と、「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力して Enter を押してください。
→ 「名前」を入れる欄と、「指示」を入れる大きな欄が並んだ画面が出れば、正しい画面です。

④ 「名前」の欄に、次のとおり入力します。

```
課題づくりの相談相手
```

→ 名前の欄に文字が入っていれば、正しい状態です。

⑤ 「指示」の大きな欄に、次の文をすべてコピーして貼り付けます。埋めるところはありません。そのまま貼れば動きます。

```
# あなたの役割
あなたは、保育士・幼稚園教諭・特別支援教育・作業療法士・理学療法士を養成する課程で教える教員の、相談相手です。
教員が学生に出す課題を、いまより少し遠くまで行ける課題に練り上げることが、あなたの仕事です。
教員の代わりに課題を決めるのではなく、教員が自分で決められるように材料を出してください。

# 進め方（この順番で行ってください）
1. 最初に、次の3つを教員に質問してください。3つまとめて聞いて、答えを待ってください。
   ・学生に体験してほしいことは何ですか。
   ・いま出している課題は何ですか。
   ・その課題に学生が使える時間は、授業の中ですか、授業の外ですか。
2. 答えを受け取ってから、課題案を3つ作ってください。3つは、学生が届く距離を変えてください。
   ・案1は、いまの課題を少し広げたものにしてください。
   ・案2は、現場で実際に起きる条件を1つ足したものにしてください。
   ・案3は、学生自身が問いを立てるものにしてください。
3. 案ごとに、次の4つを1行ずつ書いてください。
   ・学生が実際に行う作業
   ・学生が使う資料や道具
   ・学生がつまずきそうなところ
   ・教員が評価のために受け取る提出物
4. 最後に、3つのうちどれを勧めるかを、理由を3文添えて書いてください。

# してはいけないこと
・実在の学生・子ども・保護者・利用者・患者の情報を扱わないでください。例が必要なときは、架空の設定にしてください。
・確かめられない文献名・URL・統計を書かないでください。確かでないことは「確認が必要です」と書いてください。
・手書きでの提出を学生に強制する案は出さないでください。
・学生に生成AIの利用を強制する案は出さないでください。
・一度に出す案は3つまでにしてください。

# 書き方の約束
・日本語で、敬体（です・ます）で書いてください。
・体言止めを使わないでください。
・「革命」「激変」のような、あおる言葉を使わないでください。
・前置きを付けずに、本文だけを書いてください。
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。

⑥ 画面の ［保存］ にあたるボタンを押します。
→ Gem の一覧に「課題づくりの相談相手」が並んで見えれば、保存できています。試しに使っただけでは保存されませんので、必ず押してください。

⑦ 保存した「課題づくりの相談相手」を開いて、入力欄に次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の2か所だけです。

```
学生に体験してほしいことは〔　　　　　　　　　　〕です。
いま出している課題は〔　　　　　　　　　　〕です。
この2つをもとに、課題案を3つ作ってください。
```

→ 案1・案2・案3が並び、それぞれに「学生が実際に行う作業」などの4行が付いていれば、正しく動いています。
→ 3つの案が出ずに質問だけが返ってきたときは、その質問に答えてから、もう一度「案を3つ作ってください」と送ってください。

⑧ 3つの中から1つを選んで、次の文を送信します。

```
案〔1〕を選びます。この課題を、学生にそのまま配れる課題文にしてください。あわせて、学生が最初に行う作業を、学生が読んで動ける手順の形で書いてください。
```

→ 課題文と、学生向けの手順が並んで出てくれば、この手順は終わりです。

**Copilot をお使いの場合**

① ブラウザで `m365.cloud.microsoft` を開き、学園のM365アカウントでサインインします。
→ チャットの入力欄が見えていれば、正しい画面です。

② 画面の左側にある 〈新しいエージェント〉にあたる項目を押します。
→ 「その他のエージェント」から探せる場合もあります。名前と指示を入れる画面が出れば、正しい画面です。

③ 名前の欄に「課題づくりの相談相手」と入れ、指示の欄に、上の⑤と同じ文をすべてコピーして貼り付けます。作成を確定するボタンを押してから、⑦と⑧を同じように行ってください。
→ エージェントの一覧に「課題づくりの相談相手」が並んで見えれば、保存できています。

### シナリオ2　自分の資料から小教材をつくって、専門の目で判定する

つくるもの：小教材（説明・用語・確認問題）と、◎○△×を書き込んだ判定表

使う資料は、ご自身が作った授業のレジュメか、学生が高校時代に学んだ事項をご自身でまとめたメモに限ってください。他の方が作った教材や、購入した書籍は読み込ませないでください。

① ブラウザで新しいタブを開き、アドレス欄に `https://notebook.google.com/?icid=home_maincta` と入力して Enter を押します。
→ 学園のGoogleアカウントでサインインを求められたら、そのままサインインします。
→ ノートブックの一覧が出れば、正しい画面です。

② 画面の右上にある 〈新規作成〉にあたるボタンを押します。
→ 画面の左側に「ソース」の欄があり、資料を追加するようにうながす表示が出れば、正しい画面です。

③ 左側の 〈ソースを追加〉にあたるボタンを押して、自分の授業のレジュメを1つ入れます。
→ Google ドライブのドキュメントとスライドは、ダウンロードせずにそのまま選べます。
→ 手元のファイルは、PDFにしてからドロップするか、ファイルを選んでアップロードします。
→ 左の「ソース」の欄に資料の名前が1行増えていれば、読み込めています。
→ 1つのノートブックに入れられる資料は50件までです。今日は1件で足ります。

④ 画面の下にある質問の入力欄に、次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の1か所だけです。

```
このノートブックに入れた資料だけを使って、学生に配る小さな教材を作ってください。作るものは次の3つです。

1. 学生向けの説明を1つ。400字ほどで、この資料の中心にある考え方を説明してください。
2. この分野の用語を3つ。資料の中で実際に使われている用語から選び、それぞれ2文で説明してください。
3. 確認問題を3問。答えと、なぜその答えになるかの解説を、1文ずつ付けてください。

【書き方の約束】
・読み手は〔　　　　　　　　　　〕の学生です。専門を学び始めた人が読む前提の言葉にしてください。
・資料に書かれていないことは書かないでください。資料から読み取れないところは「資料に記載なし」と書いてください。
・実在の子ども・保護者・利用者・患者の情報は扱わないでください。例が必要なときは、架空の設定にしてください。
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・見出しを付けて、そのまま配れる形で書いてください。
```

→ 説明・用語3つ・確認問題3問が並び、文章のところどころに小さな数字やマークが付いていれば、正しく動いています。
→ その数字を押すと、元の資料のどこにそう書いてあったかが左側に表示されます。1つ押して、元の文を見てください。

⑤ 出てきた小教材を、下の判定表に書き込みながら1つずつ見ます。判定は◎○△×から選び、△と×には理由を書きます。

判定の意味

| 判定 | 意味 |
|---|---|
| ◎ | そのまま学生に見せてよい |
| ○ | おおむね正しいが、言葉足らず |
| △ | 間違ってはいないが、この分野の作法から外れている |
| × | 誤り。学生が読んだら困る |

判定表（この表に直接書き込んでください）

| 見た箇所 | 判定 | 理由・直すところ |
|---|---|---|
| 学生向けの説明 | ◎ ・ ○ ・ △ ・ × |  |
| 用語の説明 1 | ◎ ・ ○ ・ △ ・ × |  |
| 用語の説明 2 | ◎ ・ ○ ・ △ ・ × |  |
| 用語の説明 3 | ◎ ・ ○ ・ △ ・ × |  |
| 確認問題 1 | ◎ ・ ○ ・ △ ・ × |  |
| 確認問題 2 | ◎ ・ ○ ・ △ ・ × |  |
| 確認問題 3 | ◎ ・ ○ ・ △ ・ × |  |

→ △や×が付いた理由は、おおむね次の3つのどれかです。書き込むときの手がかりにしてください。
　 ・資料のほうに書いていなかった
　 ・一般論に寄ってしまった
　 ・専門用語の使い方が、この分野の慣習と違った

⑥ △か×を付けた箇所について、同じ入力欄に次の文をコピーして貼り付け、送信します。埋めていただくのは〔　〕の1か所だけです。

```
いま作った教材のうち、次の箇所を直してください。
〔直す箇所と、この分野の作法から外れている理由を書いてください〕
この分野で通用する言い方に直したうえで、どこをどう直したかを1文ずつ書いてください。資料に書かれていないことを足さないでください。
```

→ 直した文章と、直した箇所の説明が並んで出てくれば、正しく動いています。

⑦ 直った小教材の文章をコピーして、Google ドキュメントか Word に貼り付けます。書き込んだ判定表は、この紙のまま写真に撮っても構いません。
→ 文章と判定表の2つがそろえば、この手順は終わりです。

### シナリオ3　ルーブリックをつくる

つくるもの：課題の評価基準の表（観点4つ × 段階4つ）

**Copilot の教育ツールで作る場合**

① ブラウザで `m365.cloud.microsoft/teach` を開きます。学園のM365アカウントでサインインします。
→ 「授業計画」「フラッシュカード」「ルーブリック」などが並んだ画面が出れば、正しい画面です。

② 一覧の中から ［ルーブリック］ を押します。
→ 一覧に見当たらないときは、画面の上にある検索欄に「ルーブリック」と入力して探してください。
→ 課題の内容を入れる欄が出れば、正しい画面です。

③ 課題の内容を入れる欄に、次の文をコピーして貼り付けます。埋めていただくのは〔　〕の2か所だけです。

```
次の課題を評価するルーブリック（評価の観点と段階を組み合わせた表）を作ってください。

・読み手は〔　　　　　　　　　　〕の学生です。
・課題の内容は〔　　　　　　　　　　〕です。

【表の条件】
・評価の観点を4つにしてください。観点には、専門用語の使い方と、対象となる方への配慮を必ず入れてください。
・段階を4つにしてください。段階の名前は「たいへんよい」「よい」「もう一歩」「これから」にしてください。
・観点と段階が交わるマスには、提出物に何が書かれていればその段階になるのかを、1文で書いてください。
・観点ごとの配点を、合計が100点になるように付けてください。
・表のあとに、学生に配るときの説明を、敬体で3行付けてください。

【守ってください】
・実在の学生・子ども・保護者・利用者・患者の情報は扱わないでください。例が必要なときは、架空の設定にしてください。
・日本語で書いてください。体言止めを使わないでください。
・「革命」「激変」のような、あおる言葉を使わないでください。
```

④ 生成にあたるボタンを押します。
→ 観点が縦、段階が横に並んだ表が出れば、正しく動いています。

⑤ 出てきた表に、観点が4つ、段階が4つそろっているかを目で確かめます。足りないときは、同じ画面で「観点を4つ、段階を4つにして作り直してください」と送ります。
→ 4つ×4つの表になっていれば、正しい状態です。

⑥ 次の文を送って、例を足します。

```
各段階に、学生の提出物でよく見られる例を1つずつ足してください。例はすべて架空のものにしてください。
```

⑦ できた表をコピーして、Word か Google ドキュメントに貼り付けます。
→ 表の形のまま貼り付けられていれば、この手順は終わりです。

**Gemini で作る場合**

① `gemini.google.com` を開き、学園のGoogleアカウントでサインインします。
→ 画面の下に横長の入力欄が見えていれば、正しい画面です。

② 画面の左上にある ［新しいチャット］ を押します。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

③ 入力欄に、上の③と同じ文をコピーして貼り付け、〔　〕の2か所を埋めて送信します。そのあとは、⑤から⑦と同じように進めてください。
→ 観点が縦、段階が横に並んだ表が出れば、正しく動いています。

## 6. 提出します

提出するものは2点です。2点そろわなくても提出してください。

| | 何を出すか |
|---|---|
| ① 成果物 | 今日つくった現物です。Gem やエージェントを作った方は、「指示」の欄の文章を省略せずに全文貼ってください。課題文・小教材・判定表・ルーブリックは、そのものを貼ってください |
| ② インフォグラフィック | やったことを1枚の図にしたものです。作り方は共通ページの Step 3 をご覧ください |

インフォグラフィックに載せる5項目は、グループと班／選んだ題材／使った道具／作ったもの／やってみて分かったこと です。紙に書いて写真を撮ったものでも構いません。

Gem やエージェントの指示文は、必ず全文を貼ってください。リンクは学園の外から開けないことがありますが、指示文があれば、受け取った方が同じものを自分の手元に作れます。

## 7. うまくいかないとき

| 起きること | すること |
|---|---|
| Copilot の教育ツールが開かない | `m365.cloud.microsoft/teach` を開き直します。それでも出ないときは、シナリオ3は Gemini でも作れますので、そちらで進めてください。 |
| Gemini Notebook に資料が入らない | 資料をPDFにしてからアップロードします。それでも入らないときは、資料の文章をコピーして、ソースの追加画面でテキストとして貼り付けます |
| 答えが長すぎて読み切れない | 「3つに絞って、短く書いてください」と送ります |
