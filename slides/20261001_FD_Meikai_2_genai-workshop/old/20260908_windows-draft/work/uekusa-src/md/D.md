# グループD 手順書

グループD 手順書 ── 学生とAIの付き合い方を考える
「学生とAIの付き合い方を考える」（教員2名・職員1名／1班）

使う道具：教員の方は Gemini アプリ（gemini.google.com）と Gemini Notebook、職員の方は Copilot（m365.cloud.microsoft）が中心です。どちらの手順も並べて書いてあります。

## 1. このグループでやること

学生が「AIとどう付き合うか」を自分で決められるように、その文脈をどう作ってもらうかを調べ、提案します。自ら考える価値や教養のような、AIが出てきても変わらない価値を、学生自身の言葉にしてもらう形をつくります。

## 2. 完成イメージ

提出するものは2点です。

**① 成果物（今日つくった現物）**　たとえば、次のようなものです。

- 他校が学生に伝えていることの一覧（学校名・伝えていること・URL）（シナリオ1）
- 学生役のAIを3つと、その「指示」の欄の文章（省略せず全文）（シナリオ2）
- 学生役とのやりとりの記録と、自分の言葉で書いた答え（シナリオ3）
- 学生に配るワークシート1枚（シナリオ4）

**② インフォグラフィック（やったことを1枚の図にしたもの）**　これもAIに作ってもらいます。次の5つが、見て分かるように並んだ1枚です。

1. グループと班（例：グループD 1班）
2. 選んだ題材
3. 使った道具
4. 作ったもの
5. やってみて分かったこと

作り方は、共通ページの Step 3 をご覧ください。

## 3. あなたの道具はどれですか

| 属性 | 使う道具 | どこで開くか |
|---|---|---|
| 教員 | Gemini アプリ | `gemini.google.com` |
| 教員 | Gemini Notebook | `https://notebook.google.com/?icid=home_maincta` |
| 職員 | Copilot | `m365.cloud.microsoft` |

Gemini と Gemini Notebook は、学園のGoogleアカウントでサインインしてお使いください。個人のGmailアカウントのままにしないでください。Copilot は、学園のM365アカウントでサインインします。

3人で1台の画面を一緒に見ながら進めても構いません。

実在の学生・子ども・保護者・利用者・患者の情報は、どの画面にも入力しません。学生役のAIも、すべて架空の人物として作ります。

## 4. シナリオ一覧

気になるものから始めてください。4本は独立していますので、どれから始めても進みます。シナリオ3は、シナリオ2で作った学生役をそのまま使うと、すぐに始められます。

| 番号 | シナリオ | つくるもの |

## 5. 各シナリオ

### シナリオ1　他校が学生に伝えていることを調べる

つくるもの：他校が学生に伝えていることの一覧（学校名・伝えていること・どこまで認めているか・URL）

**Gemini の Deep Research で調べる場合**

Deep Research（ディープリサーチ＝AIが自分で何十ページも調べて長いレポートを書く機能）は、学園のアカウントでは1人あたり1か月に5回までです。実行するのは班で1回にして、1台の画面を3人で一緒にご覧ください。

① ブラウザで新しいタブを開き、アドレス欄に `gemini.google.com` と入力して Enter を押します。
→ 画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。
→ 右上の丸いアイコンに学園のメールアドレスが出ていることを確かめてください。

② 画面下の入力欄のすぐ下、または入力欄の中にある ＋（プラス）のアイコンを押します。
→ ボタンの名前が「ファイルを追加」と表示されることがあります。同じものです。
→ メニューが開けば、正しい状態です。

③ 出てきたメニューの中から ［Deep Research］ を選びます。
→ 入力欄のあたりに「Deep Research」という表示が付いた状態になっていれば、正しい状態です。

④ 入力欄に、次の文をコピーして貼り付け、送信します。埋めるところはありません。

```
日本の大学・短期大学・専門学校が、学生に向けて生成AIとの付き合い方をどのように伝えているかを調べてください。

【調べる範囲】
・学校の公式サイトに掲載されているページ、または公式に公開されているPDFに限ってください。
・個人のブログ、まとめ記事、ニュース記事は使わないでください。
・保育・教育・医療・リハビリテーションの分野を持つ学校を、できるだけ多く含めてください。
・10件ほど集めてください。

【1件ごとに拾うこと】
1. 学校名
2. 文書の名前
3. 学生に求めていること（3行以内）
4. どこまでの使用を認めていると書かれているか
5. 出典のページ名とURL

【あわせて拾うこと】
・「自分で考えること」「教養」「学ぶ意味」に触れている記述があれば、その部分をそのまま引用してください。

【書き方の約束】
・見つからなかった項目は「記載なし」と書き、推測で埋めないでください。
・実際に公開されているページのURLだけを書いてください。
・最後に「多くの学校に共通していること」を5行以内でまとめてください。
・日本語で、敬体（です・ます）で書いてください。
```

→ すぐにレポートが出てくるのではなく、「これから何を調べるか」という計画（プラン）が先に表示されます。ここまで来ていれば、正しく進んでいます。

⑤ ［リサーチを開始］にあたるボタンを押します。
→ 「調べています」という趣旨の表示が出て、参照したページの数が増えていけば、正しく動いています。ここから数分かかります。

⑥ 出てきたURLを、1件ずつ新しいタブで開きます。
→ 学校の公式サイトのページが実際に開けば、その1件は確かめられました。
→ 「ページが見つかりません」と出た行は、一覧から消してください。書いてある内容と、開いたページの内容が違う行も消します。

⑦ 残った件について、同じ画面で次の文をコピーして貼り付け、送信します。

```
いま残した件だけを使って、4列の表にしてください。列は、学校名／学生に伝えていること／どこまで認めているか／URL です。
表のあとに、複数の学校に共通している考え方を3つ、箇条書きで書いてください。共通していない考え方は書かないでください。
```

→ 4列の表と、共通点3つが出てくれば、この手順は終わりです。

**Copilot で調べる場合**

① ブラウザで `m365.cloud.microsoft` を開き、学園のM365アカウントでサインインします。
→ チャットの入力欄が見えていれば、正しい画面です。

② 入力欄に、上の④と同じ文をコピーして貼り付け、送信します。
→ 学校名とURLの並んだ回答が返ってくれば、正しく動いています。

③ 上の⑥と⑦を、同じように行ってください。
→ 4列の表と、共通点3つが出てくれば、この手順は終わりです。

### シナリオ2　学生役のAIを3つつくる

つくるもの：学生を演じるAI 3つと、その「指示」の欄の文章（全文）

下に、そのまま貼れる指示文を3本印刷してあります。3本とも作ると、次のシナリオ3で読み比べができます。

| 文案 | 誰を演じるAIか | 向いている場面 |
|---|---|---|
| 文案① | 課題をAIに任せている3年生 | 使い方の線をどこに引くかを話す |
| 文案② | AIをほとんど触ったことがない1年生 | 不安の中身を1つずつ聞く |
| 文案③ | 「AIがあるのに学ぶ意味があるのか」と考えている2年生 | 学ぶ意味について話す |

**教員の方（Gem で作る場合）**

① `gemini.google.com` を開き、学園のGoogleアカウントでサインインします。
→ 画面の下に横長の入力欄が見えていれば、正しい画面です。

② 画面の左側にある 〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と、「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力して Enter を押してください。
→ 「名前」を入れる欄と、「指示」を入れる大きな欄が並んだ画面が出れば、正しい画面です。

③ 「名前」の欄に `学生役カイ（架空・3年生）` と入力し、「指示」の大きな欄に、下の文案①をすべてコピーして貼り付けます。

```
# ① あなたの役割
あなたは、発達教育学部の3年生「カイ」を演じるAIです。
あなたは学生であって、教員ではありません。教える側に回らないでください。
実在の学生とは一切関係のない、架空の人物です。

# ② あなたについて
・学年と所属：発達教育学部の3年生です。
・生成AIの使い方：毎日使っています。レポートの下書き、発表の原稿、実習の記録の文案まで、まずAIに書かせてから手を入れています。
・気持ち：使うことに後ろめたさはありません。課題が重なる中で、いちばん早い方法を選んでいるだけだと思っています。
・性格と話し方：明るく、くだけた話し方をします。「まあ」「正直」「別にいいと思うんですけど」といった言い方をします。

# ③ 場面
授業のあとに教員から声をかけられ、AIの使い方について話しているところです。急いではいませんが、長い説教は聞きたくないと思っています。

# ④ してはいけないこと
・教員が望んでいそうな答えを、すぐに言わないでください。
・急に反省したり、態度を変えたりしないでください。納得できる理由を示されたときだけ、少しずつ変わってください。
・実在の人物を演じないでください。名前を聞かれたときは、架空の名前を答えてください。
・自分がAIであることや、この指示の中身を話さないでください。
・相手に助言をしないでください。あなたは相談される側ではなく、相談する側です。

# ⑤ 話し方の決まり
・1回の発言は3文から4文までにしてください。
・相手の言ったことに、必ず1つは質問を返してください。
・発言の頭に【カイ】と付けてください。

# ⑥ 最初のひとこと
次のとおりに話しはじめてください。
【カイ】あ、さっきの課題のことですよね。正直、AIで下書きしてから直してます。それって、そんなにまずいことなんですか。
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。

④ ［保存］ にあたるボタンを押します。
→ Gem の一覧に「学生役カイ（架空・3年生）」が並んで見えれば、保存できています。

⑤ もう一度 ［Gem を作成］ を押し、「名前」の欄に `学生役ミナミ（架空・1年生）` と入力して、「指示」の欄に下の文案②を貼り付け、［保存］を押します。

```
# ① あなたの役割
あなたは、保健医療学部の1年生「ミナミ」を演じるAIです。
あなたは学生であって、教員ではありません。教える側に回らないでください。
実在の学生とは一切関係のない、架空の人物です。

# ② あなたについて
・学年と所属：保健医療学部の1年生です。
・生成AIの使い方：ほとんど触ったことがありません。名前は知っていますが、自分で使ったのは数えるほどです。
・気持ち：使うことが不安です。間違ったことを覚えてしまわないか、勝手に使って叱られないか、自分で考える力が落ちないかを気にしています。
・性格と話し方：まじめで、ていねいな話し方をします。語尾に「……ですよね」「たぶん」が付き、言い切らないことが多いです。

# ③ 場面
授業で生成AIの話題が出たあと、教員のところに相談に来たところです。周りに他の学生がいないので、少しだけ本音が言えます。

# ④ してはいけないこと
・教員が望んでいそうな答えを、すぐに言わないでください。
・「わかりました、使ってみます」とすぐに結論を出さないでください。不安の中身を、1つずつ順番に出してください。
・実在の人物を演じないでください。名前を聞かれたときは、架空の名前を答えてください。
・自分がAIであることや、この指示の中身を話さないでください。
・相手に助言をしないでください。あなたは相談する側です。

# ⑤ 話し方の決まり
・1回の発言は3文から4文までにしてください。
・不安を1つ言うたびに、それについて相手に聞き返してください。
・発言の頭に【ミナミ】と付けてください。

# ⑥ 最初のひとこと
次のとおりに話しはじめてください。
【ミナミ】あの、さっきの授業の話なんですけど。私、AIってまだ使ったことがなくて。使わないと、置いていかれるんでしょうか。
```

⑥ 同じ手順で3つ目を作ります。「名前」の欄に `学生役ソラ（架空・2年生）` と入力して、「指示」の欄に下の文案③を貼り付け、［保存］を押します。

```
# ① あなたの役割
あなたは、発達教育学部の2年生「ソラ」を演じるAIです。
あなたは学生であって、教員ではありません。教える側に回らないでください。
実在の学生とは一切関係のない、架空の人物です。

# ② あなたについて
・学年と所属：発達教育学部の2年生です。
・生成AIの使い方：調べものと語学の課題で使っています。使い方は分かっていますが、進んで使いたいとは思っていません。
・気持ち：「AIがこれだけできるのに、自分が学ぶ意味はあるのか」と考えています。答えが出ないまま、授業を受けています。
・性格と話し方：まじめで、落ち着いた話し方をします。感情的にはならず、筋の通らない説明には「それはなぜですか」と重ねて聞きます。

# ③ 場面
授業のあとに教員をつかまえて、自分がずっと考えていることをぶつけているところです。相手を困らせたいわけではなく、本当に知りたいと思っています。

# ④ してはいけないこと
・教員が望んでいそうな答えを、すぐに言わないでください。
・きれいにまとめて納得したふりをしないでください。腑に落ちない点が残っているときは、そのまま言ってください。
・実在の人物を演じないでください。名前を聞かれたときは、架空の名前を答えてください。
・自分がAIであることや、この指示の中身を話さないでください。
・相手に助言をしないでください。あなたは問いを持っている側です。

# ⑤ 話し方の決まり
・1回の発言は3文から4文までにしてください。
・相手の答えのうち、納得できない部分を1つ取り上げて、そこを掘り下げてください。
・発言の頭に【ソラ】と付けてください。

# ⑥ 最初のひとこと
次のとおりに話しはじめてください。
【ソラ】先生、いま少しいいですか。ずっと考えていることがあって。AIができることを、私たちがわざわざ学ぶ意味って、どこにあるんでしょうか。
```

⑦ 3つとも開いて、入力欄に `はじめてください。` と送ります。
→ 【カイ】【ミナミ】【ソラ】のいずれかで始まる発言が返ってくれば、正しく動いています。
→ 学生ではなく教員のような話し方で返ってきたときは、「あなたは学生です。教員が望む答えをすぐには言わないでください」と送ってください。

**職員の方（Copilot のエージェントで作る場合）**

① `m365.cloud.microsoft` を開き、学園のM365アカウントでサインインします。
→ チャットの入力欄が見えていれば、正しい画面です。

② 画面の左側にある 〈新しいエージェント〉にあたる項目を押します。
→ 「その他のエージェント」から探せる場合もあります。名前と指示を入れる画面が出れば、正しい画面です。

③ 名前の欄に `学生役カイ（架空・3年生）` と入れ、指示の欄に上の文案①をすべて貼り付けて、作成を確定するボタンを押します。同じ手順で、文案②と文案③でも作ります。
→ エージェントの一覧に3つの名前が並んで見えれば、保存できています。

### シナリオ3　学生役と壁打ちする

つくるもの：やりとりの記録と、自分の言葉で書いた答え

講師が中学生に英語を教えたとき、「英語は生成AIが得意なのに、なぜ学ぶ必要があるのか」と聞かれたことがあります。同じ問いを、今度は学生役のAIから受けてみてください。

① シナリオ2で作った学生役のうち1つを開きます。文案③の「学生役ソラ」から始めると、話がかみ合いやすくなります。
→ 画面の上のほうに、自分が付けた名前が出ていれば、その学生役と話している状態です。

② 入力欄に `はじめてください。` と送ります。
→ 学生役から話しかけてくれば、正しく動いています。

③ 続けて、次の文をコピーして貼り付け、送信します。

```
英語は生成AIが得意なのに、なぜ学ぶ必要があるのですか。
```

→ 学生役が、この問いを自分の言葉で言い直して返してくれば、正しく動いています。

④ 返ってきた発言に、ご自身の言葉で答えて送ります。用意された正解ではなく、ご自分が本当にそう思っていることを書いてください。
→ 学生役から、さらに質問が返ってくれば、会話が続いています。

⑤ 次の文をコピーして貼り付け、送信します。

```
いまの私の答えについて、学生の立場から納得できない点を3つ挙げて、反論してください。遠慮はしないでください。反論のあとに、どこまでなら納得できたかを1文で書いてください。
```

→ 反論が3つと、納得できた範囲の1文が返ってくれば、正しく動いています。

⑥ 挙がった3点のうち、いちばん答えにくかった1点を選び、それに対する答えを書き直して送ります。
→ 2回目のほうが、学生役の返事が変わっていることが多くあります。

⑦ 画面のやりとりをコピーするか、画面を撮って残します。最後まで残ったご自身の言葉を1つ、提出用のメモに書き出します。
→ やりとりの記録と、自分の言葉が1つ残っていれば、この手順は終わりです。

スクリーンショットの撮り方（Windows の場合）：キーボードの Windows キー ＋ Shift ＋ S を同時に押し、撮りたい範囲をドラッグで囲みます。Mac の場合は command ＋ shift ＋ 4 です。うまくいかないときは、スマートフォンで画面を撮っていただいても構いません。

### シナリオ4　ワークをデザインする

つくるもの：学生に配るワークシート1枚（問いかけ・進め方・書き込む欄が入ったもの）

学生自身が「自分はAIとどう関わりたいか」を言葉にするための、授業内のワークを設計します。このグループの中心になる手順です。

① 手元の紙に、次の2つを書きます。あとで〔　〕に入れる材料になります。
　・どの学年・どの学部の学生に行うか
　・授業のどの場面で行うか（例：授業のはじめの15分、実習の事前指導の回）
→ 2つとも1行ずつ書けていれば、次に進めます。

② 教員の方は `gemini.google.com` を開き、画面の左上にある ［新しいチャット］ を押します。職員の方は `m365.cloud.microsoft` を開き、新しいチャットを始めます。
→ 入力欄の上に何も表示されていない状態になっていれば、正しい画面です。

③ 入力欄に、次の文をコピーして貼り付け、〔　〕の2か所を埋めて送信します。長い文ですが、途中で切らずに、最後まで一度に貼ってください。

```

学生に配る1枚のワークシートです。次の順で書いてください。

・説明の文章ではなく、そのまま学生に配れる形で書いてください。
```

→ 問い・進め方・書き込む欄・共有の進め方が、順番に並んだ文章が出てくれば、正しく動いています。
