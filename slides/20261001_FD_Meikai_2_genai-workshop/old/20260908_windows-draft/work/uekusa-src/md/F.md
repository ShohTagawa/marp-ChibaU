# グループF 手順書

「広報・情報発信の効率化」（広報の方1名＋職員の方8名）

使う道具：Copilot（m365.cloud.microsoft）が中心です。Canva を使えるのは1名だけですので、Canva を使うシナリオは1本だけにしてあります。

## 1. このグループでやること

1つの広報ネタを、Webのお知らせ・保護者向けの文・SNSの短文・掲示の文言といった、いくつもの出し先に作り分けます。文章も挿絵も、Copilot だけで作れるように書いてあります。

## 2. 完成イメージ

提出するものは2点です。

① 成果物（今日つくった現物）。たとえば、次のようなものです。

- 行事の案内文（500字以内）
- 同じ行事を4つの出し先に作り分けた文（Webのお知らせ／保護者向けの文／SNSの短文／掲示の文言）
- 広報文をつくる係（エージェント）の指示文の全文
- 案内やSNSにのせる挿絵が1枚
- （Canvaが使える方）文章と挿絵を配置した、1枚の案内

② インフォグラフィック（やったことを1枚の図にしたもの）。これもAIに作ってもらいます。班の名前、選んだ題材、使った道具、作ったもの、やってみて分かったことの5つが、見て分かるように並んだ1枚です。作り方は「7. 提出します」にあります。

## 3. あなたの道具はどれですか

| どなたが | 使う道具 | どこで開くか |
|---|---|---|
| 職員の方（8名） | Copilot | https://m365.cloud.microsoft |
| 広報の方（1名） | Copilot と Canva | https://m365.cloud.microsoft ／ https://www.canva.com |

Canva をお持ちなのは1名だけです。シナリオ1から4までは、Canva がなくても最後まで進みます。

1台の画面を二人や数人で一緒に見ながら進めても構いません。

### 道具の開き方（各シナリオの①で使います）

**Copilot を開きます**

① ブラウザ（Edge や Chrome など）の新しいタブを開きます。
→ 何も表示されていない、空のタブが開けば、正しい状態です。

② アドレス欄に `https://m365.cloud.microsoft` と入力して、Enter を押します。
→ サインインを求められたら、学園の Microsoft アカウント（ふだん学園のメールで使っているもの）でサインインします。個人のアカウントでは開けません。

③ 画面の下のほうにある、文章を打ち込む横長の入力欄をクリックします。
→ 入力欄のあたりに「このチャットには エンタープライズ データ保護 が適用されます」という趣旨の表示が出ていれば、正しい画面です。
→ この表示は、入力した内容が外部の学習に使われない状態であることを示しています。

**Canva を開きます（お持ちの方だけ）**

① ブラウザの新しいタブを開き、アドレス欄に `https://www.canva.com` と入力して、Enter を押します。
→ ご自分のアカウントでサインインした状態になり、「デザインを作成」にあたるボタンが見えていれば、正しい画面です。

### シナリオ1　案内文を1本つくる

つくるもの：行事の案内文が1本（500字以内）

① Copilot を開きます（開き方は「3. あなたの道具はどれですか」にあります）。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 次の文を、省略せずにそのままコピーして、入力欄に貼り付けます。〔　〕は1か所だけです。上の架空ネタ①か②の名前を書き入れてください。

```
あなたは、学校法人の広報を担当する職員です。
これからお渡しする行事の案内文を作ってください。行事の名前は「〔 そよかぜ子育て相談ひろば 〕」です。
行事の詳しい情報は、この文のすぐあとに貼る表のとおりです。
【書き方の約束】
・本文は500字以内にしてください。
・日本語で、敬体（です・ます）で書いてください。
・体言止めを使わないでください。
・最初の2文で、誰に向けた行事なのかが分かるようにしてください。
・日付、会場、対象と定員、費用、申込の締切、問い合わせ先は、貼った表のとおりに写してください。言い換えないでください。
・表に書かれていないことを、想像で足さないでください。分からないところは〔要確認〕と書いてください。
・「革命」「激変」のような、あおる言葉を使わないでください。
・最後に、こちらで確かめたほうがよい点を、箇条書きで3つまで添えてください。
行事の情報は次のとおりです。
```

③ 続けて、上の架空ネタ①か②の表を、そのままコピーして貼り付けます。
→ 入力欄の中に、指示の文と表の両方が入っていれば、正しい状態です。

④ 入力欄の右にある送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ 文字が少しずつ表示されはじめれば、正しく動いています。最後まで表示されるのを待ちます。

⑤ 出てきた案内文の、日付・会場・定員・費用・締切・問い合わせ先を、上の表と1つずつ見比べます。
→ 表と違う内容が入っていたら、「日付は2026年10月17日です。直してください。」のように、正しい内容を書いて続けて送ります。

⑥ 〔要確認〕と書かれた箇所を、自分の言葉で書き換えます。
→ 〔要確認〕が1つも残っていない案内文になっていれば、そのまま提出できます。

### シナリオ2　同じネタを4つの出し先に広げる

つくるもの：Webのお知らせ、保護者向けの文、SNSの短文、掲示の文言の4本

作り分ける4つの出し先は、次のとおりです。1本の指示で4つとも出させます。

| 出し先 | 長さ | 入れること |
|---|---|---|
| Webのお知らせ | 400字以内 | 最初の1文に、日付と対象 |
| 保護者向けの文 | 300字以内 | 当日の持ち物と、雨天のときの扱い |
| SNSの短文 | 120字以内 | 日付と、申込の締切 |
| 掲示の文言 | 見出し60字以内と本文3行 | 離れた場所から読める短い語 |

① Copilot を開きます。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 次の文を、省略せずにそのままコピーして、入力欄に貼り付けます。

```
このあとに貼る行事の情報を、4つの出し先に作り分けてください。見出しを付けて、4つとも全文を書いてください。
1. Webのお知らせ：400字以内にしてください。最初の1文で、日付と対象が分かるようにしてください。
2. 保護者向けの文：300字以内にしてください。当日の持ち物と、雨天のときの扱いに触れてください。
3. SNSの短文：120字以内にしてください。絵文字を使わず、日付と申込の締切を必ず入れてください。
4. 掲示の文言：60字以内の見出しと、3行までの本文にしてください。離れた場所から見て読めるように、短い語で書いてください。
【書き方の約束】
・4つとも、日付、会場、締切、問い合わせ先を同じ内容にそろえてください。
・日本語で、敬体（です・ます）で書いてください。
・体言止めを使わないでください。
・貼った情報に無いことを足さないでください。分からないところは〔要確認〕と書いてください。
・「革命」「激変」のような、あおる言葉を使わないでください。
行事の情報は次のとおりです。
```

③ 続けて、シナリオ1で作った案内文か、上の架空ネタ①か②の表を、そのままコピーして貼り付けます。

④ 送信ボタンを押します。
→ 「1. Webのお知らせ」から「4. 掲示の文言」まで、4つの見出しが並んで表示されれば、正しく動いています。

⑤ 4本を並べて、日付と締切が食い違っていないかを確かめます。
→ 食い違っていたら、「4つとも締切を10月10日にそろえて、もう一度全文を出してください。」と続けて送ります。

⑥ SNSの短文の字数を数えます。
→ 120字を超えていたら、「SNSの短文を120字に収めて、もう一度出してください。」と続けて送ります。

### シナリオ3　広報文をつくる係を作る

つくるもの：広報の決まりごとを覚えたエージェントと、その指示文の全文

エージェントとは、指示をあらかじめ仕込んでおける、自分専用の Copilot のことです。一度作れば、毎回長い指示を打ち直さずに使えます。

① Copilot を開きます。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 画面の左側のサイドバーで、〈エージェント〉にあたる並びを探します。
→ 「Idea Coach」「新しいエージェント」「その他のエージェント」といった名前が並んでいれば、正しい場所です。

③ ［新しいエージェント］にあたる項目を押します。
→ 自分専用のエージェントを作る画面（Build your own specialist agent という趣旨の画面）が出れば、正しい画面です。
→ 「テンプレート」と「自分のエージェント」という2つのタブが出ることがあります。その場合は「テンプレート」の側から進みます。
→ 名前を入れる欄と、指示を入れる大きな欄が見つからないときは、この手順を飛ばして、シナリオ1か2の文を毎回貼る形で進めてください。

④ 「名前」にあたる欄に、次のように入力します。〔　〕は1か所だけです。ご自分の部署名を入れてください。

```
〔 総務課 〕の広報文づくり係
```

⑤ 「指示」にあたる大きな欄に、次の文を、省略せずにそのままコピーして貼り付けます。長いですが、そのまま全文を貼ってください。

```
あなたは、学校法人の広報文をつくる係です。
利用者が行事の情報を渡したら、次の4つを、見出しを付けて全文で出してください。
1. Webのお知らせ（400字以内）
2. 保護者向けの文（300字以内）
3. SNSの短文（120字以内）
4. 掲示の文言（60字以内の見出しと、3行までの本文）
【文体の決まり】
・日本語で、敬体（です・ます）で書きます。
・体言止めを使いません。
・1つの文は60字以内にします。
・学園そのものは「本学園」と書きます。
・来場される方は「ご来場の皆さま」、お子さんの保護者は「保護者の皆さま」、在学者は「学生の皆さん」と書きます。
【使わない表現】
・「絶対」「必ず満足」「日本一」「業界初」のような言い切りを使いません。
・「革命」「激変」のような、あおる言い方をしません。感嘆符は1つの文書に1つまでにします。
【必ず守ること】
・日付、会場、定員、費用、締切、問い合わせ先は、渡された情報のとおりに写します。言い換えません。
・渡された情報に無いことを足しません。分からないところは〔要確認〕と書きます。
・個人名、電話番号、写真の写り込みについては、そのまま出さずに〔要確認〕と書きます。
・4つとも、日付、会場、締切、問い合わせ先を同じ内容にそろえます。
・最後に、確かめていただきたい点を、箇条書きで3つまで添えます。
最初のやり取りでは、「行事の情報を貼ってください。」とだけ返します。
```

⑥ 〈作成〉または〈保存〉にあたるボタンを押します。
→ 作ったエージェントの名前が、画面の左側の一覧に増えていれば、保存できています。

⑦ チャットの入力欄で「＠」を入力し、作ったエージェントの名前を選びます。
→ 入力欄のあたりに、そのエージェントの名前が付いた状態になれば、正しい状態です。

⑧ 上の架空ネタ①か②の表をそのまま貼り付けて、送信ボタンを押します。
→ 4つの見出しが並んだ文が返ってくれば、係として動いています。

### シナリオ4　挿絵をつくる

つくるもの：案内やSNSにのせる挿絵が1枚

絵の頼み方は、〈何を〉〈どんな絵柄で〉〈どの色で〉〈どの形で〉の4つを、1行ずつ分けて書きます。指定に迷ったときは、下の表から選んでください。

| 決めること | 書き方の例 |
|---|---|
| 絵柄 | 線が細く、色数の少ない平面的なイラスト／太い線の、はっきりしたイラスト |
| 色 | 白を背景に、緑と灰色を中心に／白を背景に、青と橙を中心に |
| 形 | 横長／正方形／縦長 |

① Copilot を開きます。
→ 文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

② 入力欄の上のあたりにある「何を作りますか?」という表示から、［画像の作成］にあたる項目を押します。
→ 「画像の作成」「ビデオの作成」という2つの選び方が並んで見えていれば、正しい場所です。
→ 見つからないときは、入力欄の「＋」を押して、〈機能を追加〉→〈画像を生成する〉にあたる項目を選びます。

③ 次の文を、省略せずにそのままコピーして貼り付けます。〔　〕は1か所だけです。上の架空ネタの内容を書き入れてください。

```
広報のお知らせにのせる挿絵を1枚作ってください。
題材は「〔 親子で絵本を読む子育て相談の会 〕」です。
絵柄は、線が細く、色数の少ない平面的なイラストにしてください。
色は、白を背景に、緑と灰色を中心にしてください。
形は横長にしてください。
画像の中に文字を入れないでください。
実在の人物、実在の建物、実在の校章には似せないでください。
```

④ 送信ボタンを押します。
→ しばらく待つと、画像が表示されます。作った画像は「マイ画像」に残ります。

⑤ 直したいところがあれば、「背景を薄い水色にして、もう一度作ってください。」のように、1か所だけ書いて続けて送ります。
→ 絵柄・色・形のうち、変えたいものを1つずつ書くと、思ったものに近づきます。

⑥ 気に入った画像を保存します。画像の上で右クリックして「名前を付けて画像を保存」を選ぶか、画面のスクリーンショットを撮ります。
→ スクリーンショットの撮り方（Windows）：Windows キー ＋ Shift ＋ S を同時に押し、撮りたい範囲をドラッグで囲みます。Mac は command ＋ shift ＋ 4 です。

### シナリオ5　見た目を仕上げる（Canva をお持ちの方）

つくるもの：文章と挿絵を配置した、1枚の案内

Canva には、有料プランでのみ使える機能と、月あたりの回数の上限がある機能があります。押せない機能や、上限の表示が出た機能は飛ばして、次の手順に進んでください。使える機能だけでも1枚は仕上がります。

| 使う機能 | 何に使うか |
|---|---|
| マジック作文 | 文章を、掲示物の長さに整えます |
| マジック生成 | 挿絵やイラストを作ります |
| AI背景生成 | 写真の背景を差し替えます |
| マジック消しゴム | 写真の写り込みを消します |
| マジック切り抜き | 写真から人物や物を切り抜きます |
| マジック拡張 | 写真の足りない余白を広げます |
| 高画質化 | 粗い写真をはっきりさせます |

① Canva を開きます（開き方は「3. あなたの道具はどれですか」にあります）。
→ 「デザインを作成」にあたるボタンが見えていれば、正しい画面です。

② 〈デザインを作成〉にあたるボタンを押し、「ポスター」または「A4 文書」にあたる大きさを選びます。
→ 白いページが1枚だけ表示された編集画面が出れば、正しい画面です。

③ シナリオ1か2で作った文章を、ページの中に貼り付けます。
→ 文字の枠が置かれ、貼った文が読める状態になっていれば、正しい状態です。

④ 貼った文字を選んだ状態で、〈マジック作文〉にあたる項目を押し、次の文を貼って実行します。

```
この文章を、掲示物にのせる長さに整えてください。
1つの文は60字以内、全体で200字以内にしてください。
日付、会場、締切、問い合わせ先は、書かれているとおりに残してください。
書かれていないことを足さないでください。
体言止めを使わないでください。
```

→ 押せない場合や、上限の表示が出た場合は、この手順を飛ばして⑤に進みます。文章はシナリオ1か2で作ったものをそのまま使えます。

⑤ 〈マジック生成〉にあたる項目から、次の文を貼って挿絵を作ります。

```
線が細く、色数の少ない平面的なイラストを作ってください。
題材は「親子で絵本を読む子育て相談の会」です。
白を背景に、緑と灰色を中心にしてください。
画像の中に文字を入れないでください。
実在の人物や建物には似せないでください。
```

→ 使えない場合は、シナリオ4で Copilot が作った画像を、パソコンに保存してから Canva にアップロードして使います。

⑥ 写真を使う場合は、上の表の機能で直します。背景を差し替えるなら〈AI背景生成〉、写り込みを消すなら〈マジック消しゴム〉、人物を切り抜くなら〈マジック切り抜き〉、余白を広げるなら〈マジック拡張〉、粗い写真をはっきりさせるなら〈高画質化〉を使います。
→ 押せない機能は飛ばします。写真を使わずに、文章と挿絵だけで仕上げても構いません。

⑦ 文章と挿絵を配置し、〈共有〉または〈ダウンロード〉にあたるボタンから、画像かPDFとして書き出します。
→ ファイルがパソコンに保存されれば、仕上がりです。

## 8. うまくいかないとき

| 起きていること | すること |
|---|---|
| Word や PowerPoint の中に Copilot のボタンが見つからない | アプリの中の Copilot は、別の契約が必要です。`https://m365.cloud.microsoft` のチャット画面を使い、ファイルは入力欄の「＋」から添付します。 |
| 渡していない日付や場所が、文の中に入っている | その箇所を書き出して、「貼った表のとおりに直してください。」と続けて送ります。 |
| Canva の機能が押せない、または上限の表示が出る | その手順を飛ばします。文章と画像は Copilot で作れます。 |
| 絵が思ったものにならない | 絵柄・色・形の指定を1行ずつに分けて書き直し、もう一度送ります。 |
| 文を貼っている途中で送信されてしまう | 改行は Shift キーを押しながら Enter キーを押して入れます。 |
