# テーマ③　手順書

「全く新しい授業課題を、つくる」（教員2〜3名）

使う道具：Gemini アプリ（Gem を含む）が中心です。

---

## 1. このテーマでやること

AIがあるからこそ成立する、新しい課題を1本つくります。不動産の現場にある「答えが1つに決まらない問題」を題材にして、学生が複数の立場に触れながら判断する課題です。このワークが終わるとき、みなさんの手元に、学生にそのまま配れる課題文と、その課題で学生の相手役になるAI、そしてその課題を使う1コマの授業シナリオ（進行表）ができあがっています。

12月3日までに、その課題を1コマで試してみます。

## 2. 完成イメージ

提出するのは、下の **② のスライド1枚**です。① の試作は、共有できる形になっていれば、そのスライドの下部にリンクを貼って学内に共有します（任意）。

**① 試作（今日つくった現物）。** たとえば、次のようなものです。

- 課題文（題材・学生がすること・提出するもの・AIの使い方・評価の観点、が1枚に書いてあるもの）
- 学生の相手役になるAI（Gem）の共有リンク、またはその指示文の全文
- 学生役のAIに解かせてみて見つかった、課題の穴と直した点（1〜2行）

**② 提出するスライド（またはインフォグラフィック）。** 作り方は、共通ページの Step 5 をご覧ください。「12月3日までに試すこと」を必ず入れてください。

## 3. あなたの道具はどれですか

このグループは全員が同じ道具を使います。大学のGoogleアカウントで使います。

| 道具 | どこで開くか | 得意なこと |
|---|---|---|
| Gemini アプリ | `https://gemini.google.com/app` | 課題を設計する、解かせてみる |
| Gem（ジェム） | Gemini アプリの左側のメニュー、または `https://gemini.google.com/gems/create` | 指示をあらかじめ仕込んでおける、自分専用の Gemini。学生に配れる |

**開き方（どのシナリオも、ここから始まります）**

① ブラウザ（Chrome など）の新しいタブを開きます。

② アドレス欄に、上の表のアドレスを入力して、Enter を押します。
→ Gemini アプリは、画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

③ 画面の右上にある丸いアイコンを押して、大学のGoogleアカウントでサインインしているかを確かめます。
→ 大学のメールアドレスが表示されていれば、正しい状態です。
→ 個人のGmailのアドレスが出ていたら、大学のアカウントに切り替えてください。
→ サインインできない方は、グループの他の方の画面を一緒に見る形で進めてください。

## 5. 各シナリオ

### シナリオ1　「少し遠くまで行ける課題」を設計する

つくるもの：課題文の下書き（題材・すること・提出物・AIの使い方・評価）

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。

② グループで、学生に体験してほしいことを1つ決めます。決めにくいときは、巻末の「題材の例」から1つ選んでください。

③ 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔担当科目名〕と〔体験してほしいこと〕の2か所です。

```
あなたは、大学の授業設計に詳しいアドバイザーです。
不動産学部の〔 担当科目名 〕で、生成AIを使うことを前提にした新しい課題を設計するのを手伝ってください。
課題を決めるのは私です。あなたは、材料をそろえて、選択肢を示す係です。

【この課題で学生に体験してほしいこと】
〔 例：立場が違う人の言い分を聞いて、自分の判断を根拠つきで説明する 〕

【課題の条件】
・現実にありそうな、答えが1つに決まらない問題を題材にしてください（題材は架空の都市・架空の物件で構いません）。
・学生が、最初に自分の考えを書いてから、AIを使う順番にしてください。
・AIは「答えを出す道具」ではなく、「相手役」または「資料を出す係」として使わせてください。
・提出物には、学生自身の判断と、その根拠が必ず入るようにしてください。
・教員の追加作業量は「中」までにしてください。受講人数は40名を想定してください。

【手順】
まず、次の3つを私に質問してください。私が答えるまで、課題案を出さないでください。
　(a) 学年と、この課題に使える授業時間（何コマか）
　(b) 学生がこれまでに学んでいること（前提知識）
　(c) 提出の形（レポート／発表／その両方）
私が答えたら、課題案を2つ出してください。各案に必ず付けるもの：
　・題材（1段落）
　・学生がすること（手順を番号つきで。AIを使う段階には「AI」と明記）
　・提出するもの
　・AIの使い方（使ってよい場面、使わない場面）
　・評価の観点（3つ）
　・この課題で学生が「少し遠くまで行ける」理由（1行）
最後に、「この課題でうまくいかない可能性」を1つ挙げてください。

【書き方の約束】
・敬体で、体言止めを使わずに書いてください。
・実在を確認できない統計や文献名を書かないでください。
・「革命」「激変」のような、あおる言葉を使わないでください。
```

④ 送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ いきなり課題案が出ず、3つの質問が返ってくれば、正しく動いています。

⑤ 3つの質問に答えます。課題案が2つ返ってきたら、グループで1つを選び、「案〔番号〕で進めます」と送ります。

⑥ 選んだ案をコピーして、提出用の文書に貼ります。

### シナリオ2　利害関係者役のAIをつくる

つくるもの：学生の相手役になる Gem（地権者・自治体・投資家 の3役）

Gem（ジェム）とは、指示をあらかじめ仕込んでおける、自分専用の Gemini のことです。一度作れば、共有リンクで学生に配れます。

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。

② 画面の左上にある「三本線」のボタンを押して、左側のメニューを開き、〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力してください。
→ 「新しい Gem」を作る画面（名前を入れる欄と、指示を入れる大きな欄がある画面）が出れば、正しい画面です。

③ 一覧の画面が出た方は、［Gem を作成］にあたるボタン（＋のボタン）を押します。

④ 「名前」の欄に、次のように入れます。

```
湊南市 駅前再開発 利害関係者（〔 あなたのお名前 〕）
```

⑤ 「指示」の大きな欄に、次の文をまるごとコピーして貼り付けます。埋めるところはありません。シナリオ1で別の題材を選んだ方は、【設定】の段落だけ、その題材に書き換えてください。

```
# 役割
あなたは、不動産学部の授業で使う「利害関係者の役」を演じるAIです。
学生は、あなたと対話しながら、立場の違う人の言い分を聞き取り、自分の判断を組み立てます。
あなたの仕事は、役になりきって答えることです。学生の代わりに結論を出すことではありません。

# 設定（架空です）
架空の都市「湊南市」で、2年後に新駅の開業が予定されています。駅前の約2ヘクタールの地区に、
古い商店街と低層の住宅が混在しています。市は、この地区の再開発の方針を検討しています。
以下の3人は、いずれも架空の人物です。

# 演じる3つの役
学生が最初に「〔役の名前〕でお願いします」と言った役を演じてください。役は途中で変えられます。

【地権者】商店街で40年続く金物店の店主。土地と建物は自己所有。息子は継がない。
　再開発で店を閉じることには複雑な気持ちがある。補償の額より「この街で暮らし続けられるか」を気にしている。
【自治体】市の都市計画課の担当者。人口減少と税収の先細りを心配している。
　再開発で駅前のにぎわいを取り戻したいが、住民の反対で計画が長引くことを恐れている。
　公的な立場なので、断定的な約束はしない。
【投資家】不動産開発会社の事業担当者。駅前の商業施設と分譲マンションの複合開発を提案している。
　採算が第一だが、地元との対立で工期が延びるのは避けたい。数字（想定の利回りや工期）を使って話す。

# 答え方の決まり
・1回の返答は、4文以内にしてください。
・役の立場からしか知らないことだけを話してください。他の役の内心を代弁しないでください。
・学生が「正解は何ですか」「どうすればいいですか」と聞いたら、答えを出さずに、
　「私の立場からは〜と思いますが、決めるのはあなたです」と返してください。
・学生が根拠を示さずに主張したら、「その根拠は何ですか」と1回だけ聞き返してください。
・実在の企業名・地名・統計の数値を出さないでください。数字を使うときは「仮に」と前置きしてください。
・敬体で話してください。

# 最初の一言
会話が始まったら、あなたのほうから次のように話しかけてください。
「湊南市 駅前再開発の利害関係者です。地権者・自治体・投資家のどの役で話しますか。
　役の名前を書いてください。途中で変えることもできます。」
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。
→ 英語の授業で使うときは、「# 答え方の決まり」の最後に次の1行を足しておきます。
　 `・英語で話してください。相手が日本語で話しかけてきたときも、英語で返してください。`

⑥ 画面の右側にある試し打ちの欄に、次の1行を入れて送ります。

```
地権者でお願いします。再開発に賛成ですか。
```

→ 金物店の店主として、4文以内で答えが返ってくれば、指示文が効いています。
→ 長々と答えたり、結論を出してしまったりするときは、「指示」の欄に「# 答え方の決まり」の段落が入っているかを確かめてください。

⑦ 画面の ［保存］ を押します。
→ Gem の一覧に、いま付けた名前が並んでいれば、保存できています。右側で試しに動かしただけでは保存されません。

⑧ 学生に配るときは、Gem の一覧で ［共有］ を押し、範囲は「組織内」、権限は「閲覧者」を選んで、［リンクをコピー］ を押します。
→ 「編集者」にすると、学生が指示文を書き換えられます。学生に配るときは「閲覧者」のままにしてください。
→ リンクがコピーされた、という表示が出れば成功です。
→ 共有ボタンが押せないときは深追いしないでください。「指示」の欄の文章をまるごとコピーして提出すれば、受け取った方は同じものを作れます。

### シナリオ3　学生役のAIに解かせて、穴を見つける

つくるもの：課題の穴と、直した点

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。

② 画面の左上にある ［新しいチャット］ を押します。

③ 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔課題文〕の1か所です。シナリオ1で作った課題文を貼ってください。

```
あなたは、不動産学部の2年生の役です。忙しく、できるだけ手間をかけずに単位を取りたいと思っています。
次の課題を受け取りました。

【課題文】
〔 ここに、課題文を貼り付けてください 〕

学生役として、次の3つを正直に答えてください。
1. この課題を、生成AIに丸投げして済ませるとしたら、どこまでできてしまいますか。
　　できてしまう部分と、自分で考えないと書けない部分を分けて書いてください。
2. 課題文の中で、意味が分からないところ、解釈が分かれそうなところを3つ挙げてください。
3. この課題を「面倒だが、やる価値がある」と感じるとしたら、それはどの部分ですか。1行で書いてください。

そのあとで、学生役をやめて、教員へのアドバイザーとして、
「課題文をどう直せば、丸投げできる部分が減り、考える部分が増えるか」を3つ提案してください。
敬体で、体言止めを使わずに書いてください。
```

④ 送信ボタンを押します。
→ 学生役の答え（1〜3）と、アドバイザーとしての提案（3つ）が返ってくれば、正しく動いています。

⑤ 提案のうち、12月3日までに現実にできそうなものを1つ選び、提出用の文書に「見つかった穴」と「直した点」を書きます。

### シナリオ4　課題文を1枚に仕上げる

つくるもの：学生に配れる課題文

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。

② 画面の左上にある ［新しいチャット］ を押します。

③ 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔課題文〕と〔直した点〕の2か所です。

```
あなたは、大学の授業設計に詳しいアドバイザーです。
次の課題文を、学生にそのまま配れる形に整えてください。

【必ず入れる見出し】この順番で書いてください。
1. 課題のねらい（学生に向けて、2文以内）
2. 題材（架空の設定であることを明記）
3. 手順（番号つき。最初の段階は「AIを使わずに、自分の考えを書く」にしてください）
4. 提出するもの
5. この課題でのAIの使い方（使ってよい場面／使わない場面／使ったことをどう書くか／AIの答えを事実として扱わず、自分で確かめること／実在の人物・物件・会社の情報を入力しないこと）
6. 評価の観点（3つ。学生が読んで自分の位置が分かる言葉で）
7. 困ったときの相談先（〔教員名〕と〔連絡方法〕の欄を空けておく）

【書き方の約束】
・A4で1枚（1000字以内）に収めてください。
・学生に向けた敬体で、体言止めを使わずに書いてください。
・「適切に」「十分に」のような、判断を丸投げする言葉を使わないでください。
・実在の企業名・地名・統計の数値を出さないでください。

【課題文】
〔 ここに、シナリオ1で作った課題文を貼り付けてください 〕

【直した点】
〔 シナリオ3で決めた「直した点」を1行で書いてください。無ければ「なし」と書いてください 〕
```

④ 送信ボタンを押します。
→ 1〜7の見出しが付いた1枚分の課題文が返ってくれば、正しく動いています。

⑤ できあがった課題文をコピーして、提出用の文書に貼ります。

### シナリオ5　授業シナリオ（1コマの進行表）をつくる

つくるもの：課題を使う90分の進行表

① Gemini アプリを開き、画面の左上にある ［新しいチャット］ を押します。

② 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔課題文〕の1か所です。シナリオ1または4で作った課題文を貼ってください。

```
あなたは、大学の授業設計に詳しいアドバイザーです。
次の課題を使う、90分1コマの授業シナリオ（進行表）を作ってください。
受講人数は40名、教室は可動式の机がある教室を想定してください。

【進行表に入れること】
・6〜8段に分け、各段に「時間（分）」「教員がすること」「学生がすること」「AIの使用（可／不可／相手役として可）」を書く
・必ず入れる段：
　(a) 導入（課題のねらいと、AIの使い方の説明）
　(b) 個人で考える段（AIを使わずに、自分の考えを書く）
　(c) AIを相手役にして立場の違う言い分を聞き取る段
　(d) グループで判断を組み立てる段
　(e) 発表または提出
　(f) 振り返り（AIを使って分かったこと・分からなかったことを言葉にする）
・各段に、教員が見るポイント（学生がつまずきやすいところ）を1行
・当日までに教員が準備するもの（3つまで）

【書き方の約束】
・表（Markdownの表）で出してください。
・敬体で、体言止めを使わずに書いてください。
・時間の合計が90分になるようにしてください。

【課題文】
〔 ここに、課題文を貼り付けてください 〕
```

③ 送信ボタンを押します。
→ 6〜8段の表と、準備するものが返ってくれば、正しく動いています。

④ 進行表をグループで読み、自分たちの教室・人数で無理があるところを1か所だけ挙げて、続けて直すように頼みます。

⑤ できあがった進行表をコピーして、提出用の文書に貼ります。

## 6. 提出します

提出は、共有用の**スライド1枚**です（14:10 締切）。つくった試作は、共有できる形になっていれば、そのスライドの下部にリンクを貼って学内に共有します（任意）。詳しい提出先と共有のしかたは、共通ページの「提出するもの」をご覧ください。

- **提出スライド（必須）**：共通ページの Step 5 で作ります。「12月3日までに試すこと」を必ず入れてください。
- **試作へのリンク（任意）**：課題文と進行表を Google ドキュメントに貼り、共有リンクを提出スライドの下部に貼ります。Gem を作った方は、Gem の共有リンクも同じように貼ります。

**12月3日までに試すことの例（このテーマ）**
- 作った課題を1コマで試し、学生がAIとの対話で「どの立場の言い分」を拾ってきたかを見る
- 相手役のGemを学生に配り、対話の記録（学生が貼り付けたもの）を集めて読む

## 7. うまくいかないとき

| 困りごと | 対処 |
|---|---|
| AIが質問をせずに、すぐ課題案を出してしまう | 「まず3つの質問をしてください。私が答えるまで課題案を出さないでください。」と続けて送ります |
| 利害関係者役のGemが、結論を出してしまう | 「指示」の欄の「# 答え方の決まり」に「決めるのはあなたです」の行があるか確かめ、保存し直します |
| Gem の ［共有］ が押せない | 深追いしないでください。「指示」の欄の文章をまるごとコピーして提出すれば、受け取った方が同じものを作れます |
| Gem の一覧に、作った Gem が出ない | ［保存］を押していないことが多いです。もう一度作成画面に戻り、［保存］を押します。それでも出ないときは、ブラウザの画面を再読み込みします |
| ボタンや欄が、この紙と違う名前で出ている | 名前が違っても、同じはたらきの場所です。近い名前のものを押してください |

## 8. この紙に印刷してある資料

### 題材の例（シナリオ1で、決めにくいときに使います。いずれも架空の設定です）

| 題材 | 学生が判断すること |
|---|---|
| 新駅開業に伴う駅前再開発（湊南市） | 地権者・自治体・投資家の言い分を聞き、再開発の方針を根拠つきで提案する |
| 相続した空き家の活用 | 売却・賃貸・改修・解体のどれを勧めるかを、相続人の事情と地域の需要から判断する |

| 観光地の民泊の増加 | 住民・観光客・宿泊事業者・自治体の利害を整理し、ルールを提案する |

### 「真正な課題」が満たす5つの原理（メリル）

1. 現実の問題に取り組む
2. 既有の知識を活性化する
3. 手本を見せる（例示）
4. 応用する（学生自身が試す）
5. 統合する（自分の言葉で説明し、現実に結びつける）

### 学びの目標の6段階（ブルームの分類、2001年改訂版）

記憶 → 理解 → 応用 → 分析 → 評価 → 創造

「記憶」「理解」はAIに聞けば一瞬で済みます。「評価」（複数の物件や案を比べて良否を判断する）と「創造」（新しい活用や再生の案を提案する）は、AIに丸投げできません。新しい課題は、この右側に置きます。
