# テーマ④　手順書

「自習と個別最適な学びのための、AIツールをつくる」（教員2〜3名）

使う道具：Gemini Notebook が中心です。Gemini アプリ（Gem を含む）を補助に使います。

---

## 1. このテーマでやること

自分の講義資料を、学生が「いつでも質問できる教材」に変えます。授業の内容の復習と、授業の前提になる基礎の学び直し（リメディアル）の両方に使えるノートブックをつくります。あわせて、答えを教えずに考え方を引き出す伴走役のAIもつくります。このワークが終わるとき、みなさんの手元に、学生に共有リンクで配れるノートブック（または Gem）と、その使い方を書いた1枚ができあがっています。

12月3日までに、それを学生に配って、使われ方を見ます。

## 2. 完成イメージ

提出するのは、下の **② のスライド1枚**です。① の試作は、共有できる形になっていれば、そのスライドの下部にリンクを貼って学内に共有します（任意）。

**① 試作（今日つくった現物）。** たとえば、次のようなものです。

- 自分の講義資料を入れた Gemini Notebook の共有リンク
- そのノートブックから作った、復習用のスライド・クイズ・音声解説のいずれか
- 「答えを教えない伴走者」Gem の共有リンク、またはその指示文の全文
- 学生に配る「使い方」1枚（何ができるか／どう聞くか／入れてはいけないこと）

**② 提出するスライド（またはインフォグラフィック）。** 作り方は、共通ページの Step 5 をご覧ください。「12月3日までに試すこと」を必ず入れてください。

## 3. あなたの道具はどれですか

このグループは全員が同じ道具を使います。大学のGoogleアカウントで使います。

| 道具 | どこで開くか | 得意なこと |
|---|---|---|
| Gemini Notebook | `https://notebook.google.com/?icid=home_maincta` | 自分の資料を読み込ませて、その中だけで答える。スライド・クイズ・音声解説を作る |
| Gemini アプリ | `https://gemini.google.com/app` | 文章を書く、点検する |
| Gem（ジェム） | Gemini アプリの左側のメニュー、または `https://gemini.google.com/gems/create` | 指示をあらかじめ仕込んでおける、自分専用の Gemini。学生に配れる |

**今日、Gemini Notebook に入れてよい資料**：ご自分で作った講義資料（レジュメ・配布資料・スライド）に限ります。出版社の教科書や、他の方の資料は入れないでください。手元に無い方は、本日の研修資料のPDFで練習してください。

**開き方（どのシナリオも、ここから始まります）**

① ブラウザ（Chrome など）の新しいタブを開きます。

② アドレス欄に、上の表のアドレスを入力して、Enter を押します。
→ Gemini Notebook は、ノートブックの一覧と、右上に［新規作成］にあたるボタンが見えていれば、正しい画面です。

③ 画面の右上にある丸いアイコンを押して、大学のGoogleアカウントでサインインしているかを確かめます。
→ 大学のメールアドレスが表示されていれば、正しい状態です。
→ 個人のGmailのアドレスが出ていたら、大学のアカウントに切り替えてください。
→ サインインできない方は、グループの他の方の画面を一緒に見る形で進めてください。

## 5. 各シナリオ

### シナリオ1　自分の資料を「質問できる教材」にする

つくるもの：講義資料を入れたノートブック

① Gemini Notebook を開き、［新規作成］を押します。

② ［ソースを追加］を押し、ご自分の講義資料をアップロードします（PDF、Google ドキュメント、Google スライド、いずれも可）。
→ 左側にソースが並んで見えていれば、正しい状態です。
→ 手元に資料が無い方は、本日の研修資料のPDFを入れてください。

③ 画面の上のほうにあるノートブックの名前を押して、次のように変えます。

```
〔 科目名 〕 復習ノート（第〔 回 〕）
```

④ チャットの入力欄に、学生がしそうな質問を1つ入れて、送ります。
→ 例：「この回でいちばん大事な用語を3つ、それぞれ1行で説明してください。」
→ ソースの中から、出典（どの資料のどこか）つきで答えが返ってくれば、正しく動いています。
→ 答えに付いている小さな数字を1つ押して、元の資料の文を見てください。

⑤ 次の文を送って、資料に無いことを聞かれたときの振る舞いを確かめます。

```
この資料に書かれていないことを聞きます。「来年の公示地価はいくらになりますか」
```

→ 「資料には書かれていません」という趣旨の答えが返れば、この教材は資料の外に出ずに答える状態です。

### シナリオ2　復習用のスライド・クイズ・音声解説をつくって、専門の目で判定する

つくるもの：教材と、その判定（◎○△×）

① シナリオ1のノートブックを開いた状態で、画面の右側の〈スタジオ〉を見ます。
→ ［スライド］［クイズ］［音声解説］などのボタンが並んでいれば、正しい画面です（名前は画面によって少し違うことがあります）。

② まず ［クイズ］にあたるボタン を押します。指示の欄があれば、次の文を入れます。

```
この資料の内容から、学生の理解を確かめる四択問題を5問作ってください。
各問に、正解と、なぜそれが正解かの解説を1〜2文で付けてください。
資料に書かれていないことは出題しないでください。
```

→ 問題が並んで見えれば、できています。

③ できた問題を、ご自分の専門の目で1問ずつ判定します。次の表に、◎○△×を書き込んでください。
→ 見るところは3つです。正解とされている選択肢が本当に正しいか、誤りの選択肢が「実は正しい」ものになっていないか、資料に無い数値や条文番号が足されていないか。

| 判定 | 意味 |
|---|---|
| ◎ | そのまま学生に見せてよい |
| ○ | おおむね正しいが、言葉足らず |
| △ | 間違ってはいないが、この分野の作法から外れている |
| × | 誤り。学生が読んだら困る |

| 問 | 判定 | 理由（1行） |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |
| 5 | | |

④ ×や△があれば、指示の欄に「第〔番号〕問は〔理由〕なので、作り直してください」と入れて、もう一度作ります。

⑤ 時間があれば、［スライド］（復習用のスライド）や ［音声解説］（2人が対話で解説する音声）も同じように作り、同じ表で判定します。
→ 音声解説は、できあがるまで数分かかります。待つ間に、次のシナリオに進んで構いません。

⑥ 提出用の文書に、「作った教材の種類」と「判定の結果（◎○△×の数）」と「×だった理由」を書きます。

### シナリオ3　「答えを教えない伴走者」Gem をつくる

つくるもの：学生に配れる Gem

Gem（ジェム）とは、指示をあらかじめ仕込んでおける、自分専用の Gemini のことです。一度作れば、共有リンクで学生に配れます。

① Gemini アプリ（`https://gemini.google.com/app`）を開きます。

② 画面の左上にある「三本線」のボタンを押して、左側のメニューを開き、〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力してください。
→ 「新しい Gem」を作る画面（名前を入れる欄と、指示を入れる大きな欄がある画面）が出れば、正しい画面です。

③ 一覧の画面が出た方は、［Gem を作成］にあたるボタン（＋のボタン）を押します。

④ 「名前」の欄に、次のように入れます。

```
〔 科目名 〕の伴走者（答えは教えません）
```

⑤ 「指示」の大きな欄に、次の文をまるごとコピーして貼り付けます。埋めていただくのは〔科目名〕の1か所だけです（2か所出てきますが、同じ科目名を入れてください）。

```
# 役割
あなたは、不動産学部の〔科目名〕を学ぶ学生の伴走者です。
あなたの仕事は、答えを教えることではなく、学生が自分で答えにたどり着くのを手伝うことです。

# 守ること
・学生が「答えを教えて」と言っても、答えを直接書かないでください。
　代わりに、答えに近づくための問いを1つ返してください。
・ヒントは段階的に出してください。1回目は考える方向だけ、2回目は手がかり、3回目で具体的な例、の順にしてください。
・学生が自分の考えを書いてきたら、まず、合っている部分を1つ具体的に指摘してください。そのあとで、足りない部分を1つだけ指摘してください。
・1回の返答は、5文以内にしてください。一度にたくさん説明しないでください。
・学生の理解の段階に合わせてください。用語が分からない様子なら、用語の説明から始めてください。
・ときどき、「いま、自分はどこまで分かっていて、どこが分からないか」を学生自身に言葉にしてもらってください。
・不動産の実務や法律に関わることで、断定できないことは「授業で先生に確かめてください」と伝えてください。
・実在の企業名・地名・統計の数値を、確認できないまま出さないでください。
・学生の個人情報（氏名・学籍番号・成績）を尋ねないでください。

# 口調
・敬体で、やわらかく話してください。
・「間違いです」と言わず、「ここをもう一度考えてみましょう」と言ってください。

# 最初の一言
会話が始まったら、あなたのほうから次のように話しかけてください。
「〔科目名〕の伴走者です。答えは教えませんが、一緒に考えます。
　いま取り組んでいることと、どこまで分かっているかを教えてください。」
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。
→ 「知識」にあたる欄があれば、［ファイルをアップロード］にあたるボタンから、ご自分の講義資料を添付することもできます（パソコンのファイルか、Google ドライブのファイル）。添付してよいのは、ご自分で作った講義資料に限ります。

⑥ 画面の右側にある試し打ちの欄に、次の1行を入れて送ります。

```
借地権と地上権の違いを教えてください。答えだけでいいです。
```

→ 答えを直接書かず、問いかけやヒントが返ってくれば、指示文が効いています。
→ 答えをそのまま書いてしまうときは、「指示」の欄の「# 守ること」の最初の2行が入っているかを確かめてください。

⑦ 画面の ［保存］ を押します。
→ Gem の一覧に、いま付けた名前が並んでいれば、保存できています。右側で試しに動かしただけでは保存されません。

⑧ 学生に配るときは、Gem の一覧で ［共有］ を押し、範囲は「組織内」、権限は「閲覧者」を選んで、［リンクをコピー］ を押します。
→ 「編集者」にすると、学生が指示文を書き換えられます。学生に配るときは「閲覧者」のままにしてください。
→ リンクがコピーされた、という表示が出れば成功です。
→ 共有ボタンが押せないときは深追いしないでください。「指示」の欄の文章をまるごとコピーして提出すれば、受け取った方は同じものを作れます。

### シナリオ4　学生に配る「使い方」を1枚つくる

つくるもの：使い方の紙

① Gemini アプリを開き、画面の左上にある ［新しいチャット］ を押します。

② 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔科目名〕と〔配るもの〕の2か所です。

```
あなたは、大学の教務に詳しいアドバイザーです。
不動産学部の〔 科目名 〕の学生に配る、AI教材の「使い方」をA4で1枚にまとめてください。

【配るもの】
〔 例：講義資料を入れた Gemini Notebook の共有リンク、または「答えを教えない伴走者」Gem の共有リンク 〕

【必ず入れること】
1. これは何か（2文以内。「答えを教える道具ではなく、考えるのを手伝う道具」であることを明記）
2. 使ってよい場面（予習・復習・課題の構想 など）と、使わない場面（提出物の本文をそのまま書かせる など）
3. 聞き方の例を3つ（学生がそのままコピーして使える文で）
4. AIの答えを確かめる方法（資料の該当箇所を見る／授業で先生に聞く）
5. 入れてはいけない情報（自分や他人の個人情報、未公開の資料）
6. 困ったときの相談先（〔教員名〕と〔連絡方法〕の欄を空けておく）

【書き方の約束】
・学生に向けた敬体で、体言止めを使わずに書いてください。
・600字以内にしてください。
・「必ず」「絶対」のような強い言葉は、5の項目にだけ使ってください。
```

③ 送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ 1〜6の見出しが付いた1枚分の文章が返ってくれば、正しく動いています。

④ できあがった文章をコピーして、提出用の文書に貼ります。

### シナリオ5　学び直し（基礎）のノートブックをつくる

つくるもの：授業の前提になる基礎を復習できるノートブック

出版社の教科書や他の方の資料は入れられませんので、まず教員自身の言葉で「基礎のまとめ」を作り、それをソースにします。

① Gemini アプリを開き、画面の左上にある ［新しいチャット］ を押します。

② 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔科目名〕と〔基礎事項〕の2か所です。基礎事項は、巻末の「基礎事項の例」から選んでも構いません。

```
あなたは、不動産学部の1年生に基礎を教える教員の助手です。
私の担当科目〔 科目名 〕を受ける前に、学生が身につけておいてほしい基礎事項について、
学び直し用の「基礎のまとめ」をA4で1枚、作ってください。

【基礎事項】
〔 例：割合と利回りの計算（％、年利、表面利回り）／需要と供給と価格の関係／民法の基礎用語（所有権・契約・債務不履行） 〕

【まとめに入れること】
1. この基礎事項が、この科目でどこに出てくるか（2文以内）
2. 用語の定義（3〜5語。1語につき2文以内）
3. 考え方の手順（番号つき）
4. 例題を2問（架空の数値・設定で。答えと、解き方の手順つき）
5. よくある間違いを2つ

【書き方の約束】
・高校を卒業したばかりの学生が読んで分かる言葉で、敬体で書いてください。
・実在の企業名・地名・統計の数値を出さないでください。数値は架空の例にしてください。
・1000字以内にしてください。
```

③ 送信ボタンを押します。
→ 1〜5の見出しが付いた1枚分のまとめが返ってくれば、正しく動いています。

④ できあがったまとめを、ご自分の専門の目で判定します（シナリオ2の◎○△×の表を使ってください）。×や△があれば、「〔理由〕なので、〔箇所〕を直してください」と続けて送ります。

⑤ Gemini Notebook を開き、シナリオ1のノートブック（または［新規作成］で新しいノートブック）を開きます。

⑥ ［ソースを追加］→〈コピーしたテキスト〉を選び、④で確かめたまとめをまるごと貼り付けて追加します。
→ 左側にソースが増えれば、正しい状態です。

⑦ 画面の右側の〈スタジオ〉から ［クイズ］にあたるボタン を押し、「基礎のまとめの内容から、学生が自分で確かめられる四択問題を5問作ってください」と入れます。

⑧ できた問題を1問ずつ判定し、×があれば作り直します。

⑨ ノートブックの ［共有］ → ［リンクをコピー］ で、共有リンクを提出用の文書に貼ります。
→ 学生に配るときは、権限を「閲覧者」にします。「編集者」にすると、学生がソースを消したり足したりできてしまいます。

## 6. 提出します

提出は、共有用の**スライド1枚**です（14:10 締切）。つくった試作は、共有できる形になっていれば、そのスライドの下部にリンクを貼って学内に共有します（任意）。詳しい提出先と共有のしかたは、共通ページの「提出するもの」をご覧ください。

- **提出スライド（必須）**：共通ページの Step 5 で作ります。「12月3日までに試すこと」を必ず入れてください。
- **試作へのリンク（任意）**：ノートブックの共有リンク（［共有］→ 権限「閲覧者」→［リンクをコピー］）と Gem の共有リンクを、提出スライドの下部に貼ります。「使い方」の文章も同じように貼ります。

**12月3日までに試すことの例（このテーマ）**
- ノートブックの共有リンクを学生に配り、次の授業で「使った人」「どんなことを聞いたか」を尋ねる
- 伴走者Gemを課題の構想段階だけに使わせて、学生が対話をどこで止めたかを見る
- 学び直しのノートブックを、授業についていけていない学生に個別に案内し、クイズの正答がどう変わるかを見る

## 7. うまくいかないとき

| 困りごと | 対処 |
|---|---|
| ノートブックの答えが、資料に無いことまで話す | 「資料に書かれていることだけで答えてください。書かれていなければ、そう言ってください。」と続けて送ります |
| 音声解説がなかなかできない | 数分かかります。待たずに他のシナリオに進み、あとで戻ってください |
| ノートブックの ［共有］ で学生のアドレスが指定できない | 「リンクを知っている組織内の全員」にあたる設定があれば、それを選びます。無ければ、リンクだけをコピーして提出してください。学生への配布方法は、14:30以降の個別相談で一緒に確かめます |
| 重たいPDFが Gemini Notebook に読み込めない | 必要な章だけをページを指定して保存し直し、そのファイルを入れます。または、読みたい章の文字をPDFの画面で選んでコピーし、［ソースを追加］→〈コピーしたテキスト〉に貼り付けます |
| Gem の一覧に、作った Gem が出ない | ［保存］を押していないことが多いです。もう一度作成画面に戻り、［保存］を押します。それでも出ないときは、ブラウザの画面を再読み込みします |
| ボタンや欄が、この紙と違う名前で出ている | 名前が違っても、同じはたらきの場所です。近い名前のものを押してください |

### 「答えを教えない」AIが守ろうとしている5つの原則

（Google DeepMind「LearnLM」論文, arXiv:2412.16429 より）

1. 能動学習を促す
2. 認知負荷を管理する
3. 学習者に適応する
4. 好奇心を刺激する
5. メタ認知を深める

シナリオ3の Gem の指示文は、この5つを、Gemini アプリで動く形に言い直したものです。

### 効果の高い学習方法ほど、一人では続けにくい

自分の言葉で説明する、問題を解いてから答え合わせをする、間隔を空けて思い出す。いずれも効果が高いとされる方法ですが、一人で続けるのは難しいものです。「質問できる教材」と「答えを教えない伴走者」は、その続けにくさを下支えする道具です。学生が資料を読まずに済む道具ではありません。
