# テーマ⑤　手順書

「業務で便利なツールを、開発する」（教員2〜3名）

使う道具：Gemini アプリ（Gem を含む）が中心です。Workspace Studio（Gmail・Drive・Sheets の中で動く自動化）も、使える方は試します。

---

## 1. このテーマでやること

毎回くり返している作業を1つ選び、それを「係」（Gem）にして、同僚にそのまま渡せる形にします。「きっかけがあったら自動で動く」形にしたい作業は、Workspace Studio で組んでみます。このワークが終わるとき、みなさんの手元に、係の共有リンクと、同僚がそれだけ読めば使える手順書1枚ができあがっています。

12月3日までに、その係を同僚1人に使ってもらい、分かりにくかったところを直します。

ここでの「開発」は、プログラムを書くことではありません。**毎回ゼロから書いている頼み方を、保存して配ること**です。

## 2. 完成イメージ

提出するのは、下の **② のスライド1枚**です。① の試作は、共有できる形になっていれば、そのスライドの下部にリンクを貼って学内に共有します（任意）。

**① 試作（今日つくった現物）。** たとえば、次のようなものです。

- 係（Gem）の共有リンク、またはその指示文の全文
- 係を使って実際に作った出力（通知文・要約・表 など）を1つ
- 同僚向けの手順書1枚（何をする係か／どこを開くか／何を入力するか／出てきたものをどう確かめるか／入れてはいけない情報）
- 隣の人に使ってもらって、直したところ（1行）

**② 提出するスライド（またはインフォグラフィック）。** 作り方は、共通ページの Step 5 をご覧ください。「12月3日までに試すこと」を必ず入れてください。

## 3. あなたの道具はどれですか

このグループは全員が同じ道具を使います。大学のGoogleアカウントで使います。

| 道具 | どこで開くか | 得意なこと |
|---|---|---|
| Gemini アプリ | `https://gemini.google.com/app` | 頼む、書く、整える |
| Gem（ジェム） | Gemini アプリの左側のメニュー、または `https://gemini.google.com/gems/create` | 指示をあらかじめ仕込んでおける、自分専用の Gemini。同僚に配れる |
| Workspace Studio | Gemini アプリの左側のメニュー、または Google Workspace の中の〈Workspace Studio〉にあたる項目 | 「きっかけ（メール受信・フォーム回答・時刻）→ Gemini の処理 → 出力（メール下書き・Chat通知・Sheets行追加）」を、プログラミングなしで並べて自動化する |

Gem は「人が貼って、AIが返す」道具です。Workspace Studio は「きっかけがあったら、人が貼らなくても動く」道具です。Workspace Studio の項目が画面に見当たらない方は、大学の契約で使えない状態ですので、シナリオ6は飛ばして、同じ内容を Gem で作ってください。

**開き方（どのシナリオも、ここから始まります）**

① ブラウザ（Chrome など）の新しいタブを開きます。

② アドレス欄に `https://gemini.google.com/app` を入力して、Enter を押します。
→ 画面の下のほうに、文章を打ち込む横長の入力欄が見えていれば、正しい画面です。

③ 画面の右上にある丸いアイコンを押して、大学のGoogleアカウントでサインインしているかを確かめます。
→ 大学のメールアドレスが表示されていれば、正しい状態です。
→ 個人のGmailのアドレスが出ていたら、大学のアカウントに切り替えてください。
→ サインインできない方は、グループの他の方の画面を一緒に見る形で進めてください。

つくるもの：係にする作業の名前

① 次の一覧から、毎週または毎月くり返していて、書き出しに時間がかかる作業を1つ選びます。

| 候補 | 係にすると、こうなる |

| 学生への通知文・案内文の下書き | 箇条書きを渡すと、敬体の案内文になって返ってくる |

### シナリオ2　その作業を、まず1回AIに頼んでみる

つくるもの：1回分の出力

① Gemini アプリを開きます（開き方は「3. あなたの道具はどれですか」をご覧ください）。

② 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔してほしいこと〕と〔材料〕の2か所です。材料は、シナリオ1で選んだ作業に合わせて、巻末の架空データ①か②を貼ってください。

```
あなたは、不動産学部の教員の仕事を手伝う係です。

【してほしいこと】
〔 例：次のメモをもとに、学生向けの案内文の下書きを作ってください 〕

【相手と場面】
読み手は不動産学部の学生です。メールで送ります。

【出力の形】
・敬体で、体言止めを使わずに書いてください。
・日付・場所・連絡先は、材料のとおりに写してください。言い換えないでください。
・材料に無い事実、数字、日付を足さないでください。分からないところは〔要確認〕と書いてください。
・最後に、送る前に確かめてほしい点を箇条書きで3つ挙げてください。

【材料】
〔 ここに、架空データ①または②を貼り付けてください 〕
```

③ 送信ボタン（紙飛行機や矢印のアイコン）を押します。
→ 案内文（または表）と、「確かめてほしい点」が返ってくれば、正しく動いています。

④ 出てきたものを読み、材料に無いことが書かれていないかを確かめます。
→ 直したいところがあれば、「〔直したいこと〕を直してください」と続けて送ります。

⑤ できあがったものをコピーして、提出用の文書に貼ります。

### シナリオ3　係（Gem）をつくる

つくるもの：同僚に配れる Gem

Gem（ジェム）とは、指示をあらかじめ仕込んでおける、自分専用の Gemini のことです。一度作れば、次からは同じ指示を打ち直さずに使えます。そして、同僚に配れます。

① Gemini アプリを開き、画面の左上にある「三本線」のボタンを押して、左側のメニューを開き、〈Gem〉にあたる項目を押します。
→ 画面によって「Gem」と表示されている場合と「Gem を表示」と表示されている場合があります。どちらでも同じものです。
→ 見つからないときは、ブラウザのアドレス欄に `https://gemini.google.com/gems/create` を直接入力してください。
→ 「新しい Gem」を作る画面（名前を入れる欄と、指示を入れる大きな欄がある画面）が出れば、正しい画面です。

② 一覧の画面が出た方は、［Gem を作成］にあたるボタン（＋のボタン）を押します。

③ 「名前」の欄に、係の名前を入れます。

```
〔 例：学生向け案内文 係（不動産学部） 〕
```

④ 「指示」の大きな欄に、次の文をまるごとコピーして貼り付けます。埋めていただくのは〔係の仕事〕の1か所だけです。シナリオ2の【してほしいこと】と同じ内容を入れてください。

```
# あなたの役割
あなたは、不動産学部の教職員の仕事を手伝う係です。
あなたの仕事：〔 例：箇条書きのメモをもとに、学生向けの案内文の下書きを作ること 〕

# 利用者が貼ってくるもの
利用者は、メモや文章を貼ってきます。何も説明が無くても、それを材料として仕事をしてください。
材料が足りないときは、仕事を始める前に、足りないものを箇条書きで尋ねてください。

# 出力の形（この順に出してください）
1. できあがった文章（または表）の全文
2. 送る前・使う前に確かめてほしい点を、箇条書きで3つまで
3. 材料に無くて〔要確認〕にした箇所の一覧

# 文体の決まり
・日本語で、敬体（です・ます）で書いてください。体言止めを使わないでください。
・1文は60字以内にしてください。
・専門用語を使うときは、短い言い換えを丸かっこで添えてください。
・あおる言い方をしないでください。感嘆符は1つの文書に1つまでにしてください。

# 必ず守ること
・材料に無い事実、数字、日付を足さないでください。分からないところは〔要確認〕と書いてください。
・数字・日付・場所・連絡先は、材料のまま写してください。言い換えないでください。
・個人名や連絡先が含まれていたら、そのまま出さずに〔氏名〕〔連絡先〕に置き換えてください。
・利用者が「短く」と言ったら、意味を落とさずに文字数を半分にしてください。
・法律や学内規程の解釈に関わることは、あなたが決めずに「学内で確認が必要です」と書いてください。

# 最初の一言
会話が始まったら、あなたのほうから次のように話しかけてください。
「〔係の名前〕です。材料（メモや文章）を、そのまま貼り付けてください。」
```

→ 大きな欄に長い文章がまるごと入っていれば、正しい状態です。

⑤ 画面の右側にある試し打ちの欄に、巻末の架空データ①または②をそのまま貼って送ります。
→ 「出力の形」の1〜3の順に返ってくれば、指示文が効いています。
→ 順番が違うときは、「指示」の欄の「# 出力の形」が入っているかを確かめてください。

⑥ 画面の ［保存］ を押します。
→ Gem の一覧に、いま付けた名前が並んでいれば、保存できています。右側で試しに動かしただけでは保存されません。

⑦ 同僚に配るときは、Gem の一覧で ［共有］ を押し、範囲は「組織内」、権限は「閲覧者」を選んで、［リンクをコピー］ を押します。
→ 「編集者」にすると、受け取った方が指示文を書き換えられます。配るときは「閲覧者」のままにしてください。
→ リンクがコピーされた、という表示が出れば成功です。
→ 共有ボタンが押せない、エラーが出るというときは深追いしないでください。「指示」の欄の文章をまるごとコピーして渡せば、受け取った方は同じものを作れます。

### シナリオ5　手順書を1枚つくる

つくるもの：同僚向けの手順書

① Gemini アプリを開き、画面の左上にある ［新しいチャット］ を押します。

② 次の文をコピーして、入力欄に貼り付けます。埋めていただくのは〔係の名前〕と〔指示文〕の2か所です。指示文は、シナリオ3で「指示」の欄に貼った文章をそのままコピーしてください。

```
あなたは、大学の業務マニュアルの書き手です。
次の「係」（Gem）を、同僚がその紙だけ読めば使えるようにする手順書を、A4で1枚にまとめてください。

【係の名前】
〔 係の名前 〕

【係の指示文】
〔 ここに、Gem の「指示」の欄の文章をそのまま貼り付けてください 〕

【手順書に必ず入れる見出し】この順番で書いてください。
1. この係は何をするか（2文以内）
2. どこを開くか（共有リンクを貼る欄を空けておく。リンクが使えないときのために「指示文を貼って自分で作る」方法も1行）

4. 出てきたものを、どう確かめるか（3点）
5. 入れてはいけない情報（学生・教職員・取引先の個人情報、未公開の学内資料、契約に関わる情報）
6. うまくいかないときの対処（2点）

【書き方の約束】
・パソコンに不慣れな方にも分かるように、1つの手順に1つの操作を書いてください。
・敬体で、体言止めを使わずに書いてください。
・600字以内にしてください。
```

③ 送信ボタンを押します。
→ 1〜6の見出しが付いた1枚分の手順書が返ってくれば、正しく動いています。

④ できあがった手順書をコピーして、提出用の文書に貼ります。共有リンクの欄に、シナリオ3でコピーしたリンクを貼ります。

### シナリオ6　「きっかけがあったら動く」形にする（Workspace Studio）

つくるもの：フォーム回答やメールをきっかけに、Gemini が要約して通知する自動化

Workspace Studio は、「きっかけ（スターター）」「処理（Gemini）」「出力」の3種類の部品を並べて、定型作業を自動にする道具です。ここでは「架空の見学会の申込フォームに回答があったら、Gemini が要点をまとめて、担当者にメールの下書きを用意する」自動化を組みます。

**★ 作るのは下書きだけです。回答した学生に自動で返信する設定にはしません。学生への返信は、できた下書きを読んで直してから、ご自身で送ります。**

本番で学生からの回答に使うときは、回答に個人情報が含まれることを踏まえ、貴学に生成AIの利用方針があれば、そちらを優先してください。

① Gemini アプリを開き、画面の左側のメニューから〈Workspace Studio〉にあたる項目を探して押します。
→ 見当たらないときは、Google Workspace の各アプリ（Gmail や Drive）の画面から〈Workspace Studio〉にあたる項目を探してください。
→ それでも見当たらないときは、大学の契約で使えない状態です。このシナリオは飛ばして、シナリオ3の Gem で同じ「要約して下書きを作る係」を作ってください。

② ［新規作成］にあたるボタンを押します。
→ 「きっかけ」を選ぶ画面、または「何を自動化したいか」を文章で入れる欄が出れば、正しい画面です。

③ 文章で入れる欄がある場合は、次の文を貼り付けます。部品を選ぶ画面の場合は、次の文の内容にそって、きっかけ・処理・出力を1つずつ選びます。

```
Google フォーム「現地見学会 参加申込（架空）」に新しい回答があったら、
その回答の内容（氏名・所属・参加希望日・質問）を Gemini が読み、
「参加希望日」と「質問の有無」を1行ずつにまとめたうえで、
担当者あてのメールの下書きを Gmail に作成してください。
メールの本文は敬体で、件名は「【見学会申込】〔参加希望日〕」としてください。
氏名や連絡先を、本文中で言い換えたり省略したりしないでください。
```

④ 「処理」の部品（Gemini に何をさせるか）の指示欄には、次の文を入れます。

```
あなたは、不動産学部の見学会の受付係です。
フォームの回答を受け取ったら、次の3行にまとめてください。
1. 参加希望日：〔回答のまま〕
2. 質問：〔あれば回答のまま。無ければ「なし」〕
3. 担当者が返信前に確かめること：〔1つ〕
回答に無いことを足さないでください。
```

**★ テストの前に、必ずお読みください**

テスト実行は、練習ではありません。本当に動きます。メールを送る設定ならメールが実際に送られ、予定を作る設定なら予定が実際に作られます。取り消しはできません。

テストの前に、③で組んだ出力が「メールの下書き」になっていて、「メールを送信」になっていないことを確かめてください。宛先を入れる欄がある場合は、ご自身のメールアドレスにしてください。回答した学生のアドレスを宛先に入れると、AIの書いた文章が、人の目を通らずに学生へ届くおそれがあります。

⑤ ［テスト］または［実行］にあたるボタンを押して、動きを確かめます。
→ 架空の回答を1件入れて、Gmail の下書きに1通できていれば、正しく動いています。
→ フォームがまだ無い方は、Google フォームで「氏名・所属・参加希望日・質問」の4項目だけのフォームを先に作ってください（実在の学生の回答は使わないでください）。練習の回答は、ご自身で架空の氏名と内容を入れて送ります。
→ うまくいったら、〈オンにする〉にあたるボタンを押します。ここから、回答があるたびに自動で動きます。止めたいときは、自動化の横にある〈その他〉（点が3つ縦に並んだ印）を押して、〈オフにする〉を押します。動いたかどうかは、〈アクティビティ〉にあたる項目で確かめます。

⑥ できあがった自動化の名前と、③④で貼った文を、提出用の文書に貼ります。

## 7. 提出します

提出は、共有用の**スライド1枚**です（14:10 締切）。つくった試作は、共有できる形になっていれば、そのスライドの下部にリンクを貼って学内に共有します（任意）。詳しい提出先と共有のしかたは、共通ページの「提出するもの」をご覧ください。

- **提出スライド（必須）**：共通ページの Step 5 で作ります。「12月3日までに試すこと」を必ず入れてください。
- **試作へのリンク（任意）**：係の共有リンク（または Workspace Studio の自動化の名前と貼った文、または指示文の全文）と手順書を Google ドキュメントに貼り、共有リンクを提出スライドの下部に貼ります。

**12月3日までに試すことの例（このテーマ）**
- 係と手順書を同僚1人に渡し、本人に何も説明せずに使ってもらって、詰まったところを直す
- 自分の毎週の作業に3回使い、指示文をどう直したかを記録する
- Workspace Studio の自動化を、架空のフォームで1週間動かし、下書きの出来を記録する

## 8. うまくいかないとき

| 困りごと | 対処 |
|---|---|
| 係が、材料に無い日付や事実を書いてしまう | 「指示」の欄の「# 必ず守ること」の1行目が入っているか確かめます。出力に対しては「材料に無いことは〔要確認〕にしてください」と続けて送ります |
| 出力が長すぎる | 「短く」と送ります。「指示」に「短くと言われたら半分にする」の行が入っていれば、それで縮みます |
| Gem の ［共有］ が押せない | 深追いしないでください。「指示」の欄の文章をまるごとコピーして、手順書の2に貼っておけば、受け取った方が同じものを作れます |
| Workspace Studio の項目が見当たらない | 大学の契約で使えない状態です。シナリオ6は飛ばして、同じ内容を Gem で作ります。14:30以降の個別相談で、契約の確認方法をお伝えします |
| 自動化が、学生や他の方にメールを送ってしまわないか心配になる | 出力が「メールの下書き」で、宛先がご自身のメールアドレスだけになっていれば、他の方には届きません。自動化を開いて、出力と宛先の欄を確かめてください |
| Gem の一覧に、作った Gem が出ない | ［保存］を押していないことが多いです。もう一度作成画面に戻り、［保存］を押します。それでも出ないときは、ブラウザの画面を再読み込みします |
| ボタンや欄が、この紙と違う名前で出ている | 名前が違っても、同じはたらきの場所です。近い名前のものを押してください |
