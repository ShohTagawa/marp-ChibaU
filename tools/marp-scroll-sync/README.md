# Marp Scroll Sync (ChibaU)

千葉大スタイル Marp デッキ用の、**本文 ↔ スライド スクロール同期**プレビュー拡張。

## できること
- **ステータスバー**に「いま編集中のカーソル行が Marp の何枚目か」を `Slide 34/78` 形式で常時表示
- サイドの **Webview プレビュー**が、カーソル位置のスライドへ自動スクロール(編集中の箇所が常に見える)
- プレビューの**スライドをクリック**すると、本文の該当行へジャンプ(双方向)
- プレビューの**テキストをクリック**すると、その文字列を**そのスライドの行範囲内**で照合し、原稿の該当行を**選択＋一時ハイライト**(生`<div>`/`<span>`の本文でも逆引き可)。文字の無い余白クリックはスライド先頭へフォールバック
- **文字サイズ/色の微調整**：エディタで文字を選択し、プレビュー下部のツールバー `A− [px] A+ 🎨 ✕` または **Cmd+Alt+= / Cmd+Alt+−** で `font-size` を **1px 刻み**で増減、色も変更。テーマ CSS は触らず、その箇所だけ `<span class="ss-tune" style="…!important">` を**原稿(.md)にインライン挿入**して上書きする(既に付いていれば数値だけ更新)。ツールバーが開いている間は **↑ / ↓** でも増減可。`✕` で解除
- **現在スライドをブラウザでプレゼン**：`Marp: Present`(ツールバーの ▶)で marp-cli(`--html`)が発表用 HTML を生成し、編集中のページから既定ブラウザで開く
- ファイル編集で自動再レンダリング(0.7s デバウンス。サイズ/色の微調整は即時・無スクロールで反映)
- `theme/academic.css` / `theme/ponchie.css` を自動適用、ローカル画像(`../assets/…`, `./src/…`)も表示

## 使い方
1. `marp: true` の `.md` を開く
2. ステータスバー右の `Slide n/N` をクリック、または **Cmd+K M**(`Marp: Open Synced Preview`)
3. コマンドパレット `Marp: Go to Slide by number…` で番号ジャンプも可能
4. **サイズ/色を変える**：プレビューで対象を**クリック**(→原稿の該当行へジャンプ＆実寸 px を取得) → エディタで**変えたい文字を選択** → ツールバーの `A+/A−`・↑↓・`Cmd+Alt+=/−` で 1px ずつ、`🎨`/`Marp: 選択文字の色を変える…` で色。`Cmd+Alt+=/−` は marp の md 編集中のみ有効

## 書き戻される記法
選択文字は次の形で原稿に挿入される(テーマ CSS より優先される `!important` 付き)。手書き・後編集も可：
```html
本文の<span class="ss-tune" style="font-size:26px !important; color:#A6192E !important">ここだけ</span>大きく赤く
```

## スライド番号の算出
frontmatter を除外し、コードフェンス内を無視、直前が空行の `---` のみをページ区切りとして数える。
本デッキ(78枚)で marp-core の実レンダリング枚数と一致を確認済み。
